# Governance, notification and rights acceptance

Prospective cases exercise exact evidence, current authority and recoverable
effects through the owning APIs/stores.

| ID | Scenario | Required result |
| --- | --- | --- |
| GOV01 | Report exact catalog name/body/structure/asset use | Correct component/revision, including empty/unavailable states. |
| GOV02 | Target/rule changes during moderation | Exact evidence retained; stale basis cannot silently apply to another version. |
| GOV03 | Competing reversals and independent Realm decisions | One effect per operation; other contexts preserved. |
| GOV04 | End one rights offering while another is recognized | Independent history; recognition cannot reopen ended offering. |
| GOV05 | Recipient unsubscribes/loses access before delivery | Current channel eligibility/disclosure applied. |
| GOV06 | Lost external ACK or repeated callback | Idempotent effect or explicit uncertain reconciliation. |
| GOV07 | Erasure conflicts with history pin/restored backup | Erased/unavailable result; no payload resurrection. |
| GOV08 | Read watermark/realtime connection race | Declared monotonicity and gap reconciliation. |
| GOV09 | Fit/spoiler edits race | Independent dimensions and populations preserved. |
| GOV10 | Single major spoiler vote, mixed or no evidence | Separate protection/status/distribution and confidence policy. |
