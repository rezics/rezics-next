# First public scope

Which user-facing systems the first public release contains, who owns each, and what is deferred. The evidence is
[the system inventory](research/system-inventory.md); systems built but not polished stay closed behind platform
grants. An owner is the Goal that dispatches the system's work; collaborators own their own modules.

**Closed; inactive by default** marks every system or portion kept behind platform grants. It is excluded from
the first public release and receives no proactive research, implementation, polishing, acceptance expansion or
activation unless the maintainer explicitly requests that work. Existing code, a retained Goal checklist or an
unfinished contract does not authorize continuation. Collaborating Goals apply the same status to dependent work;
released portions of a mixed system retain their own scope. Opening a gate requires a separate explicit decision.
