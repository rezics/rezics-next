# First public scope

Which user-facing systems the first public release contains, who owns each, and what is deferred. The evidence is
[the system inventory](research/system-inventory.md); systems built but not polished stay closed behind platform
grants until they are. An owner is the Goal that dispatches the system's work; collaborators own their own modules.

| System                                                                                    | Owner                                                                | First public scope                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Book library and hosted novels                                                            | content, web; semantic (bibliography), commerce (personal Library)   | In: the book library is the first product; book discovery/catalogue, personal Library, complete books and hosted-novel management, publication and reading are required at launch. Release requires both [Content native API acceptance](goals/content.md#acceptance) and [Web mounted author/reader acceptance](goals/web.md#acceptance).                                                                                                                |
| Subject pages, relations, editions and credits                                            | web                                                                  | In ([subject pages](subject-pages.md))                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Catalogue, editorial contributions, identity resolution, definitions and vertical editors | semantic                                                             | In: existing released catalogue profiles, common editors and ordinary contributions/readers; custom catalogue publication, advanced identity mutation, reviewed vocabulary seeds and measured-input expansion stay closed behind explicit platform grants until polished                                                                                                                                                                                  |
| Provider imports and bridges                                                              | imports                                                              | In: Bangumi, VNDB, Open Library and Wikidata. Recipes enter through definitions, the editor and contributions (dishes from Wikidata where licensed); no recipe-site import, since method text is copyrighted                                                                                                                                                                                                                                              |
| Search, facets and discovery                                                              | search                                                               | In: current Book/Series/Edition discovery required by the first product. Other Search remains closed behind existing grants; advanced facets, scopes and rating sorts are in the second scope. Release still requires native privacy, physical, erasure and growth evidence.                                                                                                                                                                               |
| Library, Collections, progress and copies                                                 | commerce (kernel), web                                               | In ([library and Collections](library-and-collections.md)): profiles, labels, curated and built-in dynamic Collections; user-saved dynamic queries and importing a person's own list from VNDB, Bangumi, MyAnimeList and AniList exports (with export of their Library) are in the second scope                                                                                                                                                           |
| Ratings and reviews                                                                       | content                                                              | In; content publishes the bounded public aggregate of the Global standard question (privacy threshold, Bayesian prior from the same question and population) that search sorts by; Realm rating sorts are in the second scope, private Realm figures never enter the public index                                                                                                                                                                         |
| Posts, threads and boards                                                                 | content                                                              | In; pins, slow mode, watch, public Collections/reviews/Spaces in discovery and a moderator workbench are in the second scope. | Subject-connected knowledge workspaces                                                    | content (coordination), semantic, accounts, search, web, performance | In: [first-public knowledge loop](knowledge-workspaces.md#release-priorities), including private nested documents, shared Subject attachments, viewer-aware composition and selected public revisions with exact reuse. Opening requires the [native and browser acceptance](knowledge-workspaces-acceptance.md); the design is not shipped capability. |

| Agents and public profiles                                                                | accounts                                                             | In (one agent, one page)                                                                                                                                                                                                                                                                                                                                                                                                                                  |

A system that is In has an owner who keeps its contract in its owning document and dispatches its work; a deferred
system gets an owner when it is scheduled. Change this table when the scope changes.
