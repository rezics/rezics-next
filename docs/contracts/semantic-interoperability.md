# Source graphs and portable semantic exchange

The [Source reification profile](../../model/definitions/source-reification-v1.ts)
and [export residual schema](../../services/main/src/modules/export/schema.ts)
carry the selected first-stage mapping. Full-source indexing and portable
exchange still need separate profiles and qualification; the present Open Library
title/description projection does not certify them.

## Unqualified source surfaces

Preserve external IRIs, source-scoped blank nodes, datatypes/languages, graph
structure, ordering, statements and acquisition coverage. Raw bytes support
recovery but cannot substitute for queryable preservation. Native correspondence
requires explicit evidence; redirects or equal labels cannot transfer control.

Qualified JSON-LD is the initial syntax path. Runs need frozen context
bytes/options, original evidence and counterexamples for multiple types,
lists/sets, repeated occurrences, nested IDs, JSON literals and missing fields.
Microdata and RDFa require separate qualifications. Recipe ingredient text
cannot acquire invented units; external editions, media relationships and
software versions cannot inherit native grain or comparator semantics by name.

Wikibase full statements require identity, qualifiers, references, rank,
somevalue/novalue, precise time/calendar and quantity/unit, coordinates,
external IDs and language values. Truthy dumps cannot qualify those surfaces.
Lexemes, forms and senses need elected profiles. RDF-star/RDF 1.2 syntax needs
separate parser and export qualification; unaccepted or hypothetical source
claims must never become asserted native edges. RDF 1.1 identified claims and
explicit Assertion resources are the baseline; export only supported meaning.

## Unqualified exchange and updates

Source queries retain namespace and coverage. Withdrawal must invalidate mapped
support without overriding human decisions. Cross-source union requires explicit
context and trust boundaries.
Export must pin source/native selection and disclosure and preserve blank-node
scope or an explicit deterministic skolemization policy.

Qualified native claims need their speaker, exact DefinitionRefs, Context
semantic revision, applicability and separate acceptance basis. Local meaning
cannot become an unconditional Global triple; hidden dependencies must stay
private. An unsupported recipient needs a concrete residual, including when a
named narrower concept and simultaneous local interpretations cannot round-trip.
The [live source qualifications](../testing/source-conformance.md) remain scoped
to their actual provider, surface and selected fixture.
