# Names, identifiers and editorial authority

## Name and identifier records

Names have stable occurrences, role, language/direction, provenance, validity and
revision. Preserve aliases, credited names and transliterations independently.
Identifiers include scheme/provider/namespace, grain and source evidence; equal
strings in different registries are not equal identities. A checksum identifies
bytes only under its algorithm and coverage.

## Selection and control

Human-edited, source-supported and Realm-selected names can coexist. A same-value
human confirmation advances editorial control and prevents later source jobs from
silently taking over. Source deletion retracts only its support. Public display
selects eligible names under explicit context/language policy and returns provenance.

Updates use expected field/selection revision, source observation and human-control
epoch. Source proposals cannot manufacture account control, licenses or unrelated
native identities. Concurrent editorial/source changes return conflict or staged
review instead of last-writer-wins. Search aliases remain attributed and scoped.

## Implementation and acceptance

Store identified records and decisions in Jena; history anchors preserve exact
forms. Maintain root-local searchable name projections and bounded reverse
dependencies. Do not rerank or hash an entire high-degree name set on each change.
Test identical text from different sources, human takeover, multilingual fallback,
withdrawal/reapply, private aliases and exact exported identifiers.
