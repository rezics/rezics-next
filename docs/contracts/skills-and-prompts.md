# Hub content rollout gaps

The current [Hub owner](../../services/main/src/modules/hub/store.ts) admits inert
Agent Skills directory imports and exact Prompt revisions. Requirement sidecars
and bounded dependency locks have [executable cases](../../scripts/qa/cases/ai-hub.ts).

The selected Hub capability still needs native Skill and Prompt contribution,
review, release, publication, download and export flows. Releases and downloads
must pin artifact integrity, license and provenance. Repository-package imports
need an explicit profile that preserves unsupported fields and residuals; an
arbitrary folder does not become a valid Skill by normalization.

MCP software/project identity, package release, deployment endpoint and observed
server capability are different resources. Endpoint reachability cannot prove
ownership, compatibility or invocation permission; observations need their own
time and schema revisions. [Connected apps](connected-apps.md) govern current
consent and schema drift. Untrusted execution and persistent hosting retain their
separate [admission decision](../research/ai-hub-execution.md).

## Open agent contribution protocol

Decision 24, product manager under maintainer delegation, 2026-09-29;
third-party compute and the first advertisement/spam reviewer are maintainer
choices. Official and third-party agents use the same proposals: exact targets
and expected revisions, changes, evidence selectors, coverage and rights, method,
asserted confidence and disclosure. Review binds the candidate, application
returns receipts, and reversal compensates rather than rewriting history.

Agent, AI configuration, assignment and run stay distinct. Credentials are scoped,
budgets belong to the operator and trust is task/language-specific. Durable event
reads with resumable SSE and checkpointed tasks with approvals support long work.
[Wikidata's bot policy](https://www.wikidata.org/wiki/Wikidata:Bots) motivates
declared tasks, trial edits and sources; [MCP](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization)
supplies interoperability, not a catalogue-review policy.

Third parties bring compute through the API and `/mcp`. Official inference defaults
to $0 with an operator cap. The maintainer selected [TypeSafe's Jev](https://docs.typesafe.ai/models) for first-batch
advertisement/spam review, using typed confidence-aware results, evidence spans
and human override. The approximately $20/million-items figure is a planning
estimate to verify against the provider and local workload, not qualified cost.
The maintainer approved a funded cap of US$10 a month on 2026-09-30; when it is
reached, Jev pauses and review falls back to people until the next month.
Tests and development never call Jev: they use a deterministic fake classifier
with controllable verdicts and no network, and only production uses the paid
model. A dedicated, vendor-neutral grant, "bypass automated content screening",
lets trusted editors, official bulk imports (the older site's records, admitted
dumps) and test principals skip the classifier (maintainer, 2026-09-30). It is
granted explicitly per person or agent and per operation class, never implied
by an administrator role, recorded on every receipt that used it, and revocable;
rate limits, reports and later review still apply.

Other first-batch agents propose post/book tags against shared vocabulary,
maintain entity relations, normalize free-form posts into structured content such
as recipes (video later), and assist library migration. Next comes the
[sourced wiki builder](information-verification.md#a-big-franchise-wiki-for-every-work),
then taste memory and a spoiler-safe reading companion. Human review, permissions
and evidence apply equally to every producer; none fabricates community activity.

## AI speed through open interfaces

Decision 38, maintainer, 2026-09-29. People who hold novels or VN scripts run
their own agents to analyze them. REZICS supplies evidence contracts, review and
publication rather than the compute. This keeps rights and compute custody with
the holder while accepting interoperable contributions. The shared protocol above
and [W3C Annotation selectors](https://www.w3.org/TR/annotation-model/#selectors)
provide the evidence boundary; possession alone is not publication permission.
