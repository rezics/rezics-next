# Catalog grain still to qualify

The first product spans books, software, media, recipes, Skills and Prompts
under provider-independent Work/Main Version and source-free authoring. Its
existing [native Work contract](work-and-release.md) and
[source conformance](../testing/source-conformance.md) carry implemented cases.

The remaining cross-domain profile must keep composition, recording, release,
medium and repeated track/episode/ingredient occurrences distinct from Work and
Main Version. A contextual credit must bind performer, character and Work in one
occurrence; joining independent credits cannot manufacture that fact. Provider
labels never become native identity keys, and a redirect cannot silently change
Main Version or Realm selection. Elected source fields need explicit native,
source-only, lossy, excluded or unsupported dispositions with reasons and exact
coverage. These obligations require owner profiles and conformance fixtures
before this page can retire.
