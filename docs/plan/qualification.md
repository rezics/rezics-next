# Recorded qualification

`yarn qa --record` generates this page from the latest full [harness](../testing/test-harness.md)
run on a clean tree. Do not edit it by hand. Each row gives an acceptance ID, its
status (`pass`, `fail` or `uncovered`), the tests carrying it, and the run ID and
commit.

No harness run has been recorded yet. Scoped results from before the harness are
summarized in the [plan's implemented baseline](README.md#implemented-baseline).
