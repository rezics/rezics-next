# Semantic audit gap journeys

The three audits describe different source snapshots. This plan binds their Semantic responsibilities to retained
source `683638d2c18047d3f389f25c68dda8dba9738dd5`, checks the actual Goal task registry and `git log dev`, and
distinguishes delivered consumers from the native definitions they still cannot admit. Integrated means source work
exists; it does not assert native, browser, growth or promoted acceptance. The audits remain unchanged.

The premise that every backlog is empty and all workers idle does not hold: the registry contains running, held,
ready and integrated tasks. No live definition-publication task covers the missing meanings below. Existing Web and
Imports work explicitly consumes published bindings and leaves missing Semantic configuration unavailable. Seven
continuations fill those native gaps without dispatching another copy of those consumers.

Decision: journey sizes of 2,000–3,000 lines are implementation estimates, and missing released meanings extend the
existing bounded page composition and consumers under current grants; music personal profiles remain Commerce-owned.
The [Semantic Goal](../goals/semantic.md#audit-gap-journeys) owns that decision. Estimates include focused tests and
generated release/locale changes, never a requirement to pad code or write thousands of lines of instructions.
