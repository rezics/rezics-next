# Public community converter caller

The ordinary journey is one acquired metadata record, the selected public pure
converter and its exported revision, a caller-owned authorized public bulk
transport, a returned create identity, and reconversion into bound proposals.
[`public-bulk.ts`](../../../packages/conversion/examples/public-bulk.ts) supplies
this reusable example without importing the platform importer. It adds no package
subpath, schema, registration service, journal or retry mechanism.

## Decisions and limits

Source kind selects a closed pair of actual public export/revision inside the
example; the optional registration alias is separate trusted caller input. The
native journey explicitly uses `openlibrary`, while the converter's unsupplied
default alias remains `open-library`. Source-body registration, revision, target
and media bindings cannot override those choices. Create result validation uses
the existing public bulk result checker, a single exact key, successful status
and returned UUID before any bound send. `submitted` describes transport delivery;
callers must inspect proposal results and own any editorial workflow.

This is metadata-only evidence. It excludes media acquisition/rights, nonzero
statistics, source disappearance/reconciliation, refresh, durable caller
recovery, discovery publication and the six consumer surfaces. Existing rights,
tuple fences, permissions, source isolation, source/converter identity bounds and
mass-disappearance rules remain authoritative. No deferred metadata producer,
vocabulary seed or recipe-site/user-post import is introduced.

The journey touches only supplied bounded bytes and exact source, receipt,
subject and candidate keys. Existing local counted ceilings and canonical/derived
PostgreSQL suites remain unchanged. It adds no growth series or replacement
counters. Native growth evidence is missing; no zero-block or synthetic count is
reported. No external reference implementation or legacy code was ported, and
no files outside the declared paths are required.
