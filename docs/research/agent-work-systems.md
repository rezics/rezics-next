# Agent work systems

The canonical [research report](../../tools/goal/research/agent-work-systems.md) compares established coding-agent
systems with the Goal control plane and ranks adoption experiments by useful work landed per allowance.

The report lives beside the product it studies, as required by its contract. This entry makes it discoverable in
the repository's research collection without duplicating the evidence. Recommendations remain proposals until
adopted in the owning control-plane documents.
