## Outcome

A commit that reached `main` stays in its history. On 2026-10-13 a manager's turn amended its commit on `main` seconds after making it; a task's branch being rebased in that moment kept the replaced commit, and its landing was refused for files it never touched. Managers, their turns and the tool all work in the main checkout, and landings rebase onto `main` at any moment, so a rewrite is never safe there.

- **The repository refuses it.** A git hook of the shared repository (the `reference-transaction` hook sees every update of a reference before it is made) refuses an update of `refs/heads/main` whose new commit does not contain the old one: an amend, a rebase, a reset to an older commit and a forced update all stop with one line that says a correction is a new commit. A fast-forward, a new commit and the tool's own landing pass. Every other reference, the task branches and the archive branch included, is untouched.
- **It is installed by a command** (`task goal -- main-guard install`, a file in `scripts/goal/commands/`; `status` and `remove` beside it), into the common git directory, so that every worktree is covered. It leaves an existing hook of another purpose in place and runs beside it, and says so; it never replaces one silently. The handoff names the one place where the tool should call `install` by itself (another task holds those files).
- **The cost is nothing a commit notices:** the hook answers in a few milliseconds for a reference that is not `main`, and for `main` reads only the two commits.

Do not build: a hook for anything but this, a change to how the tool lands, a guard against a push, a server-side rule, a change to a file of `scripts/goal/` you do not own.

none

## Checks

`task goal -- check`, and the test file once with `CLAUDECODE=1`. The tests use a temporary repository with a second worktree and cover: an amend, a rebase, a hard reset and a forced branch update on `main` refused from each worktree with the line; a new commit and a fast-forward merge accepted; a task branch rebased freely; an existing hook kept and still run; install twice, status, remove. Do not install it in the real repository: the supermanager does that after the landing. Wait on a running command with one long call (`yield_time_ms: 300000`).
