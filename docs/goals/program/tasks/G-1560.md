## Outcome

On 2026-10-09 the host had 107 containers. 20 compose projects were leaked:
- 16 `rezics-qa-classification-*` (created by `classification-restore.test.ts`
  through `qaStack()` in `tests/qa/fault-recovery/search-ops-support.ts`);
- `metadata-restore`, `g727-target`, a fixture stack and a held-HTTP container;
- some up to 2 days old.

QA runs were OOM-killed. None of them carried the reap-owner label, so
`sweepOrphanContainers` never saw them ("Unlabelled containers are never
listed"). `qaStack` starts a `--persistent` project under a random run id, its
`finally` only runs `stack:reset`, and its compose calls use
`loadDockerEnvironment()`, which bypasses the reap path.

1. **One owner rule.** Every container a QA process or test creates carries the
   reap-owner label, whichever helper starts it. Find where the label is
   applied (the docker shim on `PATH`, `REZICS_REAP_*`), and make the
   environment builders (`loadDockerEnvironment`, `composeProcessEnvironment`)
   keep it instead of dropping it. Do not make each test opt in.
2. **Teardown.** A test-owned stack (`qaStack`, the metadata-restore stack) is
   brought down with its volumes when the test ends. If the test is killed,
   the sweep removes it because its owner is dead.
3. **Guard.** A static check fails any `docker` or `docker compose` spawn in
   `tests/`, `scripts/qa` or `services/*/tests` whose environment does not come
   from the owner-preserving builder. Existing exceptions go on an exact debt
   list (there are about 33 spawning files; convert the ones in `paths`).
4. **Admission.** Confirm memory admission never admits without a reading.
   "free unknown" appears on the wait line before a reading exists; show that
   the admit decision always has one. Add a test.

Acceptance:
- A unit test: a stack started through `qaStack` carries the owner label, and the sweep removes it after its owner process exits.
- A killed test leaves nothing behind (simulate with a short-lived owner).
- The guard catches a fixture that spawns `docker compose` with a bare environment.
