## Outcome

The import policy (decision 55): our imports publish what each source licenses. That covers Bangumi under CC BY-SA 3.0 (summaries included), VNDB, Open Library and Project Gutenberg public-domain recipes. Covers are credited to their rights holder, with a takedown path. User posts are never imported. Before public launch, prove a visitor sees this correctly everywhere imported content appears:

1. **Attribution is visible.** Every Work hub, catalogue card where it applies, Recipe page and cover shows the source, the licence (with its link) and the credit the licence requires, in every UI language.
2. **Share-alike is honoured.** CC BY-SA text keeps its licence wherever we redistribute it, including API answers and exports.
3. **Takedown works.** A rights holder can report a cover or a text through the public report intake, an operator can act on it, and the item stops being served everywhere, including caches and exports, with the decision audited.
4. **No user content from a source** appears among imported records.

Write API outcome tests and one browser journey for these. Fix every gap in the product, the importer or the pages.
