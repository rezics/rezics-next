## Outcome

A change that leaves a cell of the scope without its registered proof cannot land. On 2026-10-13 at 19:23 UTC a landing registered the pending owner proof of `zone/site-pages` with a plain `test(outcomeTitle(row, 'owner'), …)` where the reader of declarations (`loadOutcomes`, `scripts/qa/cases/outcomes.ts`) knows a proof only through `outcomeTest`. For 25 minutes `status`, `scope`, the admission of every brief and every surface gate stopped with "Missing outcome test title for zone/site-pages / owner", in three Goals. Nothing refused the landing, because the file that guards declarations was already red on `main`, and a gate does not charge a task with a failure `main` has.

1. **The guard file is green on `main`.** `scripts/qa/cases/outcomes.test.ts`, test "declarations and outcomeTest reach only loader-free cells during integration planning", fails since about 13:15 UTC that day: its fixture copies `tests/qa/support/outcome-test.ts`, which since then imports `scripts/api/answer-record.ts`, and the fixture does not hold it ("Cannot resolve local integration import"). Repair the test so that it still proves what its name says about the real helper, not about a stub of it; if the helper's new import is itself what the test exists to forbid (a loader reached during integration planning), do not bend the test: hand off `partial` with that finding in three lines.
2. **The real tree is read.** A test in this file loads the repository's own declarations exactly as the tool does and fails with the tool's message when any cell, proved or pending, has no `outcomeTest` registration, when a title is registered twice, or when a declaration does not load. Show in the handoff, by mutation and not checked in, that it fails on the plain-test form above and names the row, the persona and the file.
3. **It is run when it matters.** Show the output of `task test -- --affected --list` for a change to one file under `tests/qa/integration/outcomes/`, one under `scripts/qa/cases/outcomes/` and `tests/qa/support/outcome-test.ts`: this file is in each plan. If it is not, say which selection rule leaves it out and where that rule lives; change nothing outside this file.
4. The handoff gives the file's run three times in a row and its seconds.

Do not build: a change to the reader, to `outcomeTest`, to any outcome test or declaration, a new form of registering a proof.
