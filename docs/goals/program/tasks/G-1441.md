## Outcome

The coordinator (`scripts/goal/coordinator.ts`) wakes an enrolled manager
whenever it has unread mail or a task exit. It enrolls Codex managers only. On
2026-10-08, Codex ran out, so kernel and trust-ops moved to interactive Claude
sessions and the coordinator was disabled. From then on, a manager woke only
if it had armed its own watcher. Program and kernel each sat idle for hours.

Add a Claude engine so that any Claude manager can be enrolled the same way:
- `coordinator enroll <goal> --engine claude --model <id> --effort <level> --session <uuid> --cwd <dir>`.
  This uses the same explicit handover as Codex.
- A wake runs one finite headless turn:
  `claude -p --resume <session> --model <id> --effort <level> --dangerously-skip-permissions --output-format json -- <wake prompt>`,
  run in the manager's cwd. It keeps the existing single flight, the attempt
  record written before launch, the independent tmux server, and restart
  reconciliation.
- **Native session check:** `~/.claude/projects/<cwd with / as ->/<session>.jsonl`
  exists, and its `cwd` matches.
- **Ownership:** a wake is refused while a live process holds the session.
  That is a claude process whose child shells carry
  `CLAUDE_CODE_SESSION_ID=<session>`, or one whose argv resumes it. A worker
  that inherited the manager's variables (it has `GOAL_TASK_ID`) is not the
  owner.
- **Admission:** reuse goalctl's Claude usage gate. A `restricted` level
  defers the wake, as Codex does.
- **Wake prompt:** lists the events, and tells the manager to end its turn
  when done. The coordinator wakes it on the next event, so it arms no
  watchers.

## Checks

Unit tests with a stub launcher:
- The Claude descriptor's argv.
- A live owner blocks the wake.
- An inherited worker does not block it.
- A coordinator restart after the intent is recorded does not launch twice.

Run `task goal -- test scripts/goal/coordinator.test.ts scripts/goal/goalctl.test.ts`
and `task dev:typecheck`.

Verify on real state with a scratch Claude session in a scratch cwd, never a
live manager:
1. Enroll the session, then mail its Goal address.
2. A headless turn starts and its reply appears in the run output.
3. Kill the coordinator mid-turn and restart it. No second turn starts.

Put the commands and their output in the handoff.
