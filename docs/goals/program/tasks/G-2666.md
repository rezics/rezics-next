## Outcome

Reddit's checks and actions and Discourse's trust progression remove repeated moderator work. Manual rules and cases cannot route a flagged post automatically or lift a narrowly defined newcomer limit. The report calls this an operator-retention gap. Keep the first cut to bounded, auditable and reversible actions through existing moderation commands, with the durable-job machinery shared with Scheduled (`docs/architecture/scheduled-plans.md`).

Write `docs/architecture/community-automation.md` as a proposal for program review. Base it on the report's row **B07** (`.temp/ref/competitor-coverage.md`): the missing job, the smallest engine-level capability and its reuse, and the falsifying scenario.

1. Read the existing owners first. Decide what is reused, what is added and why. Reuse existing vocabularies before adding local terms.
2. Make every read, sweep and command touch a bounded neighbourhood.
3. Write the per-persona authority matrix and the falsifier as an API observation table.

Follow the form of `docs/architecture/actionable-collections.md` and `docs/architecture/scheduled-plans.md`. Write no contracts, rows or code in this step. The note lands as a proposal; program reviews it before any contract step.
