## Outcome

`recordedFileDurations(artifactRoots(root), tier)` in `scripts/qa/core.ts` estimates each file's duration from the latest runs under `artifactRoots`. Those roots are the checkout's `.artifacts/qa`, the main checkout's and every Goal worktree's.

Regression runs are the only runs that measure every file, but since the regression evidence moved into the run directory they write to `.temp/goal-orchestration/regress/<run>/qa/<batch>/<qaRun>`, which no root covers. Before that move they wrote into regression checkouts, also not covered. So integration planning (now at 60% headroom) estimates most files from a fallback median.

1. `artifactRoots` (or the one caller that needs it, if only estimation should read them) also includes the regression run directories' per-batch QA roots under the main checkout, `.temp/goal-orchestration/regress/*/qa/*`. That layout comes from `scripts/goal/regress.ts`, so read it there, not from a second copy of the pattern.
2. Keep `recordedFileDurations`' existing rule (latest runs, the given number of observations per file). The extra roots only add observations. Do not let many regression roots make one estimate take seconds: bound the run directories read, as `maxRuns` already does.
