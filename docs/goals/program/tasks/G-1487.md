(`.temp/goal-orchestration/regress/20261008t151155-f007cc/manifest.json`, main
a5de93040, still running) has 62 of the first 73 integration batches failing.

are in `<artifact>/logs/`. Run 4
(`.temp/goal-orchestration/regress/20261007t210455-f9d432`, main a278665c5) is

2. **Cluster the rest by error signature.** Examples so far:

   - "change would break Agent control continuity";
   - "Expected persistent, received tmpfs".

   representative file only when that comparison can't decide. Re-run a file
