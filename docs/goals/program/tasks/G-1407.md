## Outcome

About 42 test and fixture files start containers with `spawnSync('docker',
['run', '--rm', ...])`. When a run times out, the gate (`stopProcessGroup` in
`goalctl.ts`) or the QA runner kills the test process group. That kills the
`docker` client, but not the container, which belongs to dockerd. On
2026-10-07 a timed-out native gate left Maven running in its container until
kernel removed it by hand. Fix the class without touching the callers:

1. **Shim.** `scripts/qa/docker-shim/docker` is a small executable script. For
   `docker run`, `docker create`, `docker container run` and
   `docker container create`, it inserts
   `--label rezics.reap-owner=<value of REZICS_REAP_OWNER>` when that
   variable is set, then execs the real Docker. The QA runner passes the real
   binary's absolute path in `REZICS_REAL_DOCKER`. Every other subcommand
   passes through unchanged, including `compose`.
2. **Runner.** Before starting test processes, the QA runner (`scripts/qa/core.ts`):
   - puts the shim directory first on their `PATH`;
   - sets `REZICS_REAP_OWNER` to its own `<pid>:<start time>`, where the start
     time is field 22 of `/proc/<pid>/stat`, so a reused PID never matches;
   - keeps the value it inherits, if one is set.
   On exit, including timeout and signal paths, it removes the containers that
   carry its own label.
3. **Sweep.** `scripts/qa/container-reaper.ts` exports `sweepOrphanContainers()`.
   It removes (`docker rm -f`) every container whose `rezics.reap-owner` process
   no longer exists, or exists with a different start time. Call it:
   - at QA runner start;
   - in `goalctl` right after `stopProcessGroup` kills a gate shard.
   It never touches containers without the label, such as the shared dev stack
   or QA stacks managed by compose.

## Checks

In `tests/qa/unit/container-reaper.test.ts`, with a stub `docker`:
- The shim adds the label only on run and create.
- The sweep removes dead-owner and reused-PID containers, keeps live-owner ones,
  and never lists unlabelled ones.
- The runner sets and inherits the owner value.

Then a real check: a throwaway test runs `docker run --rm alpine sleep 600`
under `task goal -- test` with a short timeout. After the run times out, no
labelled container remains (`docker ps --filter label=rezics.reap-owner`).
Run `task goal -- test tests/qa/unit/container-reaper.test.ts scripts/goal/goalctl.test.ts`
and `task dev:typecheck`.
