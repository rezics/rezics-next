## Outcome

A shared owner does its job without recognising a vertical or a source (`docs/product/platform-thesis.md`; `docs/architecture/shared-capabilities.md`, Discovery, exchange and release, first paragraph). The audit evidence is in `.temp/ref/` (report-3.md).

Phrase search reaches a Work from Content only through Book chapter placement. The web discovery page has its own type list of book, document and recipe. The year directory intersects with a ten-page Realm roster. Make search use profile-declared searchable placements, preserving multiple placements; make discovery read the served type registry and store type IRIs; make the year directory pass Realm and conditions to the publication-year query and hydrate its returned IDs.

Likely files: `services/main/src/modules/{post/patterns,work/search-public,content-publication/search,collection/dynamic}.ts`, `apps/web/features/discover/state.ts`, `apps/web/features/zones/{catalogue-browse.tsx,catalogue-facts.ts}`, `apps/web/features/search/types.ts`.

Prove it with a test that fails before and passes after, on the real composition (`composeMain`), using a consumer other than the original one. Preserve exact versions, order, unknown authorship, truthful credit, rights evidence, private, refused and revoked states, idempotent recovery and bounded cost. Do not add a second engine, a framework or a per-vertical replacement, and do not move or rename a special case. Keep provider parsing and domain arithmetic in adapters. When the repair lands, remove its paragraph from `docs/architecture/shared-capabilities.md` in the same change, or narrow it to what remains.
