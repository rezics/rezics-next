## Outcome

The record of `zone/navigation-and-theme` holds the owner's publication (`publish-site-bundle`, 201) but not the save that made the draft it publishes: the row's test saves the home document with `POST /v1/content-drafts` as preparation, outside the record. The web Goal's home editor replays the record, so its save and its save on leaving find no answer, and the saved revision cannot be followed into the publication.

1. The owner's saves of the home document that lead to the published draft are recorded as samples, each under its own label, with the body the test already sends: the first save (`expectedHead: null`) and, where the test saves again over it, that save with the head it names. The chain must hold inside the record: the `resourceId` is the Zone's `homeDocument` as its configuration answers it, and the revision the recorded save answers is the one `publish-site-bundle` names. Assert that in the test.
2. Read `browserZoneAuthoring` in `apps/web/features/zone-editor/api.ts` (read only; change nothing there). For each request it sends that the owner's record lacks (the read of the saved draft, the read of the heads), record it once as the client spells it, after the save and before the publication. A request the recorder refuses is listed in the handoff with the refusal, not worked around.
3. No existing sample's label or request changes, no other assertion changes, no cell changes state. Never write an answer by hand: run the row's test so that it records, and check in the record it writes. Identities are this run's.
4. `scripts/api/answer-records.guard.test.ts` passes. The handoff lists the samples added (label, method, path, status) and the recording run's seconds.

An answer of 500 or above inside a proof is handed off, never recorded. If the recording run fails on a 503 or a timeout alone, run it once more when the host's one-minute load is below 64 (`cat /proc/loadavg`); then hand off `partial` with the request, the answer, the load and the log path.

Do not build: a change under `apps/` or `services/`, a change to the recorder, the record's format or the guard, another row's record.
