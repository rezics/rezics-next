## Outcome

A shadowed variable in `scripts/fixture/prune.ts` made every apply throw, and it
passed every check. Each script directory has its own tsconfig and task, or
none:
- `goal:typecheck` covers `scripts/goal/*.ts` and its imports.
- `dev:typecheck` and `observability-scripts:typecheck` cover their own directories.
- `scripts/load/tsconfig.json` is run by no task.
- `scripts/fixture`, `scripts/static`, `scripts/package`, `scripts/ops` and others are checked only when something else imports them.

A probe tsconfig over `scripts/**/*.ts` (excluding `scripts/datasets`, which has its own) reports 28 errors: `scripts/package` 13, `scripts/static` 7, `scripts/qa` 7, `scripts/api` 1. The probe is `.temp/goal-program/tsconfig.scripts-probe.json` on main's checkout; it is copied to `.temp/ref/` in your worktree.

1. One `scripts/tsconfig.json` covers every `scripts/**/*.ts` except `scripts/datasets`, and one `scripts:typecheck` task runs it under host admission, measuring the `--gib` the way the Taskfile comment says. `goal:typecheck`, `dev:typecheck` and `observability-scripts:typecheck` either become that task or are removed along with their tsconfig. Pick the one that leaves a single definition, and update every caller you find with `git grep`. A directory that genuinely needs different compiler options keeps its own tsconfig; say which one and why.
2. Fix the 28 errors at their cause. Use no `any` casts or `@ts-expect-error` unless the error is in a third-party type, and name it if so.
3. When a file under `scripts/` changes, the affected plan (`task test -- --affected --list`) includes `scripts:typecheck`. Find where the plan chooses typecheck tasks and add the mapping there.
4. Record the change in `docs/development/toolchain.md` if it lists typecheck tasks.

- `oxlint --type-aware` on the changed files.
