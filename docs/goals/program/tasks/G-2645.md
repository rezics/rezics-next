## Outcome

Improvement 5 of the API audit (G-2640; report in `.temp/ref/audit.md`, section 7). Today:

- the inferred `MainApp` display exceeds 1.17 MB;
- declaration emit hits TS7056 and TS4058;
- the web workspace instantiates 31.5 million types;
- app-only compilation accounts for nearly all of the Eden fixture's instantiations.

G-2640 committed measuring scripts (`a2c69dfd3`, `e6aea825a`).

Turn the measurement into a gate:

- a reproducible baseline of instantiation counts, check time and inferred-type size for Main, web and the Eden fixture, recorded in the repository;
- a check, run by `task goal -- check` when API or Eden files change, that fails when any of them grows past the baseline by a stated margin;
- the existing 30-second Eden gate retained.

This lets the coming refactors (typed returns, domain errors, contract separation) prove they shrink the graph rather than claim it. Do not change the API in this task.

## Checks

The gate passing at the baseline, failing on a planted inflation, and `task goal -- check`.
