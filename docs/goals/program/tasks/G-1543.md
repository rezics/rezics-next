## Outcome

Read `.temp/ref/G-1522.md`, finding 16.

`knip.jsonc` declares every `scripts/**/*.ts` file an entry, so Knip can never
report an unused script or helper. A clean Knip run proves nothing for `scripts/`.

1. Derive the script entries from what really launches them: `Taskfile.yml`
   commands, `package.json` scripts, `bun <path>` and `spawn` calls, and files
   discovered by directory scan (fixtures, generators, `*-child.ts`). Each
   dynamic discovery is declared once, with the code that discovers it. Feed the
   derived list to Knip from `scripts/static/knip.ts`; `knip.jsonc` keeps no
   `scripts/**/*.ts` wildcard.
2. Run it and list what it now reports as unused. Delete a script only when
   nothing in the repository (code, Taskfile, docs, tests) names it; list the
   rest in the handoff with what still names them. Do not delete anything under
   another Goal's claim (`goalctl owner`).

Acceptance:
- A unit test with a fixture tree: a disconnected helper is reported, a
  Taskfile-launched script and a declared directory-scan file are not.
- `task knip` (or the repository's Knip task) passes on main after the deletions.
