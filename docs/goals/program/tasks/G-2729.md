## Design note

Writers: none. Readers: every reader whose continuation carries a read basis, starting with the recipe page reader and the shared `WorkReadMoved` owners. Each basis covers only what its reader is admitted to see, so hidden drafts and private changes neither restart nor reveal anything; a visible change still restarts the read.

Proof: a visitor pages a published recipe while another Person's private draft changes, without a restart; a visible edit restarts it; a second reader proves the same rule.
