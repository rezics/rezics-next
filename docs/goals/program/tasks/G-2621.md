## Outcome

Audit every production page against WCAG 2.2 AA, at phone and desktop widths, in English and Japanese:

- run axe on every recorded story and on each browser journey's pages (`apps/web/tests/a11y.e2e.ts` shows the existing pattern);
- check keyboard-only operation of each interactive flow: focus order, visible focus, no traps, and skip links;
- check screen-reader names, roles and live regions for dynamic results and errors;
- check reduced motion.

Fix each violation in the page or the shared component that causes it, using the design system's tokens; text-bearing colour uses the ink blue, never the brand red. Turn the axe sweep into a gate test that fails on a new serious or critical violation in any recorded story. Hand off the violations found and fixed, per page.

none

## Checks

The new gate test passing, the journeys passing, and `task goal -- check`.
