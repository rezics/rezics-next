## Outcome

Close three findings from the security review that let an anonymous or forged caller cost the platform without bound:

1. Anonymous requests can grow a counter table without bound.
2. A forged token with an unknown key triggers a key exchange.
3. An original image has no total-pixel limit, so a small file can decode into a very large bitmap.

The findings come from `docs/goals/api/later.md`; detail and file positions are in the archived end-of-run tables (`archive/goals:program-2026-10-06/study-2026-10-12/end-of-run/`; read them with `git show archive/goals:<path>`). Check each finding against wave/3 first, since some may already be fixed. Say so with evidence and move on.

Fix each at its cause:

- **Counters:** bound them by principal class, with expiry or keying that an anonymous caller cannot multiply.
- **Tokens:** refuse an unknown key without outbound work, or rate-limit the exchange per key.
- **Images:** cap total pixels before decoding, with a typed refusal.

Add a test per finding that demonstrates the bound under hostile input.
