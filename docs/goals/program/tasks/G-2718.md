## Outcome

In every outcome confirmation on 2026-10-16, the Realm ranking row's six cells did not run. In confirmation `confirm-20261016t102527-0f8d88`, Realm discussion source preparation failed at bootstrap with `Catalogue backups must stay in this checkout .temp` (`scripts/load/catalogue-backup.ts`, `privateDirectory`). The log is `.temp/ref/realm-source.log`. The same row passes in worktree runs (G-2711, G-2585), so the fault is in how the source names its backup directory when the confirmation runs from its own checkout under `~/.cache/rezics-r/`.

Make the Realm source write its catalogue backups inside the checkout that runs it, as every other retained source does, and keep the guard: a backup outside the running checkout's `.temp` is still refused. Reuse the retained source machinery other rows use in confirmations rather than adding a special case.
