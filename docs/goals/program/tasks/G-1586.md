## Outcome

`scripts/goal/regress.ts` adds a git worktree under `~/.cache/rezics-r/<repo key>/` for the pinned commit and for every bisect probe, and installs dependencies in each. Nothing removes them.
- 507 checkouts of about 2 GB each have accumulated since 10-07, and `git worktree list` shows 547 entries.
- The disk is at 77%.
- The class: a run's own checkouts outlive the run.

They cannot simply be deleted today. A run's evidence lives inside them: QA artifacts go to `<checkout>/.artifacts/qa/<id>` and preflight logs to `<checkout>/.temp/regress-preflight`, and the manifest, its diagnoses and the routed inbox entries all point there.

(Amended at review. The first version asked to keep checkouts of any non-terminal run. That kept all of them, because interrupted runs never become terminal, and the abandon path added to work around it is not wanted.)

1. **Evidence in the run directory.** A regression run's evidence lives in its run directory, `.temp/goal-orchestration/regress/<run>/`, not in its checkouts.
   - The QA CLI accepts an artifact-directory override (one env variable, read where `scripts/qa/cli.ts` builds `<root>/.artifacts/qa/<runId>`), and `artifactRoots` in `scripts/qa/core.ts` includes it.
   - regress points it at `<runDir>/qa`. Preflight logs go to `<runDir>/preflight`.
   - Manifest and inbox paths name these locations.
2. **Checkouts are disposable.**
   - When a run ends, finished or failed, it removes the checkouts its `checkouts.json` maps, using `git worktree remove --force` then `git worktree prune`.
   - A non-live run's checkouts may be removed, because `--resume` recreates missing checkouts as it does today. Live means the run lock has a live holder.
3. **Prune** is an exported `pruneRegressionCheckouts({ apply })`, a dry run by default. It removes registered worktrees of this repository under the cache root that no live run maps. While any run is live, it removes nothing that run could be creating: checkouts appear in git before they appear in the map, so with a live run, prune removes only paths that a non-live run's map names. Paths outside the cache root, and non-worktrees, are listed, never removed. For a checkout that still holds `.artifacts/qa` or `.temp/regress-preflight` from before this change, the dry run says "holds old evidence".
4. **No goalctl changes.** goalctl.ts is held by another task. Do not parse `--prune-checkouts` in regress args; Program calls the export with `bun -e`. Remove `abandonRegressionRuns` and the `abandonedAt` manifest state.

## Checks

- `scripts/goal/regress.test.ts` covers:
  - a finished and a failed run each remove exactly their mapped checkouts, and their evidence survives in the run directory;
  - a live run's mapped checkouts, and an unmapped worktree created during a live run, are kept;
  - a non-live run's checkouts are removed and recreated on `--resume`;
  - prune ignores paths outside the cache root and non-worktrees.
- `task scripts:typecheck`, plus `oxlint --type-aware` on the changed files.
- The dry run on this host, with counts in the handoff. Do not apply.
