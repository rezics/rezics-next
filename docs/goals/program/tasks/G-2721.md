## Outcome

In main's confirmation `confirm-20261016t115233-9f63f9`, six Realm outcome batches (36 cells) failed before running, with the harness class: `docker rm -f 3ef62a634157 … failed: Error response from daemon: removal of container 3ef62a634157 is already in progress` (`.temp/ref/realm-harness-runner.log`). Two cleanups of the same shared stack raced, and the loser failed every batch that shared it.

Make QA stack cleanup idempotent: a container that is already being removed, or is already gone, counts as removed, and cleanup waits until it is actually gone before reporting success. Any other removal error still fails. Find where two cleanups of one stack can start at once and keep it to one, if the cause is there.
