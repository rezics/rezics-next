## Outcome

Read `.temp/ref/G-1522.md`, finding 3.

Nine scripts grant themselves authority by writing `access.scope_gate`,
`access.representation` and `access.permission_grant` with their own SQL, about
fifteen copies with drifting rules (expiry, which gates must be open, whether a
missing principal is created). Access owns that state, and
`scripts/ops/bootstrap/platform-grant.ts` already shows the supported path: a
bootstrap through the API with no database connection.

1. Every script in `paths` obtains its authority through Access's own
   operations: over the API where the script already talks to a running stack,
   otherwise through the Access module's grant and representation operations.
   No script writes those tables. Keep each script's stricter preconditions
   (closed recovery or dispatch gates deny before any grant) and keep retries
   granting exactly the same authority.
2. If Access has no operation for an effect a script needs, add it to the Access
   module behind Access's normal checks, and list it in the handoff. Do not add a
   script-side helper that writes the tables.
3. Register `access-authority` in `scripts/static/mechanisms.ts` (owner
   `services/main/src/modules/access`, owned state the three tables plus
   `access.policy`) and make `scripts/static/mechanism-writers.ts` refuse writes
   to them from `scripts/`. Main modules outside Access that still write them
   (`work/maintainers.ts`, `proposal/access.ts`, `vote/access.ts`,
   `agent/provision.ts`, `public-report/store.ts`) go into a frozen debt list for
   their owner. Test fixtures stay out of scope for now; say so in one comment.

Acceptance:
- The seed, dataset bootstrap and web-auth bootstrap still produce the same grants
  (compare before/after rows in a test).
- A closed gate still refuses before any grant.
- The guard refuses a fixture script that inserts into `access.permission_grant`.

## Mechanisms

access-authority: new — Access owns grant, representation and gate state, but no mapped mechanism records it, so scripts rebuilt it nine times.
