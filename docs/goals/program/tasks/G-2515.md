## Outcome

A build task of a wave (docs/goals/wave.md) works on top of `wave/<n>`, but `task goal -- check` and `task goal -- resume` treat every worker branch as based on `main`:

- `prepareCheckTree` → `updateWorktree` (`scripts/goal/tree-currency.ts`) rebases a clean branch onto `main` whenever `main` has moved. On a wave branch, this replays every wave commit onto `main`. Of 91 checks in wave attempts from 06:00 to 08:30 UTC on 2026-10-14, 27 rebased the branch onto `main` (it then diverged from `wave/1`), and 25 hit conflicts and failed with "rebase undone" before checking anything. `resume.ts` calls the same function.
- `checkChangedFiles` (`scripts/goal/check.ts`) diffs against `merge-base HEAD main`. On a wave branch that is the whole wave, so each of about 30 builders lints, AST-scans and guard-tests the whole wave's diff instead of its own change. Type-aware lint over that diff peaked at 9.2 GiB in one worker, and the duplicated runs keep the host at its memory floor.

Make a branch that carries wave work follow its wave. A branch carries wave work when, for a local `wave/*` branch, `merge-base HEAD <wave>` is not an ancestor of `main`. For such a branch:

- `updateWorktree` brings it up to date with that wave branch, never with `main`: fast-forward or rebase onto the wave, and report "commits behind wave/1". `warnHarnessCurrency` compares against the same base.
- `checkChangedFiles` diffs against `merge-base HEAD <wave>`, so a check covers only the task's own change.

A branch with no wave work behaves exactly as today. Write one function that names the base, and use it in all three places. Tests in `scripts/goal/tree-currency.test.ts` and `scripts/goal/check.test.ts` build small repositories, as the existing tests there do:

- A wave branch behind `main`: not rebased onto `main`.
- A wave branch behind its wave: brought up to it.
- A non-wave branch: unchanged behaviour.
- A wave branch's changed files: only its own commits and edits.

## Checks

`task goal -- check` with the brief's tests. This lands on `main` through the usual gate. Program merges `main` into `wave/1` afterwards, and workers pick the fix up at their next rebase.
