## Outcome

Three small follow-ups, independent of each other. Reproduce each on main first. Skip any that no longer reproduces, and say so in the handoff.

1. Publication cancellation reports a rights refusal as `authority_denied`. Report it as the rights refusal the publication path already names (`rights-unavailable` in `services/main/src/modules/work/structured-publication.ts`), with the API's documented problem for it.
2. `task goal -- dispatch` with no argument fails with a bare `EISDIR`, and `dispatch G-2739` fails with `ENOENT` on `./G-2739`. Accept a task ID by resolving it to its brief under the Goal's tasks directory, and fail with a usage message when nothing is given.
3. Main and Accounts disable Bun's idle timeout (`idleTimeout: 0` in `services/main/src/app.ts` and `services/account/src/app.ts`), so a slow request can answer within its deadline. Bound it above the longest request deadline those services enforce, so idle client connections still close. Keep the slow-request tests in `services/main/tests/request-timeouts.test.ts` passing.
