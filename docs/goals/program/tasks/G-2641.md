## Outcome

The maintainer's report (`.temp/ref/report.md`) asks for typed domain errors that drive the HTTP status, OpenAPI and Eden types from one declaration, and for API contracts kept separate from handler implementations. Native mechanisms come first, with no new framework. This task is step 2: find out what our pinned versions can actually do. The sibling task audits the current code in parallel.

Pinned versions: `elysia` 2.0.0-beta.16, `@elysia/eden` 2.0.0-beta.5, `@elysia/openapi` 2.0.0-beta.4, TypeScript 7.0.2. Known limitation: `@elysia/openapi` overwrites authored `detail.responses` when a route has runtime response schemas (G-2586 added an overlay in `scripts/api/generate.ts`).

In a scratch app under `.temp/` using the repository's installed packages, prototype and measure:

1. **Typed domain errors:** an error class or `status(...)` declaration carrying a literal code, an RFC 9457 Problem body and a status. Does it flow to the route's response type, the OpenAPI per-status responses and the Eden client as a discriminable union with the code as a literal? Try the native facilities: `status()`, `error()`, custom error classes, `onError`, response schemas keyed by status, and models.
2. **Contract separate from handler:** declare an operation (path, params, body, per-status responses, auth and exposure metadata) in one module and implement it in another, using native composition: plugins, `.model()`, guards, macros and route options objects. Does the compiler check the handler against the declaration?
3. **Auth, exposure and rate limit as macros:** declared on the route, enforced at runtime, and visible in the contract.
4. **Cost:** `tsc` time and Eden instantiation count for the prototype at 1, 20 and 100 routes, against the current approach's numbers.

Report what works, what fails at these versions (with the exact error or missing type), and a recommended approach for a three-route pilot: a public read, an authenticated command, and an operation with several typed failures. Do not build a framework over Elysia. If native facilities fall short, say exactly where and propose the smallest typed binding.
