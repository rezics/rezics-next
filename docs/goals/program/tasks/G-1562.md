## Outcome

G-1560 made every container started through the owner-preserving environment
carry the reap-owner label, and froze the other docker spawns as debt
(`scripts/static/docker-ownership-debt.json`, 120 calls in 24 files).

1. Move every frozen call onto the owner-preserving environment builder and
   empty the debt list. A call that reads state and never creates a container
   (`ps`, `inspect`, `logs`) still uses the builder, so the rule stays simple.
2. Test-owned stacks come down with their volumes:
   `second-host-format-upgrade.test.ts` and `content-rebuild-positive.test.ts`
   still leave volumes after `stack:down`. A copy supplied to
   `erasure-campaign-qualification.test.ts` belongs to its supplier, so the
   test stops it and keeps its volumes (amended at review: the test did not
   create that copy).
3. Change only the environment and teardown. Each test keeps its own stack
   shape, fault points and assertions.

Acceptance:
- The debt list is empty and the guard passes.
- After running the converted fault and integration files, `docker ps -a` and `docker volume ls` show no project or volume that they created.
- Files that fail on main fail the same way (give the main run id).
