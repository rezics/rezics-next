## Outcome

Four stories in `apps/web/features/work-page/games-hub-recorded.stories.tsx` (Member, MemberPhone, MemberSaved, MemberSavedPhone) fail on main: the Edition selector still has `pointer-events: none` when the story interacts with it. G-2475 reproduced this on main `96dea42d5c` without its own changes. `packages/ui/src/components/select.tsx` disables the Select until hydration, and the likely cause is that the selector never leaves that state in these stories, or the stories interact before it does.

Find the cause and fix it there. A user must be able to choose an Edition once the page is interactive, on phone and desktop. If the stories act too early, make them wait for the readiness signal the component exposes, not a fixed delay. Do not remove the interactions from the stories.

All ten Games Hub recorded stories passing, the Select's existing unit tests, phone and desktop screenshots of a member choosing an Edition, and `task goal -- check`.
