## Outcome

Over 2026-10-15 08:30–20:30 UTC, fixture and harness repairs cost about 89 M worker input tokens. Many runs started stacks and broad persona journeys, then failed on retained data:

- a key that changed with unrelated code;
- a published directory without a manifest;
- a backup missing for the selected key;
- a PostgreSQL collation drift (2.41 recorded, 2.43 on the host).

Several of these failed only after minutes of setup, and workers then spent turns diagnosing them.

Before a QA run starts any persona or integration test, check every retained source its selected files declare:
- compute the key from the frozen tree;
- find the manifest and backup custody for that key, with integrity;
- compare the recorded collation and image with the host.

Report in seconds which source is missing or stale and the exact command that builds or repairs it. The check reads only; it never builds by itself. Run it automatically at the start of `task goal -- test`, of confirmations, and of the surface and merge gates' integration tiers. A worker can also run it alone.

Prove it on synthetic sources: a missing build, a stale key, a missing manifest and a collation drift are each reported before any test starts, and a complete source passes in under a few seconds. Measure it on one real confirmation.
