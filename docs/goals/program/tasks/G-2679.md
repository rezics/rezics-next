## Outcome

`scripts/static/web-page-filtering.test.ts` scans the web app's production files and took 5.25 s in G-2462's canonical gate (`run-K92Qfp`), exceeding the 5 s test timeout and failing two surface gates. The sibling guards `web-accepted-commands` and `web-continuations` scan the same files.

Make the scan fast instead of raising the timeout:
- parse each file once and share the result across these guards, for example through a cached project scan keyed by file content;
- or restrict the scan to the files the rule concerns.

The guard must find exactly the same violations as before; prove that with the existing tests and a planted violation. Report the before and after times on this host. If the shared scan helps the other static guards that scan the web app, use it there too.

When it lands, mail web through `task goal -- mail send web` that G-2462 can rerun its canonical gate.
