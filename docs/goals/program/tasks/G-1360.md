## Outcome

Switching the live shared stack to pinned mode on 2026-10-07 exposed two
defects.

1. **Port collision.** In `REZICS_DEV_MODE=main` the AppHost keeps 3001 and
   3002 on Aspire's proxy and gives Main and Account dynamic target ports.
   While a refresh had writers stopped, a QA stack's toxiproxy container
   (`rezics-qa-metadata-restore-…-toxiproxy-1`) got Main's target port 34769
   as a random Docker published port. Main then failed with `EADDRINUSE`, and
   the refresh failed at restart. Docker and QA stacks draw from the Linux
   ephemeral range (32768–60999), so a stopped writer's dynamic port can
   always be taken.

   In main mode, have Main, Account and the relay listen on fixed ports
   outside that range. Either bind 3001 and 3002 directly (`isProxied:
   false`), or give the target ports fixed values below 32768. Choose
   whichever keeps the public URLs, the issuer and the health checks
   unchanged, and say why in the handoff.
2. **Held-stopped writers.** After an unfinished maintenance refresh,
   `task dev` starts the AppHost with Account, Main and the relay
   NotStarted. The next `task dev:refresh -- --wait` then reported
   `Generated stack environment would change` for every Account variable
   and refused. `inspectRefresh` compares each resource's loaded environment
   (`refresh-stack.ts` around line 270), and a NotStarted resource reports
   none. Treat a resource that has never started in this AppHost as having
   no environment to compare. It cannot be stale, because it will start from
   the current AppHost configuration. The refresh should then finish the
   maintenance and start the writers.

Update the switch-over and recovery text in `docs/development/README.md`.

## Checks

Unit tests:

- In main mode the AppHost declares fixed, non-ephemeral listening ports for
  Main, Account and the relay.
- A refresh whose writers are NotStarted after `task dev` plans normally,
  with no environment blocker.
- A refresh whose running writers really have a stale value still blocks.

Run `task goal -- test scripts/dev/tests/refresh.test.ts` and
`task apphost:typecheck`. Do not restart the shared AppHost; the manager does
that at merge.
