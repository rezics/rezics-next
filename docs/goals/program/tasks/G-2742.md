## Outcome

The program Goal is about to close. `task goal -- goal close program` moves `docs/goals/program/` to the `archive/goals` branch, and it refuses while documents outside that directory link into it. Prepare the tree so that the close removes only history.

1. Move each piece of standing procedure in `docs/goals/program/GOAL.md` and `state.md` into the document that owns that kind of instruction, following `docs/README.md`:
   - "Asking the maintainer": the charter links to it from `docs/goals/manager.md`.
   - "How managers run from now on": `docs/development/toolchain.md` links to it.
   - "The efficiency audit": its researcher procedure.
   - "Starting": supermanager startup, including the start command and message.
   - The duties that outlive this Goal.
   - The checkpoint's "Operating decisions".

   Keep each idea once. If the charter, `docs/goals/README.md` or `.agents/skills/goal-management/` already states one, drop the copy. Shorten while moving, and keep the instruction style of the destination.
2. Move the checkpoint's open questions (Windows support, title control and Work merge, Tailnet sign-in) to the documents that own those subjects, as open questions.
3. Repoint or remove every link into `docs/goals/program/` from outside it. These are `GOAL.md`, `docs/README.md`, `docs/goals/README.md`, `docs/goals/manager.md`, `docs/development/toolchain.md`, `docs/operations/external-conditions.md` and `docs/architecture/content-adoption.md`. Where a sentence only reports the program's state at a past date, delete it. The external-conditions list stays a list the maintainer holds; no Goal solves or waits for it.
4. Leave `docs/goals/program/` itself unchanged, apart from deleting text you moved. History and `later.md` are archived with the Goal.

Do not change code or briefs, and do not run the close.

## Checks

`task docs:check`. `GOAL_ID=program task goal -- goal close program --dry-run` reports no link into the Goal; it may still report open tasks and briefs.
