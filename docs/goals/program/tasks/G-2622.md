## Outcome

Measure the public pages a visitor reaches first: the Zone home, catalogue browse and search, a Work hub, a Recipe reading page, a Realm home and a thread. For each, measure, on a production build:

- JavaScript sent;
- server render time;
- largest contentful paint;
- interaction latency on a throttled mid-range phone profile.

Find the largest avoidable costs, such as a client bundle pulling server-only or editor code into a reading page, an unsplit route, unoptimised images, or a waterfall of reads that could start together, and fix them. Add a budget test that fails when a public page's JavaScript or server render time grows past a stated budget. Hand off before and after numbers per page.
