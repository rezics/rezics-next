## Outcome

Program measured where workers wait, from 06:00 to 09:25 UTC on 2026-10-14. 37% of worker input tokens were polls: a worker re-sending its whole context (median 144k tokens) to ask whether a command had finished. A Codex poll blocks at most 60 s. By command waited on: the worker's own `task goal -- check` 43%, tests that start a QA stack 15%, type checks and tests chained after `task gen` 12% (`task gen` itself takes 1-2 s). Inside a check, the 38 repository guards run one after another in a single `bun test` process: 295 s summed, 301 s wall. Six files cost 81%: authentication-subject 74 s (one case 45 s), mechanism-dependencies 65 s, serialization-points 31 s, web-acting-identity 27 s, g-543-rate-limit 22 s, g-1046-sql-relations 20 s. The type check had a median of 52 s but p75 of 172 s while queued for memory (web needs 5.5 GiB plus 8 GiB reserve). Type-aware lint took 60 s and peaked at 9.2 GiB.

After G-2515, a check covers only the worker's own diff, but it still runs whole-program tools per worker. Make a worker's `task goal -- check` finish in under a minute and stay off the memory queue:

- **Types:** `bun check` accepts files and checks them with their imports. Check the changed TypeScript files and the files that import them (their dependents), not the whole workspace, whenever that set is smaller. Fall back to the workspace for a change to a tsconfig, a package manifest, or a declaration that many files depend on.
- **Lint:** run oxlint's non-type-aware rules on the changed files in the worker check. The type-aware rules (tsgolint, 9 GiB) move to the branch-level check.
- **Branch level:** add `task goal -- check --branch <ref>`. It runs the whole-workspace type check, type-aware lint, AST scan and every repository guard once for a branch tip, records the result keyed by commit, and returns the recorded result for a tip already checked. Program runs it on `wave/<n>` tips; the merge gate keeps its own full checks.

Coordinate with G-2524 (parallel guard runner) and G-2525 (Rust index), which may land first; G-2525's import graph can give the dependents. Report a worker check's wall time before and after, on a one-file change in `apps/web` and in `services/main`.
