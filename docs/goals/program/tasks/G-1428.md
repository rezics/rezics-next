## Outcome

Unit and owner-tier cases fail on current main. Managers have been bypassing
the merge gate around them since 2026-10-08 04:00 UTC. Program needs each
failing case routed to the Goal whose commit broke it.

1. Run the unit and owner tiers on current main HEAD and list every failing
   case by file. Known so far:
   - **nested-pool-checkout:** "restore reconciliation reuses the held access
     and relay connections". In launch's QA run 20261008t092836-2d8d73, the
     main log shows 98 `NestedPoolCheckoutError` worker faults, and the
     recipe page's wiki section failed to load.
   - **library-public-bounds:** the carried-count "hidden mid-walk" and
     HTTP-retry candidate-budget cases.
   - **owner-response.**
   - **Reading position:** g-847, g-954 and g-1021, plus structure-group-seek.
     Kernel saw "untagged-record prefix visibility".
   - claim-statement-fold, private-name and saved-filter.
2. For each failing file, run it in isolation twice to separate deterministic
   failures from order or load failures.
3. Bisect each deterministic failure to its first bad commit (`git bisect run`
   with only that file). Read the commit's `Goal:` trailer.
4. Do not fix anything. Name the suspected cause in one line for each.

Skip `scripts/static/anti-silo.test.ts`: program already traced it to
2965a02a4.

## Checks

The handoff lists, for each failing case:
- file and case;
- deterministic or not;
- first bad commit and its Goal;
- a one-line cause.

Write the same list as JSON in `.temp/triage.json` in the worktree.
