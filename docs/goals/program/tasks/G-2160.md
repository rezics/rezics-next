## Outcome

A story runs the web's real client and adapters on answers the API gave, and never on a model written by hand. The design note (staged as `.temp/ref/surface-design-note.md`, section 3) was read by the program on 2026-10-13, which decided: the replay enters through the fetch the typed client already accepts (`browserMainApi({ fetcher })`, `apps/web/features/api/browser.ts:14`), with the same seam for the server readers (`apps/web/features/api/main.ts`); no new library and no global `fetch` spy for a caller that uses the client. The record's envelope is `scripts/api/answer-record.ts` on `main`, and the first record is `tests/qa/fixtures/outcomes/books/catalogue-browse-and-search-in-its-zone.json`.

1. **`apps/web/features/stories/recorded-fetch.ts`:** from a record, a persona and the samples a story names, a `fetch` for that story alone. It matches method, path, query and body exactly and answers with the recorded status, headers and body. A request no sample matches fails the story with the request printed; nothing reaches a network.
2. **The five states, as far as the operation's contract admits them:** populated and empty are recorded `200` answers; error is a recorded problem answer, unchanged; loading holds the matching call unanswered until the story ends, and releases it; pending is a recorded `202`. A state with no recorded sample cannot be asked for.
3. **The seam:** the browser client and the server readers take the story's fetch through one optional argument each; without it they behave as today.
4. **One story proves the path:** in `recorded-fetch.stories.tsx`, the typed client reads the Books record through the replay and a minimal component shows the populated, empty, error and loading states for one persona. It is the path's proof, not the row's surface.

It must not become a second client (no authentication, retry, pagination arithmetic or cache of its own) or a server with behaviour (no state between calls, no rule).

Do not build: the Books surface or any row's stories, a change to a feature's reader beyond the optional argument, a migration of existing stories, a replay for a caller that bypasses the client.
