## Outcome

wave/1 holds about 120 changed files in `services/main`, `model`, `packages/model`, `generated` and `infra/jena` that no landing review has read. Builders repaired from reading the code, so their changes have not met a stack yet. Review `git diff main...wave/1` for those paths, as the API's reviewer would before the wave merges:

- correctness against each row's outcome test;
- authority and disclosure: concealed versus absent answers, `actingSubject` handling, platform grants;
- every operation touching a bounded neighbourhood: no scan that grows with the catalogue, the Realm or history;
- migrations that are safe on existing data;
- generated files that match `task gen`;
- contracts the web consumes that changed without their schema.

Read `docs/goals/method.md` and the briefs of the tasks whose commits you read (the commit message names the task). Fix a defect you are sure of in place and push it. Leave a judgement call, or anything a row's owner must decide, as a finding.

## Wave
