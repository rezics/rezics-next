## Outcome

Read `.temp/ref/G-1522.md`, finding 14 (env and canonical JSON parts).

1. **Env files.** Four readers parse the same generated files differently:
   `readEnv` (`scripts/dev/config.ts`), `node:util` `parseEnv` in `dev/cli.ts`
   and `refresh-stack.ts`, and private parsers in `datasets/auth.ts` and
   `datasets/bootstrap.ts`. Keep one reader in `scripts/dev/config.ts`. It is
   strict: a malformed line is an error naming the file and line. Its quoting
   rule is written once, and every caller uses it. Delete the others.
2. **Canonical JSON.** `datasets/store.ts` and `fixture/corpus.ts` each
   serialize with sorted keys and handle `undefined` differently. Keep one in
   `scripts/lib/canonical-json.ts` with the undefined rule stated, and have both
   use it.

Generated environment values, digests and stored identities must not change.
A test re-reads the current dev and QA env files and compares them, and
re-hashes stored dataset records. Production lines must drop (show
`git diff --numstat main...HEAD`).
