## Outcome

A wave's prove phase runs every outcome test twice: once in `task goal -- confirm --at <commit>` to read the cells, and again with `OUTCOME_RECORD_DIR` to capture the answer records the web replays (`tests/qa/support/outcome-test.ts`). The confirmation passes its environment to the tests. But the recorder writes only under the checkout's own `.temp/`, and `confirm.ts` removes its pinned checkout when it ends. A recording confirmation therefore loses its records.

Add `--record <directory under .temp/>` to `confirm`. Each lane records into its checkout as usual, and before the pinned checkout is removed, confirm copies every record written there into `<directory>` in the main checkout. A record from a file whose cells did not all pass is copied to a separate `failed/` subdirectory, not mixed with publishable ones. The manifest lists each record with the file and status it came from. Without `--record` nothing changes. A test covers the copy-before-cleanup order and the passed/failed split.
