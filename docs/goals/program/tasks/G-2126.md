## Outcome

The maintainer sees every agent of a Goal at work in his own terminal, and the tool keeps that view. termspaces is his tool for tmux workspaces; its facts are staged in your worktree at `.temp/ref/termspaces-facts.md`. Today a worker is a detached process nobody can watch, and a manager turn runs in a tmux session of its own on whatever server the enrolment recorded.

- **The windows are a view of the ledger.** After one pass, the session `rezics-agents` on termspaces' socket holds one window `goal-<goal>-<task id>` for each live worker, one `goal-<goal>-turn-<n>` for each live manager turn, and no other window whose name starts with `goal-`. A window with another name is never touched, read or typed into. `task goal -- windows` runs one pass; the coordinator's pump runs it each interval.
- **A worker's window follows its attempt:** one line for each step the engine's event stream gives (the time, what it did, 120 characters), each new attempt of the task, and the handoff's result line at the end. `task goal -- follow G-NNN` prints the same anywhere. It is a view: closing it changes nothing for the worker.
- **A manager turn runs in its window**, so it is outside the coordinator's cgroup and outlives a restart of the service, as the session of its own did. The window shows the turn's steps the same way; where an engine prints nothing until it ends, it says which event it is deciding and prints the result. The pass removes the window once the turn's record is written.
- **Nothing of a Goal runs on another tmux server.** The socket is termspaces' (`/tmp/tmux-<uid>/termspaces`; `GOAL_TERMSPACES_SOCKET` and `GOAL_TERMSPACES_SESSION` override both for a test), not the one recorded at enrolment and not the caller's.
- **Without termspaces nothing stops but turns.** When the session is missing the pass runs `termspaces apply` once. If it is still missing, workers run unwatched, a turn waits with the existing back-off, and `status` says why in one line.
- `status` names each worker's and each turn's window. `task goal -- windows --remove` removes every `goal-` window, for a `termspaces reset`, which refuses while a window it did not make exists.

No task or turn is started, stopped or changed by a window. Do not change termspaces or its configuration files.

Do not build: registration calls in `launch`, `dispatch`, `stop` or `close` (the pass replaces them), panes, layouts, keys sent to a window, a capture of a window's text, the coordinator's journal window.

## Checks

`task goal -- check`, and `windows.test.ts` once with `CLAUDECODE=1`. Every test runs a tmux server of its own on a temporary socket; none touches termspaces' socket. They cover: windows made for two workers and a turn and removed when each ends; a window with another name left alone; a second pass changing nothing; a missing session; `--remove`; a turn started in a window and found again after the coordinator restarts; the follower's lines for a recorded Codex attempt and for an engine with no stream. Then one pass on the real session, with the window names it made in the handoff. Wait on a running command with one long call (`yield_time_ms: 300000`).
