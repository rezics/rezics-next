## Outcome

The web catalogue and search surfaces built on wave/1 list requests that no record holds yet. For every request below, make the named row's outcome test send it for each persona, exactly as production sends it (client, `actingSubject`, body), with the label the story looks up. Read the story inputs that list the requests as the specification. Change no assertion, no cell and no existing sample's label or request, and write no answer by hand. An empty, error or continuation state is produced by the test arranging that state through the API, never by editing an answer. If a state cannot be produced through the public API, name it in the handoff.

- `missingRealmSearchStates` in `apps/web/features/discover/realm-search-fixtures.ts` (closed, closed continuation, global, empty and error Realm search; row `realm/closure-search` and the search row its fixtures name).
