## Outcome

Improvement 1 of the API audit (G-2640; full report in `.temp/ref/audit.md`, section 5 and the priority list). The generated OpenAPI and the Eden types omit responses that shared transport policies actually produce:

- 376 budgeted operations omit their 429;
- ten direct handler response pairs are absent;
- two non-problem error bodies are relabelled with the wrong media type.

Derive each operation's policy-owned responses from its existing operation metadata, then declare them on the route so they reach OpenAPI and Eden. Policy-owned means rate limit and budget 429s, authentication 401, exposure-gate 404 or 403, and idempotency 409 and 422. Keep read exemptions and hidden-resource indistinguishability exactly as today: a hidden resource still answers like an absent one, and the declaration may not reveal a difference. Enumerate concrete Problem variants with literal codes; a broad string is not documentation. Fix the two media types.

Add a guard: for every operation, the statuses its handler branches and its policy hooks can produce are declared. Prove it with a planted undeclared status that fails. Review the full `task gen` contract diff, which should only add responses.
