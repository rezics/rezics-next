## Outcome

Building the medium fixture (100,000 Works) fails during verification with PostgreSQL error `53200`: advisory-lock entries are exhausted under the default `max_locks_per_transaction` (64). It built only with `REZICS_POSTGRES_MAX_LOCKS_PER_TRANSACTION=2048` (`docs/storage/qa-shared-databases.md`). A test or prove run that needs the medium fixture would fail to prepare it.

Find which verification or load step takes one advisory lock per item inside a single transaction. Make its lock use bounded by batch, for example by committing per batch, using transaction-scoped locks released per batch, or taking one lock for the owner rather than one per row, so the build succeeds on the default setting. Do not raise the setting to hide it. Keep the verification's guarantees.

`task goal -- check`, then one medium fixture build on default settings, with its time.
