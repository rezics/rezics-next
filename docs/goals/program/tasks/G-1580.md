## Outcome

`task fixture:prune` keeps every generation whose seed it cannot compute. That
is right, because only a seed's builder knows its current id. But nothing
removes old ranked generations, and 25 `g556-ranked-v1` medium generations now
sit on the host.

1. Add a seed-scoped prune to `scripts/fixture/prune.ts`, taking a seed and the id to keep. It removes that seed's generations other than the kept id. Pinned, retained and in-use generations are kept as `fixture:prune` keeps them. It uses the same root rule, never touches another seed, and removes stopped containers before volumes, as `executeFixturePrune` does.
2. `buildRankedFixture` calls it after a successful build, keeping the id it just built. Nothing else changes in the ranked test.
3. In the handoff, give the current ranked id and the list of generations a seed-scoped dry run would remove now. Do not remove anything. Program applies it.
