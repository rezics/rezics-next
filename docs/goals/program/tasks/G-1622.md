## Outcome

On 10-10 at 09:25 UTC, `task dev:refresh -- --wait` failed with `Refresh failed at align-model: Backend task dev:prepare failed (exit 201)`, and nothing more. The retry passed, so the cause was never seen.

The error sites in `scripts/dev` disagree:
- `refresh.ts` (`Backend ${executable} … failed (exit …)`) and `refresh-stack.ts`'s `command()` report only the exit code.
- `refresh-stack.ts` already says "output in ${log}" for the image build and for `task …`.

1. One failure-message helper in `scripts/dev` is used by every backend, Aspire and task call in the refresh path. It gives the step, the command, the exit or timeout, and either the redacted last 40 lines of its stderr and stdout or the path of a log file holding all of it. Use whichever the call already captures, and do not capture more than it does today. Redact with the existing `redactCommandOutput`.
2. Remove the per-site message strings that the helper replaces.

- `scripts/dev/tests/refresh.test.ts`: a failing backend task's error contains its output tail or log path. Update the existing exact-message expectations to the helper's form.
