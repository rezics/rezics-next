## Outcome

Competitor coverage (rank 1, B01): for a recipe manager user, re-entering a Paprika or Mela collection is the move-in blocker. Add import adapters for their export formats, through the existing Recipe exchange import and the content-adoption model (`docs/architecture/content-adoption.md`):

- Paprika's `.paprikarecipes`: a zip of gzipped JSON per recipe;
- Mela's `.melarecipes` and `.melarecipe`: JSON.

Map each field to its owner:

- ingredients become the Recipe's ingredient facts, with amounts parsed where stated and never invented;
- directions become a Content procedure block;
- notes, the source URL and the photo become their content, source and media owners;
- categories and ratings become the person's private collection data; ratings use the native scale work of the sibling B02 task if it has landed, otherwise they are kept raw for it.

Import is private to the importing person by default, idempotent on re-import, and reports per recipe what was kept and what was lost. Prove it with a fixture export of each format containing tricky lines (ranges, fractions, unit-less amounts, non-English), import twice, and API tests as the owner and a stranger.
