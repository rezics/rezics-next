## Outcome

Prove that the **public discovery reads** touch a bounded neighbourhood as the population grows: catalogue browse and search in each Zone, typeahead, the Realm feed, rankings (Best and Top), boards, the directory, and notifications.

For each read, seed one method at three or four modest sizes, for example 10, 100 and 1,000 Works or posts. Measure the operation's real work for the same first page and the next page: graph calls, SQL rows touched, native index next and advance calls, and served time. A count that grows with the population is a defect. Find the operator and fix the algorithm at its cause, as G-2567 did for native ranked search. Keep each measurement as a growth test, red before any fix and green after.

Never raise a budget or cap to pass. Hand off a table: read, sizes, work per size, verdict, fix commit.
