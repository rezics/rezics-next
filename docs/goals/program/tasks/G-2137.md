## Outcome

Every failure of the run on `main` d2a2e3166 (run `20261013t043515-585e9a`: 2,168 files run, 329 failed, 452 not run) has a disposition a manager can act on without reading a log. The staged references `.temp/ref/regress-clusters.md` and `.json` hold the 189 clusters by first error line, made with no model. The run's directory, `.temp/goal-orchestration/regress/20261013t043515-585e9a` in the main checkout, may be read and never written. You change no file of the repository.

Write `.temp/goal/regression-disposition.md` in your worktree, one line for each cluster, in this order:

1. **Caused by the run itself.** Workers ran on the host until 05:39 UTC and again from 09:39 UTC; between them the host was quiet. A cluster whose failures are a timeout, a refused connection or a stack that did not start, in batches that ran beside workers or beside a sibling batch's fault injection, is a candidate. Decide it by evidence: rerun one file of the cluster by itself on your worktree (`CLAUDECODE=1 task goal -- test <file>`), at most twenty-five reruns in all, the largest clusters first. Passes alone: `self-caused`, with what in the run caused it. Fails alone the same way: it goes to 2 or 3.
2. **A pending cell of a row.** The scope's 67 rows are the registry `launchCoverage` that `scripts/qa/cases/outcomes.ts` imports, and their declarations are under `scripts/qa/cases/outcomes/`. A cluster that shows what a person gets from the API wrongly in a row's subject is `row <vertical>/<row>`, with the persona when the test names one and the request and answer in ten words.
3. **One task of the Goal that owns it.** Everything else: `task <goal>` with the cause in one line. The owner is the Goal of the failing source, not of the test (`task goal -- owner <path>`); a test that asserts something `main` no longer promises is `obsolete test`, with the commit or document that changed the promise.

Clusters that share a cause are joined under one line with their file counts; say how many causes remain of the 189 clusters. The file ends with three tables: causes by Goal with their file counts, the ten causes that hold the most files, and the 452 files not run by reason.

Then the handoff gives the three tables and the path of the file, in at most sixty lines.

Do not build: a fix, a change to a test, a new regression run, a rerun of more than twenty-five files, a classification by a model of text you did not read.
