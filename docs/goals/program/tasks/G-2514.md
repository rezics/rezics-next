## Outcome

The web Realm discussion, boards, thread and closure surfaces (web G-2483) list requests and states that no record holds yet. For every group below, make the named rows' outcome tests send the requests for each persona, exactly as production sends them (client, `actingSubject`, body), with the labels the stories look up, so the wave's single record run records them. Read the stories and recorded-read modules under `apps/web/features/realm/` and `apps/web/features/zones/` that name these requests as the specification. Change no assertion, no cell and no existing sample's label or request, and write no answer by hand. An empty, error, moved-cursor or continuation state is produced by the test arranging that state through the API, never by editing an answer.

- Requests: `GET /v1/realms/{realm}/classification-context; GET /v1/classification-vocabulary?context={context}&limit=20[&cursor={boardsCursor}]`. States: HTTP 200 populated, empty and opaque next board page; HTTP 503 vocabulary error; held request loading
- Requests: `GET /v1/realms/{realm}/threads?sort={best|new|top}[&window={week|month|all}]&concept={Concept}[&language={contentLanguage}][&cursor={threadCursor}][&actingSubject={self}]`. States: HTTP 200 populated/empty/continuation; HTTP 400 mismatched board cursor or unsupported selection; HTTP 409 moved cursor; HTTP 503 unavailable; HTTP 404 retired/closed/absent; held request loading
- Requests: `GET /v1/realms/{realm}/threads/{reply}?sort={best|new|top}[&language={contentLanguage}][&cursor={siblingCursor}][&actingSubject={self}]`. States: HTTP 200 public/private member thread, opener with no children, sibling/deep/ancestor pages; HTTP 404 closed placed thread/descendant; HTTP 503 unavailable; held request loading
- Requests: `GET /v1/realms/{realm}, /join-page, /works, /decisions, /decisions/{decision}, /zone; /about-thread?about={work}; /modules/{new-adoptions|recently-completed|recent-decisions|latest-chapters|discussions|reader-quotes|editor-lists|browse}`. States: Exact ordinary HTTP 404 for closed and absent Realm, all six personas. Existing closure record only covers entry resolution.
- Requests: `GET /v1/zones/{zone}/routes?path=/[&actingSubject={self}]; GET /v1/zones/{zone}/routes?path=/original[&actingSubject={self}]; GET /v1/zones/{zone}/presentation[&actingSubject={self}]`. States: Post-closure HTTP 200 independent credited home/original, realm:null, old Realm module source state unavailable, no roster or Realm lookup from discussion entry
- Requests: `GET /v1/realms/{realm}/threads/{canonical-about-thread}[?actingSubject={self}]`. States: Full canonical attached discussion body is missing from current zone/attached-realm-discussion record; retain authored identity/credit and private policy

Rows: `realm/boards`, `realm/threads-and-replies`, `realm/membership-and-admission`, `realm/closure-direct-routes`, `realm/closure-threads-and-replies`, `realm/closure-zone-discussion-entry-and-modules`, `zone/attached-realm-discussion` and `zone/home-rendering`.
