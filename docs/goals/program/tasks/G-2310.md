It is not run when it matters: `task test -- --affected --list` for a change to a file under `tests/qa/integration/outcomes/` or under `scripts/qa/cases/outcomes/` does not select it ("Guard absent"); only a change to `tests/qa/support/outcome-test.ts` does. The selection matches exact source references for code files (`scripts/qa/affected.ts`, about line 269) and its reverse-import walk (about line 454) cannot see a guard that reads the tree. On 2026-10-13 such a change landed and stopped every gate for 25 minutes.
