## Outcome

An agent that needs an API operation asks one command before it reads source: `task operation -- <query>` prints where the operation is declared and which tests call it. On 2026-10-11 and 2026-10-12, 35% of worker tokens went to reading and searching.

- A query is words matched against the operationId, the method and the path (every word must match, case ignored), or an exact `METHOD /path`. `task operation -- browse realms modules` and `task operation -- 'GET /v1/realms/:realm/modules/browse'` both find that operation.
- Each match prints one short block: the operationId; method and path; exposure; rate-limit family; whether it takes a bearer and an idempotency key; the route file and the line of its handler (`services/main/src/routes/zone-modules.ts:95` for the example); the test files that call it. A test file calls it when a string or template literal in it matches the path pattern (`/v1/realms/${realm}/modules/browse` matches; a path that only shares a prefix does not). Test files are grouped by tier directory, ten at most and then a count. The example lists `tests/qa/integration/outcomes/books/catalogue-browse-and-search-in-its-zone.test.ts`.
- Output is bounded: fifteen matches at most, then `N more; narrow the query`. `--json` prints the same as JSON. No match exits 1 and names the three nearest operationIds.
- It is computed when asked, from what the route modules declare (`openApiOperations`; `scripts/api/generate.ts:275-311` shows how the generator imports them, `services/main/src/modules/access/exposure-routes.ts:15` how an operationId is derived). No committed file and no change to the generator. If a call takes more than about three seconds, cache under `.temp/`, keyed by the contents of the route files.
- It needs no stack and no `task gen`.

Do not build: an owner column (every Main route is in the api Goal's area and no finer owner is recorded anywhere), Account's operations unless the same declarations give them for nothing, descriptions or search over prose, an MCP or HTTP surface, a change to a route module, documentation.
