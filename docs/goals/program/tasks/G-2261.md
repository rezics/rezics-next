## Outcome

The owner's navigation editor of a Zone can be shown from its row's record. The first surface built from `tests/qa/fixtures/outcomes/zone/navigation-and-theme.json` could show the theme and the published frame but not the editor, because the editor's own reads are not in the record. A story replays a request by its method, path, parameters and body and never mixes personas, so a read recorded with other parameters than the page sends cannot be replayed.

1. **The draft navigation as the editor asks it.** `draft-navigation` is recorded as `GET /v1/zones/{zone}?actingSubject={owner}`; the editor sends the same read with `limit=50`. Record the owner's read with `limit=50` under its own label, beside the existing sample.
2. **The names of what the navigation mounts.** For the target of the draft navigation's mount the editor reads `GET /v1/collections/{target}/name` (no parameters) and `GET /v1/works/{target}?actingSubject={owner}`. Record both for the owner, each under its own label, with the answer the API gives, whatever its status: the editor asks both because it does not know the target's kind, and the refusal of one is a state the editor shows.
3. The reads are bodyless and the owner's only. Confirm each against the reader under `apps/web/features/` that loads a Zone's navigation for editing (read it, change nothing there); if it sends another parameter or another read than the three above, record what it sends and say so in the handoff.
4. No assertion changes and no cell changes state; no existing sample's label, request or order changes. `scripts/api/answer-records.guard.test.ts` passes. Give in the handoff each added sample (persona, label, method, path, status), the recording run's seconds, and any read the editor makes that is still not recorded, with the reason.

An answer of 500 or above is a fault of the API, not a state of the page: do not record it under a refusal's label; hand off `partial` with the exact request and answer so the api Goal receives it.

Do not build: a change under `apps/` or `services/`, a change to the recorder, the record's format or the guard, another row's record.
