## Outcome

Since the platform gates, 247 Main operations answer 403 `platform_closed`
unless the caller holds `platform:use:<group>`. Integration and fault/recovery
tests written before that now fail on it: known cases are
`tests/qa/integration/package-lock-go-cargo.test.ts` (403 `platform_closed`),
`tests/qa/integration/poll-template.test.ts` (POST `/v1/polls` expects 400,
gets 403) and `tests/qa/integration/post-author-notes.test.ts`.

1. Find every such caller: list the closed operations from
   `generated/openapi/main/public.json` (`x-rezics-exposure` other than
   `public`), find the tests under `tests/qa/integration`,
   `tests/qa/fault-recovery` and `services/main/tests` that call them, and run
   each one you change.
2. Each such test opens the group it needs for its own principal through
   `tests/qa/fixtures/platform-grant.ts` before the call (extend the helper if
   a case needs it). A test that asserts a closed operation is refused keeps
   that assertion and gains the open counterpart only if its purpose needs it.
3. Add `tests/qa/unit/closed-operation-callers.test.ts`: a static check that
   a test file calling a closed operation also uses the grant helper (or is
   listed with a reason), so new tests cannot regress this.

The changed test files are outside your claim and unclaimed: change them
minimally and list them under OWNER CHANGES.

## Do not

Change product code, exposure declarations or the gate; weaken assertions.

## Checks

Each changed test passes through `task goal -- test <file>`; the new unit check
passes and fails on a planted caller without the helper.
