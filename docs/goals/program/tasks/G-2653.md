## Outcome

On 2026-10-15 at 10:45 UTC, G-2646 (the native contract pilot) merged into main. Its branch began before G-2645's inference-cost check landed (09:40). Its rebased tree took the Eden consumer from 12,154,275 to 13,903,588 instantiations, over the budget, and every `task goal -- check` on main then failed until program re-recorded the baseline (`1be8504a6a`). The check never ran on G-2646:

- its worker's `task goal -- check` ran on a base without the check;
- the merge gate (`scripts/goal/merge.ts`) runs types and the unit gate, but not the checks that `scripts/goal/check.ts` selects, such as `needsInferenceGate` → `inferenceGateCommand`.

Make the merge gate run, on the rebased tree, every check that `check.ts` would select for the task's change against main. Reuse `check.ts`'s own selection, not a second list, so a check added later is enforced at merge with no edit here.

Prove it with a test where a branch that predates a check fails that check at merge. Keep the gate's cost bounded: run only what the change selects, and reuse a result already computed for the same tree.
