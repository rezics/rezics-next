## Outcome

A read-only, adversarial review of what this Goal merged, so defects are found
before the frontend builds on it. Change no files; report findings in the
handoff, most severe first, each with file and line, a concrete failure
scenario and the smallest fix.

Scope (all on `main`): decisions 51–53 in `docs/contracts/semantic-model.md`,
`context.md` and `ratings.md`; `services/main/src/modules/projection/`;
relation credited names and the star constraint (`relation/change.ts`,
`semantic/change.ts`); typed applicability, frame filters and the projection
page (`statement/projection.ts`, `projection/frame-read.ts`, `entity-page/`);
rating components, thresholds and roll-ups (`rating/target*.ts`,
`rating/rollup*.ts`, `access/rating-aggregate-inventory.ts`, migration 1055);
projection grain, v4 acceptance and Global questions (`rating/acceptance.ts`,
`rating/target-context-authority.ts`, `access/baseline.ts`,
`access/platform-administrator.ts`, `outbox/relay.ts`); question presentations
(`rating/question-presentation*.ts`); exports (`export/scoped.ts`,
`library-export/bundle.ts`).

Look hardest at: authority (who can create Global questions, rate without
membership, write presentations, read private projections through
normalization, filters or exports); disclosure leaks through projections,
summaries, roll-up members and exports; correctness of `covers`, specificity
and the star constraint under concurrency; additive components under
concurrent seals, withdrawals and merges; costs that grow with stored data on
hot paths; places where the code contradicts decisions 51–53 or does more than
they require (unrequired layers are findings too).

## Checks

Read code and tests; run any existing unit or integration file you need through
`task goal -- test`. No commits.
