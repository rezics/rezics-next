## Outcome

Let people rate, review and discuss "X in F" and any subject without joining a
Realm, per [decision 53](../../../contracts/ratings.md#scoped-targets-and-roll-ups).
On `main`: projections (`services/main/src/modules/projection/`, target base
`projection`), additive rating components with display thresholds and
`POST /v1/rating-rollups`, and `realm-target-rating-context-v3` whose grain list
already includes `rv:Projection`.

1. **The projection grain end to end.** Admit `projection` in `TARGET_GRAINS`,
   the RDF grain read, `resolveRatingTarget`, `release.ts` grain recognition,
   `target-read`, `populations`, the merge handler (projection ratings are not
   Main Version votes), `review/read.ts` and discussion (`realm-reply/root.ts`,
   exact revision). Creating a `projection`-grain Context is no longer refused.
2. **Questions declare what they accept.** `realm-target-rating-context-v4` (and
   its observation v4) adds optional accepted subject types and, for the
   projection grain, accepted frame dimensions; leave v1–v3 untouched. A rating,
   review or discussion on a target the Context does not accept is refused with
   a typed error. `GET /v1/resources/{id}/rating-contexts` lists only Contexts
   that accept that resource (for a projection: its subject's type and its
   frames' dimensions).
3. **Global questions.** Platform administrators create target Contexts owned by
   Global through the same command and profile, not a Global-specific path;
   signed-in people rate them without Realm membership, and Global
   ownership is visible in reads. Seeding the first Global questions belongs
   to a later fixtures task, so do not touch bootstrap or dev seeds.
4. **Relay.** `outbox/relay.ts` validates `com.rezics.rating.observation-changed.v1`
   as requiring `work` and `main` (≈1456). Add the target-rating branch carrying
   `target` (the receipt's `rv:target`) and no `work`/`main`, so these events
   are delivered. The addresses-discovery Goal's classifier reads exactly that
   field name; if the receipt already uses another, stop and tell the manager.

Smallest change that satisfies the decision. Do not build: a Global-specific
rating path, new aggregation, caches, Realm standing changes, UI, or changes to
the per-Context admission scope gate (it serializes seals per Context today;
note its cost in the handoff, do not redesign it).
