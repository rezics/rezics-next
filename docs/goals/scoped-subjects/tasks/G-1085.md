## Outcome

`dispatch --allow-area` (goalctl.ts ≈958) lets a manager claim a path in
another Goal's area after the two managers agree; `reclaim` (≈1478) has no such
flag, so reclaiming a task dispatched with an allowance fails, and on
2026-10-05 a manager had to edit the ledger by hand. Make `reclaim` accept
`--allow-area` with exactly the same parsing and conflict checks as
`dispatch` (all other conflicts still refuse), list it in the usage text, and
keep every other behaviour unchanged.

## Checks

`bun test scripts/goal/goalctl.test.ts` with new tests: `reclaim` refuses a path
in another Goal's area without the flag and accepts it with the flag; a claim
overlap with another open task still refuses with the flag.
