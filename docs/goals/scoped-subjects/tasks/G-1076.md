## Outcome

Prove decisions 51–53 end to end through the public API, and give the shared
stack demo data for the browser work that follows. Everything is written
through the API, never directly to stores.

1. **First Global questions** in bootstrap and the dev seed, owned by Global
   through the v4 target Context (G-1074): "How much do you like this
   character?" (resource grain, accepts Characters), "How did they do here?"
   (projection grain, accepts Characters and Persons with position or event
   frames) and "How strong is this unit in this version?" (projection grain,
   accepts units with a release frame), each with labels in the eight UI
   locales and default thresholds.
2. **Dev seed `scoped-subjects`** (one step registered in the seed CLI) with
   realistic, small data:
   - Misaka Mikoto: one Character appearing in *A Certain Magical Index* and *A
     Certain Scientific Railgun* (appearance relations with roles); ratings of the
     Character and of "Misaka × *Railgun* S1 episode 3".
   - Artoria (hub) and Saber Alter linked by `variant-of` (persona); Saber
     Alter credited as "Saber" in an appearance scoped to the Heaven's Feel
     route, which is a Structure occurrence of the visual novel, not a Work.
   - Takanashi Hoshino and the unit "Hoshino (Swimsuit)" that represents her;
     the unit rated within one game version (a release).
   - Goku: one Character with ages and forms as Statements scoped by Work.
   - Edogawa Conan / Kudo Shinichi: one Character with an alternative name and a
     credited name on an appearance.
   - A player (Person) in one match with two maps as Events: per-map ratings
     from enough raters to pass the projection threshold on one map and not
     the other, a `pooled` and `mean-of-means` roll-up, and a ranking.
   - Excalibur (a Resource) in *Fate/Zero* episode 24, rated.
   - Anakin Skywalker with narrative continuities Canon and Legends, Works
     `in-continuity` of each, facts scoped per continuity, and canonicity
     Statements by an authority.
3. **Acceptance test** `tests/qa/integration/scoped-subjects-acceptance.test.ts`
   that seeds its own namespaced copy and asserts, per case: one identity where
   decision 51 says one; variant, unit and title links read both ways; frame
   filters return the continuity- and Work-scoped facts; the projection page
   lists covered facts; ratings below the threshold withhold the mean;
   projection ratings never change the subject's aggregate; roll-up formulas,
   coverage and ranking eligibility; Global questions listed only for the
   types they accept.

Chapters, episodes and routes are Structure occurrences (the `position`
frame dimension), never chapter Works: the post-layers Goal retypes chapter
Works to `rv:Post`. Do not add backend features: if a case cannot be expressed
with the merged APIs, stop and report the gap instead of working around it.
