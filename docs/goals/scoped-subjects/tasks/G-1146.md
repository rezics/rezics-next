## Outcome

G-1141 made seedFranchises, seedLnVnZones and seedRealms converge on the
long-lived shared stack: read first, write nothing when the facts match,
correct with evidence, adopt existing resources. Its commit is 5a09e29e5. A
full `task dev:seed` now gets further and stops on the same kind of problem
(`/home/edge/projects/rezics/rezics-next/.temp/manager/scoped-subjects/full-seed-2.log`):

- `seedContributions` reports incomplete. The text contributions
  `camp-lanterns` and `trail-markers` get `POST /v1/contributions` 409
  `idempotency_conflict`: a key is reused with a body that has changed since
  the stack was first seeded.
- `seedLibrary` reports incomplete. Find out why.
- `seedHomeFeed` reports incomplete with **511 writes on every run**, and
  `/v1/me/feed-watermarks/following` answers 401 `invalid_account_assertion`.
  Two problems: a converged seed must write nothing on a rerun, and the
  account assertion it sends is refused.
- `seedOfficialZones`: the Account sign-in for
  `local-operator-…@example.test` answers HTTP 503. Find out whether it is a
  readiness race (Account not ready) or a stable failure. Fix a race by
  waiting on Account's readiness, never by blind retries.

Apply G-1141's rules, and never weaken Main's or Account's rules. Find the
steps' files with `grep -n "seedContributions\|seedHomeFeed\|seedOfficialZones\|seedLibrary" scripts/dev/seed/*.ts`.
If a fix needs a file outside your paths, name it under PROPOSED TASKS.

## Checks

Unit tests for each convergence rule. Then run `task dev:seed` twice on the
shared stack, after `/health/search-ready` answers ready. Both runs must
complete, and the second must report 0 writes for every step. Include the
second run's step summary lines in the handoff.
