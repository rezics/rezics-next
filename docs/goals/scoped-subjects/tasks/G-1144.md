1. **The owner pointer appears as a fact.** On place and event pages, the
   `semanticWork` owner pointer is listed under "Other facts" and duplicates
   the Work row under Relations. Main's statements section should treat it as
   structure, not a Statement. Fix that in Main's entity-page statements
   disclosure (`services/main/src/modules/entity-page/**`), not by hiding it
   in the UI. If the web still needs a rule, put it in
   `apps/web/features/entity-page/statement-groups.ts`, and add a unit test
   on the Main side.
2. **"Ratings by part" shows when empty.** It reads "Nobody has rated this in a
   specific part yet." directly under the "Rate in a specific part" action.
   Hide the section when it has no parts with ratings; the action already
   invites the first rating. This follows the rule from earlier reviews:
   empty identity sections are not shown.
3. **Two notices state the reading position.** In a Zone, "Showing
   everything" (the position control) and "Showing everything, including
   records from chapters you may not have read." say the same thing. Keep one,
   whichever the position control does not already say, in all eight locales.
