## Outcome

Rating a target writes with `expectedRevisionHead`, but Main offers no read of
the caller's own current rating of a target: `GET /v1/resources/{id}/ratings`
ignores `scope=mine` for target grains and `GET /v1/me/ratings` returns only
Global Work ratings. On a second device, or after local storage is cleared,
re-rating a character, a projection or any target answers 409 `stale_head` with
nothing to recover from (found by G-1077).

Make `GET /v1/resources/{id}/ratings?scope=mine` (with the RatingContext) return,
for target grains, the caller's own current observation: value or withdrawn,
its revision head and the RatingContext, or none. It is private to the
principal (Access-bound, never visible to others or anonymous readers, not
cacheable publicly) and uses the existing slot derivation and read budget. A
409 `stale_head` from a target rating write also returns the current head so a
client can retry once without a separate read. Keep public aggregates and
every other read unchanged.

## Checks

`task main:typecheck` through the slot; unit tests; integration tests alone: a
rater reads their own value and head on a projection and a Character, another
person and an anonymous reader get nothing; a stale write returns the current
head and a retry with it succeeds; `scoped-judgments` and `rating-components`
still pass. Run `task gen` locally and restore generated paths.
`task ast-grep -- scan`.
