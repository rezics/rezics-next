## Outcome

The manager's screenshot review of G-1097's journey found pages that show what
does not apply:

1. **Empty identity sections.** Every Character page shows "Other versions",
   "Units" and "Titles" with "No … are listed here." Show each section only when
   it has members (keep the spoiler-hidden message when members exist but are
   hidden).
2. **Unrateable places.** "Ratings by part" lists a place no question accepts
   ("Star Wars Canon — No question applies here yet"). List only places with at
   least one accepting question, and make the frame picker offer only frame
   dimensions some question accepting the subject's type accepts (read the
   subject's rating-context listing), so people never mint a place that cannot
   be judged.
3. **Raw model words.** Statement rows show predicate local names such as
   `semanticWork` and `ability`. Every displayed predicate comes from its
   definition's label in the reader's language; if a seed used unlabelled
   predicates, fix the seed to use labelled definitions.
4. **Generic relations.** The seed's appearances render as "Related" with chips
   "Related Supporting character". Use the lexicon's appearance relation (or the
   one the wiki uses) so rows read as appearances with roles.
5. **Episodes.** The seed's episodes are `group` positions that the reading
   position read never offers as frames, so "Rate in an episode" has nothing to
   pick. Seed episodes as the placements chapters and episodes use.
6. **Journey seed.** Move the journey's 50-rater seed out of the first Playwright
   test into setup that runs once, so the default 300 s budget suffices.

## Checks

`task web:typecheck`, `task dev:typecheck` through the slot; changed stories;
the scoped-subjects acceptance test; the journey with the default budget.
Capture phone and desktop screenshots of the Character, place and event pages
and review them before handoff.
