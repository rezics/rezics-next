## Outcome

The main-wide e2e tier (`bun scripts/goal/goalctl.ts test --heavy --tier e2e`)
cannot run its Playwright journeys at all: Playwright refuses seven test files
that import other test files (since f10e1075d, 2026-10-01):
g-856-discovery → g-853-zones, g-856-library-export → g-855-library-export,
g-856-library-import → g-855-library-import, g-856-primary-action → g-850-hub,
g-856-progress → g-838-tracking, g-856-query07 → g-841-q07-wiki,
g-856-wiki → g-849-wiki ("test file … should not import test file …").
Run: `/home/edge/projects/rezics/rezics-next/.temp/verify/.artifacts/qa/` (latest
e2e run, `logs/e2e-playwright.log`).

1. Move each imported journey's body into a non-test module under
   `apps/web/tests/journeys/` that both files import, keeping the same tests,
   titles, viewports and seeds; the replay files then call it for their extra
   viewports. No journey is dropped or weakened.
2. `features/feed/feed.stories.tsx` "Follow From All" expects `kind: 'realm'`
   in the follow request; since G-1114 the relationship control sends no kind
   hint. Update the expectation to the request the control sends.
3. `features/home/home-page.stories.tsx` "Pin A Topic" fails intermittently
   ("The component failed to render properly"). Find the race and fix it in the
   story or its fixture; do not skip it.
