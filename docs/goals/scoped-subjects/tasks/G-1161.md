## Outcome

`apps/web/tests/studio.e2e.ts:120` and `apps/web/tests/studio-language.e2e.ts:30`
click the text 'A book'. Since 16954e53b (2026-10-01), the kind chooser shows
the registry label ('Book'), so both journeys fail at that step. Make each
journey choose the kind the way a person does: by the control's accessible role
and the label the chooser shows now. Do not match exact text where a role
query works. Keep everything else each journey asserts. If either journey fails
at a later step for a product reason, report it with the QA run id instead of
working around it.
