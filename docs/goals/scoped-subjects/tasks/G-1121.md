## Outcome

G-1115 added the scoped-subjects journey's seed to the e2e harness by matching
the journey's file name in `scripts/qa/cli.ts` and `scripts/qa/e2e.ts` (a 600 s
preparation budget and a launch of `apps/web/tests/scoped-subjects-journey-seed.ts`).
Replace that special case with a small, declarative per-journey preparation: a
journey file (or a sibling `*.prepare.ts`) declares its preparation command and
budget; the harness runs each selected journey's preparation once, before
Playwright, and adds its budget only when that journey is selected or the whole
e2e tier runs. The scoped-subjects journey uses it; behaviour and budgets stay
the same.

## Checks

Unit tests for selection (journey selected, whole tier, other journeys only);
`bun scripts/goal/goalctl.ts test apps/web/tests/scoped-subjects-journey.e2e.ts`
once to show the preparation still runs. `task ast-grep -- scan`.
