## Outcome

In a full Storybook run (G-1171, `/tmp/g1171-full.log`), `work-page/reviews`
"Write Review" cannot find the button `/한국어/`, because the page behind an
open dialog is inert. The story queries the body before the dialog that holds
the control has settled. Scope the query to the dialog (`within(dialog)`),
after waiting for the dialog's own ready state rather than a timeout. Keep
every assertion's intent. Use the shared helpers in
`apps/web/features/stories/choose-option.ts` for any option or menu click.

The story file three times in a row through the slot, and under
`task storybook:test` for the whole `work-page` folder.
