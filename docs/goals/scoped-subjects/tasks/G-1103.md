## Outcome

Main-wide regression finding (reported by post-layers on main 816835767): the
four direction-9 `wiki position` journeys fail in fixture setup on the shared
dev stack with `Fixture POST /addresses/claims: HTTP 409 (alias_conflict)` at
`apps/web/tests/direction-9-fixture.ts:129` ← `seedDirection` :341. The agent
handle `d9-reader-${suffix}` (suffix = sha256(name:actor)) is deterministic, but
the person it is claimed for comes from `POST /agents`, which returned a new
person this run, so the earlier run's person still holds the handle. The same
command passed 96/96 on a fresh stack. Log:
`/home/edge/projects/rezics/rezics-next/.temp/worktrees/post-layers-qa/.wiki-position.log`.

Make `seedDirection` idempotent on a persistent stack: before claiming, resolve
the handle; if it is already held by an agent this principal controls, reuse
that agent as the named person; if it is held by someone else, derive a
distinct handle from that fact rather than failing. Apply the same rule to every
other deterministic handle or name the fixture claims. Change only the fixture
and, if needed, the journeys' setup calls; assertions stay as they are.

## Checks

Run the `wiki position` journeys twice in a row against the shared stack through
`task goal -- slot --heavy` (the environment variables are in the log above),
and once on an isolated stack. `task web:typecheck`. `task ast-grep -- scan`.
