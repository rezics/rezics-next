## Outcome

Main-wide regression. Nine tests in
`services/main/tests/g-954-reading-position.test.ts` fail on main with
`Reading label search requires the configured order store`
(`services/main/src/modules/reading-position/traversal.ts`, `range`). Since
98a348cdf (index chapter labels for bounded reader search), label search runs
only through the order store (`searchOccurrenceLabels`). The tests' mocked
dependencies still have none.

Give the tests a faithful in-memory order store: same interface, same ordering
and label-matching semantics as the real one. Read the store's implementation
and `searchOccurrenceLabels` for those semantics. Every assertion keeps its
meaning. Do not weaken or delete any assertion, and do not change product code.
If a test turns out to assert behaviour the order store deliberately replaced,
say so in the handoff instead of changing the assertion.
