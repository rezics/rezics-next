## Outcome

Two failures from the main-wide pass on pinned `4bbf5f2cb`, both caused by this
Goal and failing when run alone:

1. **Language cap counts the wrong thing.**
   `tests/qa/integration/scoped-subjects-acceptance-recovery.test.ts` ("concurrent
   question seeding recovers an expired, terminally cancelled review…") gets
   `422 question_presentation_language_limit` while seeding eight languages,
   although G-1095's cap is 64 reviewed languages per Context. The count must be
   the number of distinct languages with a reviewed presentation for that Context:
   drafts, retries, cancelled or expired attempts and replays never consume it,
   and a cancelled attempt that reserved a slot releases it. Fix the counting in
   the presentation command (forward migration if the stored counter is wrong),
   with a test that cancels and expires attempts and still writes all eight
   languages, and one that hits the cap at exactly 65 distinct reviewed languages.
   Run: `/home/edge/projects/rezics/rezics-next/.temp/verify/.artifacts/qa/20261005t035153-05c7b1`.
2. **Fixtures with non-coordinate applicability.**
   `tests/qa/integration/search-grouped-native.test.ts` (SEARCH01/04/10) writes
   Statements whose applicability (`scope`) is not a coordinate, which G-1090 now
   refuses (`statement_applicability_not_coordinate`, decision 51). Change the
   fixture to scope those Statements by a real coordinate (a Work or a narrative
   continuity) so the test asserts the same grouping and counts. Check the other
   integration fixtures that write Statements for the same pattern and fix any
   you find. Run: `/home/edge/projects/rezics/rezics-next/.temp/verify/.artifacts/qa/20261005t035554-537c72`.
