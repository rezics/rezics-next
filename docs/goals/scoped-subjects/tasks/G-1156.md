## Outcome

`seedScopedSubjects` pushes about 50 helper rater sessions into
`state.sessions`, which later steps read as "the plan's people". The library
name lookup crashed on them. G-1146 filtered them out on the reading side. Fix
the class at its source:
- Keep the rater sessions in their own list, owned by the scoped-subjects
  step, so `state.sessions` holds only the plan's people.
- Then remove the reading-side filter G-1146 added, if it is no longer needed.

## Checks

`bun test scripts/dev/seed/` and `tests/qa/unit/dev-seed-plan.test.ts`;
`tsc -p scripts/dev/tsconfig.json`. Then run `task dev:seed -- --scoped-subjects-only`
followed by a full `task dev:seed` on the shared stack. Report the summary
lines. The full run may still report discovery staleness in
`checkPublicReads`; another task handles that.
