## Outcome

`apps/web/tests/scoped-subjects-journey-zone.ts` seeds the official
`franchise-wiki` Zone lazily. When another journey has already taken the
route segment, the script exits 3 and the Zone Character step is skipped. In a
full-tier run the g-743 and g-849 journeys seed first, so the step never runs
there.

Change the step so that, when the segment is taken, it adopts the existing
franchise-wiki Zone. It finds the Zone through its public read and points it at
the saga Work through the same public API a Zone owner would use. If that is
not possible for a principal the journey controls, say why in the handoff.
Do not leave a skip. The Zone step must run in a full-tier run as well as
alone.

## Checks

`task goal -- test apps/web/tests/scoped-subjects-journey.e2e.ts` alone. Then
run it with `apps/web/tests/g-849-*.e2e.ts` listed first, so the segment is
already taken; Playwright must pass both times with the Zone step executed.
Report Storybook results separately.
