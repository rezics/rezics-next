# Search and composition

## Outcome

Readers can discover permitted subjects, refine lists and render configured pages across verticals. Editors can
publish safe page compositions without adding a page implementation for each vertical.

## Done when

- A documented development OpenSearch setup supplies the required analyzer and regression cases.
- Real relays index semantic public projections, publish observable checkpoints and recover/rebuild into a new
  generation with reconciled coverage before switching it into use.
- Search, facets, typeahead, ordering and cursors have typed invalid, preparing, unavailable and restart outcomes.
  Filled pages or explicit readiness replace unproductive chains of empty successful pages.
- Current native disclosure protects results, exclusion, order and displayed fields after privacy changes, even while
  indexing is delayed. Public totals and facets require their own safe aggregate proof.
- Admitted plans cover filter, source and order together, with bounded direct execution or bounded preparation.
- Shared compositions validate against the registry, reject executable input and render each launch vertical from
  configuration. Aggregate page reads keep standalone authorization and declared budgets.
- Unavailable components are skipped and malformed declared slots render empty; supported siblings keep document order.
  Configured-list lookup uses those same slots and structural nodes, without crashing or exposing lists elsewhere.
  TypeList admits only native Search pages at or below its planned `body.limit`; oversized or non-search pages are wholly unavailable.
  Collection directory capability, recency/popularity order and catalogue publication of selected public A over live working B are Search-owned; omitted-source HTTP stays owner.
- The real default worker proves convergence, freshness, generation recovery and public rating-sort consumption.

Completion requires the scoped outcomes on main with recorded checks covering the promoted commit. Specified,
implemented, exposed, tested and promoted are separate states; a passing local check alone does not complete a Goal.

the opener. That group uses the displayed-locale catalogue label `subject_cover_group` for the current subject title.

target, address and Realm edits, ordinary completion, a replaced read or locale, an unmount, and a reader who has

including an empty terminal page and a later successful retry; directory source-status recovery does not retire it, a
newer Restart or Retry replaces an older request, and any other focus movement, visit replacement or unmount does.

## Dependencies

Requires semantic public projections and current native disclosure, content's rating projection, kernel relays and
checkpoints, Access and the web shell/client. Access resource-role compilation and Commerce offer anchors must finish
module initialization without importing HTTP request catalogues or Semantic definitions, so the Search supervisor can
start. Semantic first adopts shared filtered-list owner contracts; search
then implements admitted plans, preparation and freshness. Performance derives per-plan work budgets. Composition
slots and read descriptors are agreed with web before interface consumption.

## Acceptance

Use [search outcomes](../../specs/search-outcomes.test.ts),
[page outcomes](../../specs/pages-outcomes.test.ts), analyzer and native search/presentation tests, and composition
package checks. The [real-worker harness](../../services/kernel/test/search/README.md) defines process ownership
and default-worker proof; adopting that harness is not evidence that it passed. Cover anonymous, editor, suspended,
hidden and taken-down subjects, privacy reduction during lag, rebuilds and generation changes. Carry the filtering
examples from [feature design](../development/feature-design.md) through native plans. Follow
[verification](../development/verification.md) and the owning check runners for focused checks and growth evidence.

## External conditions

Production search capacity and deployment configuration must satisfy the measured budgets. Native acceptance uses
isolated development services rather than depending on production access.
