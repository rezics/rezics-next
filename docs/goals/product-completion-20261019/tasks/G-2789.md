No actual credits/cards/paid Claude usage or product changes.

Read goal-management settings/worker protocols and existing usage/launch/coordinator machinery. Main settings/review controls have another independent reviewed branch; avoid broad refactors and do not edit another checkout. Prefer a local ignored policy and a narrow existing owner extension to another scheduler. Implement Task-accessible refresh/status and safe admission of Claude work for THIS repository, not a global cap imposed on about. Keep policy/observations/tokens untracked; do not put account balances or quota timestamps in docs/briefs.

Respect token expiry, request timeout, 401/429 and missing/stale data; unknown capacity must fail closed for newly scheduled Claude tasks. Do not confuse seven_day-only cached output with available session capacity. Do not change extra-usage/billing settings. No paid fallback.

Policy needs an explicit verified-completion release, not an automatic inference from absent processes. When reserve is released, useful work may use the remaining allowance up to exhaustion; do not waste tokens solely to spend quota. Use existing task queues/coordinator wakes/jobs where possible; give manager an exact bounded operational command to keep observation and pending tasks moving across the reset without an interactive session or long blocking sleeps. No auto-dispatch of product work that has no reviewed brief/prerequisites. No automatic main landing.

If active-call interruption cannot strictly bound spend with the actual CLI, document the concrete boundary and use a conservative measured margin; never promise an absolute guarantee that the provider interface cannot enforce. Do not treat one caller's interruption as worker completion. Keep permissions, replay, ownership and restart behavior correct. Add only minimal explicitly needed owner files beyond claims and report them. No nested agents.
