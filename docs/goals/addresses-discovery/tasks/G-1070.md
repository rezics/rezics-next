## Outcome

G-1063 replaced the `discovery_source_changed` triggers on
`access.rating_aggregate_head` and `rating_aggregate_context` (dropped in
Access migration 1043) with outbox-event classification in
`services/main/src/modules/discovery/effects.ts`. Two gaps remain. Close both
with the smallest change.

1. **Out-of-band rating changes.** `tests/qa/fault-recovery/rating-daily.test.ts`
   fails on main (manager's pass, read-only:
   `/home/edge/projects/rezics/rezics-next/.temp/verify/.artifacts/qa/20261004t144742-8edc71/logs/fault-recovery-f13.log`).
   In `tests/qa/support/rating-aggregate.ts:322–328`, restoring the
   authoritative head after graph loss should advance
   `access.discovery_source_fence` by 4 (delete, insert, both updates). It
   now advances by 0 (Expected 11, Received 7). Find every path that changes
   rating aggregates without an outbox event Discover classifies (recovery
   restore, rebuild, repair). Make each one reach Discover's projections:
   either the path emits or relays a classified change, or the refresh worker
   honours a source fence again for those paths only. Then make the test assert
   the mechanism you chose and that the projection becomes current. If the
   change belongs in `services/main/src/modules/rating/**`, which is the
   scoped-subjects Goal's area, stop and report what is needed there instead
   of editing it.
2. **Target ratings** (agreed with the scoped-subjects manager, 2026-10-04).
   A `com.rezics.rating.observation-changed.v1` event for a target rating has
   no `work` or `main`. It carries `target`, the receipt's `rv:target`: the
   exact rated Resource IRI, which can be a projection. Work-owned grains
   (release, realization, occurrence) also carry `target`. Today such events
   fall back to a scope-wide rebuild of every Discover and rating scope.
   - A target rating is Work-local, on its owning Work, only if it changes an
     aggregate that Discover or the global rating projection reads (the global
     Context targets `rv:MainVersion`).
   - Every other target rating is irrelevant and advances the position only:
     projection, resource, Character and Person targets, and grains Discover
     does not aggregate.
   - Unknown actions keep the conservative rebuild.
   - scoped-subjects is changing `outbox/relay.ts` (its area) to accept
     generic-target receipts. Read `target` as described and do not edit relay.

Prove it with cost assertions in the G-1063 style on capability-named files.
An irrelevant target rating stays at G-1063's constant 4 graph calls and 46
SQL statements. A Work-local one stays at 8 / 126 at 1k and 10k Works.
`rating-daily` passes, and `/health/rating-ready` recovers after a restore.
