`tests/qa/integration/g-1025-ranking-cost.test.ts` fails. "Request cost
contract failed: postgresStatements: 13 > 12" for ranked reads behind 4, 16
and 64 privately read Books. The extra statement is constant, not growing with
the number of Books.

- G-1168 `83a06b8de`: change signals and the Content fence;
- G-1200 `18edae245`: checkpoint reset;

- **Fold the extra statement** into an existing one (for example, read the

- **Raise the contract**, only if the statement is necessary for correctness,
