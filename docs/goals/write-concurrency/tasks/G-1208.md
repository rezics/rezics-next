## Outcome

Main-wide regression (QA `20261005t213548-e73c3b`, fails alone):
`tests/qa/integration/g-1063-refresh.test.ts:252`. After a Work is published
during a pinned build and the build drains, the next base tick returns
`activated` where the test expects `advanced`.

G-1183 made a discovery catch-up pass complete and activate at its cut,
leaving later changes to the next refresh. So `activated` may be the intended
new behaviour, with the appended Work covered by the next tick. Decide which
it is, with evidence:
- **Intended:** update the test so it asserts the activation and then that
  the following tick covers the appended Work, so it is never reported as
  covered before then.
- **Not intended:** fix `discovery/refresh*.ts` so the result is `advanced` as
  before.

State which, and why. No change may let a later change count as covered.
