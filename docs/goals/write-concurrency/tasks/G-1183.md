## Outcome

G-1179 made builds converge, and two gaps remain.

1. **Co-reader generations are only built manually.** Under continuous shelf and
   rating writes, every activated co-reader generation goes stale at once, and
   reads withhold co-readers until someone runs a build.

   Product decision (manager, 2026-10-06):
   - Rebuild co-reader generations on a bounded schedule whenever their inputs
     changed, reusing the discovery refresh tick that already folds the logs.
   - Reads keep serving the last active generation while only signal changes
     (ratings, shelf states) are pending.
   - Changes that bear on privacy still withhold co-readers until a generation
     covers them: library visibility, principal deactivation, erasure and
     recovery.

   Distinguish the two kinds where the change rows are recorded. The privacy
   behaviour from G-1179 must not regress.
2. **Discovery catch-up can chase the head.** A catch-up pass that finds a new
   relevant change can schedule another pass, so continuous relevant graph
   writes can delay activation without bound. Let a pass complete and activate
   at its cut, leaving later changes to the next refresh. The no-skip rule
   stays: later changes are never reported as covered.

Smallest change: no new worker processes, tables only if a change kind needs a
column, no options.

## Checks

- **Extend `also-enjoyed-continuous-writes`:** a co-reader generation activates
  without a manual build under continuous shelf writes; reads serve it after a
  signal change; reads withhold it after a library-visibility change until a
  covering generation activates.
- **Extend `discovery-continuous-writes`:** activation under continuous
  relevant graph writes completes within a bounded number of ticks.
