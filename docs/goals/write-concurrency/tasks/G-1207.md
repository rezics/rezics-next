## Outcome

Main-wide regression (QA `20261005t213548-e73c3b`, fails alone): three cases in
`tests/qa/integration/g-523-agent-control.test.ts` predate G-1187's per-source
authority fences. The behaviour is preserved, but the observable details changed:

- `:574` expects claim to reject with "epoch is stale" after an edge
  revocation. It now rejects with "represented authority changed before
  claim".
- `:815` expects "admission scope epoch is stale". It now gets "selected
  authority changed before dispatch".
- `:870` expects the gate order `['work:create:root','access:representation-topology']`.
  Representation-edge revocation no longer locks `work:create:root`, so both
  concurrent operations now take only the topology gate, in the same order.

Update the assertions so they test the property, not the old wording:
- the claim or dispatch is refused because the authority it used changed;
- the two concurrent operations take their gates in one consistent order and
  neither deadlocks.

Keep every other assertion, and do not change product code. If any case
shows that a revoked authority is still accepted, stop and report it.
