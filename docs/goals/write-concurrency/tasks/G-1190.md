## Outcome

Two test-composition gaps found by main-wide regression.

1. **Directory publication.** `tests/qa/integration/g-939-discovery.test.ts:670`
   (QA `20261005t173906-585cb4`) creates a community Realm, runs `refresh()`,
   and reads `/v1/discovery/sections` at once. Since G-1165, the Realm
   directory is published by a background worker, so the `communities` section
   is empty for up to a tick.
   - Wait through the bounded poll helper G-1165 added
     (`tests/qa/integration/support/realm-directory.ts`). Do not add sleeps.
   - Check `g-979-browse-registry` for the same pattern. `g-964-discovery` is
     already adapted.
2. **Disclosure baseline.** G-1177 made public disclosure without
   `configureBaseline(fuseki)` fail loudly. G-1185 found two more compositions
   that reach it without the call: `growth-search-context.test.ts` and
   `tests/qa/fault-recovery/sys-revocation.test.ts`. Use the shared helper
   G-1185 added (`tests/qa/fixtures/access-baseline.ts`).

Change only these test files. Do not change product code or helpers.
