## Outcome

No application database connection sets a default `lock_timeout` or
`idle_in_transaction_session_timeout`. Paths that skip `SET LOCAL`, such as
Content core, comments and progress saves, wait without limit behind any lock.
A connection left idle inside a transaction holds its locks indefinitely, and
the snapshot horizon this Goal relies on stalls behind long writing
transactions.

Give every request-serving pool these defaults through the pool's connection
`options`:
- `lock_timeout`
- `idle_in_transaction_session_timeout`
- `transaction_timeout` (PostgreSQL 17+)

The pools are Main's Access, Content and relay pools (`services/main/src/index.ts:199-221`,
`relay.ts:17`) and Account's (`services/account/src/index.ts:20-24`). Use one small
helper so the values live in one place.

Choose the values from evidence, and list them in the handoff:
- **Lock waits.** Request paths already use 2 s `lock_timeout` and 5 s
  `statement_timeout`.
- **Long transactions.** Find the longest legitimate transactions (`rg
  "SET LOCAL (lock|statement)_timeout"`, rebuilds, imports, fixture builds,
  recovery capture, migrations). Pools that run them keep a larger bound or set
  it locally. Migrations and operator CLIs are out of scope.

Set `max_prepared_transactions = 0` where the local and deployment PostgreSQL
configuration lives, unless something uses prepared transactions. Record the
settings in the deployment owner's PostgreSQL section, in one or two
sentences.

Add no new configuration variables unless a deployment needs a different value.

## Checks

- **Unit:** the helper's test (`services/main/src/infrastructure/pg-pool.test.ts`).
- **New `tests/qa/integration/connection-bounds.test.ts`:**
  - a request pool connection reports the defaults (`SHOW lock_timeout`);
  - a lock wait fails within the bound;
  - a connection left idle in a transaction is closed.
- `task main:typecheck`, `task account:typecheck`
- `task goal -- test tests/qa/integration/connection-bounds.test.ts`, plus one
  long-running path you found (for example the discovery build or the fixture
  restore smoke), to show it still completes.
