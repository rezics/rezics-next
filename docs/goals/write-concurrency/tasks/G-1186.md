## Outcome

G-1182 scoped `CountingFuseki`
(`tests/qa/integration/support/counting-fuseki.ts`) so that background workers,
such as the Realm directory refresh, no longer count toward an operation's
graph budget. Static inspection found four files with their own counters or
injectors that background queries can still affect:
- `public-search-scale`
- `read-stability`
- `g-1021-reading-cost`
- `g-1022-reading-cost`

Move each onto the scoped counter, or apply the same scoping. Do not change any
budget value unless it was miscounted; if one was, give the arithmetic.

## Checks

Run each file three times through `task goal -- test`.
