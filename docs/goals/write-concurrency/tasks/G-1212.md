## Outcome

Main-wide regression. Two browser journeys fail twice in a row from a
worktree pinned at current main (QA run under
`.temp/verify/.artifacts/qa/`, the latest `e2e-playwright.log`):

1. **`apps/web/tests/g-841-q05-reviews.e2e.ts:73`.**
   `[data-review-aggregate][data-aggregate-grain="release"]` is never rendered.
   The release-grain review aggregate is missing.
2. **`apps/web/tests/home.e2e.ts:49`.** In the Filters popover, the "Korean"
   checkbox resolves but `check()` cannot click it within 30 s. It never
   becomes visible, enabled and stable.

Find the cause of each. Run the journey at the Goal start (`f08e85295`) and at
the suspects this Goal merged into the feed, review and ranking paths:
- G-1163: votes and keyset paging;
- G-1175: retained cursors and the web `projection.ts`;
- G-1168 and G-1200: review rank sequencer and rankings;
- G-1205: rankings statements.

If a journey also fails at `f08e85295`, say so and name the commit that broke
it instead.

Fix the product, frontend or backend:
- a missing aggregate is a data or read regression;
- a checkbox that never settles is a layout or rerender problem.

Change a journey only if it asserted wrong behaviour. Run journeys through
`task goal -- test <file>` (it builds the isolated stack). Do not run
Playwright against the shared stack.
