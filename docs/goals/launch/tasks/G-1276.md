## Outcome

Official Zone packages are built like third-party ones: they import only
React, the Zone SDK, Rezics UI, icons and their own files. `apps/web/tests/zone.test.ts`
enforces that and fails for `ai-workshop`, `light-novels` and `visual-novels`,
which import the host's `apps/web/features/address/path.ts` (for example
`zones/official/light-novels/slots.tsx`, `visual-novels/slots.tsx`; G-1240's
triage confirmed it is a real violation, not a stale test).

Expose what those packages need (an address or path builder) through
`packages/zone-sdk` as a small, typed function or a value the host passes in,
and switch the three packages to it. The host keeps owning address rules: the
SDK function delegates to data the host provides rather than copying
`features/address/path.ts` logic into the package.

## Do not

Do not loosen `zone.test.ts`, move host internals into the SDK wholesale, or
change address formats. Changing a package's files changes its approval
digest: say so in the handoff (the manager re-approves through `task dev:refresh`).
