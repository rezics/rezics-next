## Outcome

GOV05, GOV06 and GOV08 fail on main (regression run 9) before reaching their
assertions. The fixture helper `revision(title)` in
`tests/qa/integration/notification-delivery.test.ts` (about line 138) saves a
`content-shape-v1` draft whose JSON is `{ title }` only. The Content owner now
requires a text body for that model (`services/content/src/core.ts` around
line 511 → `retainedDocumentBody` in `services/content/src/document-body.ts`),
so `saveDraft` throws `ContentConflict('invalid Content body or notes')`.

Change the fixture to save a body as well, for example
`JSON.stringify({ title, body: title })`, and run the file. If a test then fails
for another reason, fix it only if the cause is the fixture's own data; report
any product cause under BLOCKERS with the failing line. Keep every assertion's
meaning; do not touch other files.
