## Outcome

The Storybook step of the first main-wide browser run (program, 2026-10-11)
failed 5 of 2,462 stories, which stopped the whole browser tier. The log is
staged at `.temp/ref/e2e-storybook.log`.
1. `features/home/home-page.stories.tsx` "More Topics Phone" (line 506): the
   "Contemporary fantasy…" link in the More Topics dialog is not visible.
2. `features/manage/queue.stories.tsx` "Chinese": no navigation named
   "领域管理"; the page has one named "管理".
3. `features/manage/decision-reasons.stories.tsx` "Simplified Chinese": no
   dialog named "保留 1 条举报中的内容".
4. `features/tracking/tracking-sheet.stories.tsx` "Forty Five Editions": no
   "Show more editions" button.
5. `features/work-maintainers/panel.stories.tsx` "Confirm" (line 53): the
   dialog's "Remove" button is not visible.

For each story:
- reproduce it alone;
- find the commit that changed the outcome;
- name the cause in one line:
  - a product regression, meaning the person now meets something wrong;
  - an intended product change the story did not follow;
  - a timing or visibility race in the story.

Then fix accordingly:
- a regression: fix the component;
- an intended change: update the story to the current product. A changed
  string must match the current catalogue, and you must say why the new
  wording is the intended one;
- a race: wait for the right state, never sleep.

Do not weaken an assertion to pass: an accessible name or visibility check
stays a name or visibility check.
