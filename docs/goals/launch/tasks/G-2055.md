## Outcome

Program class B, now affordable (2026-10-12 14:11 UTC); audit pass 1, class 8 (`.temp/ref/product-audit-pass-1.md`, section 8). A failed or retired constraint must not silently change a saved query's meaning.
- `apps/web/features/realm/routes.tsx:279` turns a failed registry read into `noReleaseFilter`, and lines 332-335 then serve ordinary browse despite the release choices in the URL.
- `apps/web/features/release-filter/registry.ts:59` skips selected fields whose facets are missing, malformed or not current, and `state.ts:22` parses only the surviving fields, so English+Windows can become Windows-only.
