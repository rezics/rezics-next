## Outcome

The program's bisect (G-1428) shows nine cases of
`services/main/tests/content-zone-revision-delivery.test.ts` failing on main
since launch's G-1284 (a66daf6a6), among them "exact public bundle bytes stay
unchanged after awaited rights" and "bundle withdrawal during exact Zone
rights refuses before Response". G-1284's new publication proof throws
`ZonePublicationUnavailable` (503) in that test's fixture, before the paused
rights and delivery phases the cases test are reached.

Find out why the proof refuses there, and report: which check, what it reads
and what the fixture lacks.
- If the proof wrongly refuses a valid publication (for example by reading
  state the publication path never writes, or by requiring authority the
  delivery route doesn't hold), fix it in launch's zone code. The test passes
  unchanged.
- If the fixture lacks state that production always has, don't change the
  test. Report the exact missing state and the production path that writes
  it under BLOCKERS; the manager decides any fixture change.

## Do not

Don't edit any test, and don't weaken the proof: a publication whose rights or
Content pin are gone must still refuse.
