| Rule | Sites | Test that must fail without the fix |
|---|---|---|
| A row reload costs ONE read: when a page is loaded, each row keeps the server position token of the page that held it (the cursor that page was requested with, `null` for the first page). It never restarts at the beginning, and a failure on another page cannot block it. | `apps/web/features/library/import-rows.ts:70` | Reloading row 4999 of 5000 makes exactly one request. | The guard is a CANONICAL SYNTACTIC rule, not data-flow analysis (decided for G-1925 and G-1977: validators that model data flow do not converge).
