## Outcome

For a Work composed of episodes, such as a long anime series, Main can't
seek by number yet. A numeric query to `GET /v1/reading-positions/{work}`
answers 503 with code `reading_seek_unavailable` (kernel's Episode-number
reader, planned after launch). The position chooser
(`position-picker.ts:62` turns any error into `PositionReadError(status)`)
shows its generic unavailable state, as if the whole read had failed.

When a numeric query is refused with `reading_seek_unavailable`, the chooser
says that jumping by number isn't available for this series yet, and that
the reader can browse the list or search by title. Paging and title search
keep working, and the query box keeps what the reader typed. Every other
error keeps today's state. Strings come in all eight locales, with
non-English marked for native review.

Add a unit test for the code-to-message mapping, and a story showing the
state at 390 px and 1280 px.
