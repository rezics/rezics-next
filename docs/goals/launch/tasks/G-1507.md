## Outcome

G-1459 found that a catalogue Work's page header and its generated cover name
the account that created or imported the Work (in the dev seed,
`catalogue-editor`) as if it were the author. An imported anime, manga, book
or visual novel is then attributed to whoever loaded it. G-1459 fixed this on
the anime and manga Zones' own cards and fact panel. The shared Work page
(`apps/web/features/work-page/`) and its generated cover still do it.

A Work's page names creators only from what the API reads as its credits (the
work-credits read, and the authorship Statements the page already reads):
- With credits, show them as now.
- With none, show no byline. Don't fall back to the creating or importing
  account in the header, the cover or the metadata.

A Work the reader wrote themselves keeps its author, through the same credits
read: authors of original Works are credited, so this is no special case. If
an original Work has no credit for its author, report where that credit should
come from under PROPOSED TASKS; don't fall back.

Add `apps/web/tests/work-page-byline.test.ts`:
- an imported Work with no credits has no byline;
- a credited Work shows its credited author;
- the cover text never contains the creating account's name.

Check the Work page stories at 390 px and 1280 px.
