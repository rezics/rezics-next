## Outcome

Found by launch's anime progress proof (2026-10-11). When a reader marks
episode 1001 watched without episodes 1–1000, the tracker says "No episode
watched yet". `apps/web/features/tracking/episode-progress.tsx:98` shows
`noneWatched` whenever `read.through` (the unbroken run from episode 1) is
empty, even though later episodes are watched. "Continue from" already uses
the episode after the furthest one watched (`read.next`).

Fix the summary so it never says nothing was watched when something was:
- With no unbroken run but a furthest watched episode, show the furthest
  watched episode, for example "Last watched: episode 1001". This is a new
  message in `messages.ts` and the seven locale files; machine-draft them like
  the neighbouring strings.
- Keep "Watched through N" and its progress bar for an unbroken run, and keep
  "No episode watched yet" only when nothing is watched.
- Use what the read already returns (the furthest completed part, as the
  continue action does); no new request.

Prove it:
- `apps/web/tests/episode-progress-summary.test.tsx`:
  - none watched;
  - an unbroken run;
  - only episode 1001 watched;
  - a run plus a later episode.
- Stories for the sparse case.
