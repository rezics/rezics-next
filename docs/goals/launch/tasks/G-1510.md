## Outcome

The dev seed creates catalogue Works with `authoring: 'own-work'`
(`createOwnWork` in `vn-catalogue-step.ts:457`, called from
`ln-vn-zones-step.ts`). Main then stores the acting seed account
(`catalogue-editor`) as the Work's native author credit. Since G-1507, the
Work page names creators only from credits, so that seed account still shows
as the author of every seeded visual novel and light novel. It's a false
credit in our own data, and journeys and screenshots inherit it.

The seed must write catalogue Works the way catalogue intake does: no author
credit for the acting account. Credit a creator only where the source names
one, as a credit to that creator's Agent.
- Use the API's catalogue (non-own-work) authoring. `services/main/src/routes/works.ts`
  and `modules/work/activate.ts` show where own-work writes the credit.
- Check `anime-manga-zones-step.ts` too, and fix it the same way if it uses
  own-work.
- If the API has no way to create a catalogue Work without an own-work credit,
  stop. Report under BLOCKERS the exact route and field you'd need. Don't
  write SQL.

Writes go through the API. Each seed step's test asserts that no seeded
catalogue Work has an author credit naming the acting account.
