## Outcome

At launch 247 Main operations are closed behind platform gates (gradual
opening, standing direction 11). A person never meets a closed capability as an
error, an empty box or a dead link: the web shows exactly what is open for the
viewer, and opening a group with a grant makes its surfaces appear without a
web change. Code, not review, keeps it that way.

The contract comes from trust-ops T5 (G-1235), which this task depends on:

- `GET /v1/me/platform-access` (public, works without a bearer) answers
  `200 { "groups": string[], "operations": string[], "generation": string }`,
  `cache-control: private, no-store`; anonymous viewers get empty lists.
- Generated OpenAPI marks each operation `x-rezics-exposure` (`public` or
  `platform:<group>`), and the SDK carries it.
- An operation is open for the viewer when its exposure is `public`, its group
  is in `groups` or its ID is in `operations`.
- A closed operation answers 403 with problem type `platform_closed`.

## Work

1. One platform-access read per server render (in the BFF), shared with client
   components through the shell. One helper, `operationOpen(operationId)`, fed
   by the generated exposure and that read. No second exposure table in the
   web.
2. The shared fetch layer turns a `platform_closed` 403 into a typed
   "closed" outcome that callers render as absent, never as an error toast.
   This covers a grant revoked between the access read and the call.
3. Gate every surface whose operation is closed for the viewer: saved-filter
   Home tabs and the pin picker, the mod-releases section on Work and Zone
   pages, type administration reads, and any other web call site the
   generated exposure shows as closed. Hide entry points (tabs, buttons,
   links) as well as content.
4. A followed Concept's Home tab must not vanish silently forever: until the
   public followed-Concept template (on the program's board: kernel C5 with
   T5) lands, keep followed Concepts reachable from their own pages and say
   nothing about tabs; do not fake a tab from another operation.
5. Guard the class: `closed-operations-guard.test.ts` lists every Main
   operation the web calls (through the SDK or a path literal) and fails when
   one whose exposure is not `public` is called outside `operationOpen` or the
   typed closed outcome.

Evidence for the current call sites: `/home/edge/projects/rezics/rezics-next/.temp/goal-launch/closed-web-callsites.txt`
and a grep over `apps/web/features` (saved-filter, home tabs, realm/read.ts,
zones/mod-sections.tsx, catalogue/types-read.ts). The approved matrix is
`/home/edge/projects/rezics/rezics-next/.temp/trust-ops/launch-matrix-draft.md`.

## Do not

Do not decide authority in the browser: the gate only hides; Main still
refuses. Do not cache platform access across viewers or in browser storage.
Do not add a web copy of the matrix, and do not change Main.
