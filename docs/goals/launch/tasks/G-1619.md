## Outcome

Program decision (2026-10-11): this is class A, part of L1. Every reply a
person posts pays this cost, and the Realm ranking corpus (G-1590) cannot be
built at the current rate (4.88 s per reply under QA load).

One reply through its four product commands (draft, identity, review,
placement) costs about **783 Postgres statements and 105 Fuseki requests**. The
guard `REALM_REPLY_WRITE_COST` allows 840 and 130. By command:
- Content: 14, 13, 12 and 24 statements;
- account verification: 54, 54, 18 and 72;
- access and other reads: the remaining ~520.

The cost is flat with Realm size (the asymptotic rule holds); the constant is
the defect.

**This session is analysis only. Do not change code.** Your RESULT is the
specification for one implementation session:
1. A per-command breakdown, measured with the shared meter
   (`foregroundCounted()`, `meterPool`, `meterFuseki`) on
   `services/main/tests/realm-reply-write-cost.test.ts`. For each command, list
   the module issuing each statement or request and how many times the same read
   repeats within the command and across the four:
   - admission;
   - account assertion;
   - membership;
   - Realm basis;
   - policy;
   - thread root;
   - Work head;
   - disclosure.
2. The architecture cause, in one paragraph. Why does each command re-derive
   the same facts? For example: no per-command context object, account
   verification per step instead of once per request, one-per-row lookups.
3. The exact change:
   - files and functions;
   - what is read once and passed through;
   - what is batched.

   Every authority, disclosure and fence check stays. A deliberate re-check
   (such as a closing fence) is kept and named.
4. The expected counts after the change, and the new itemised
   `REALM_REPLY_WRITE_COST`.
5. The tests that prove it: the existing 100- versus 1,000-thread equality; the
   decisions unchanged (admission, hidden root 404, sealed refusals); the lowered
   guard.

Keep it minimal: no new cache layer or second policy mechanism. Reuse the
session and admission objects that exist.
