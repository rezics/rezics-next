## Outcome

Kernel's G-1271 (3411b8982d0f) changed Main's `creditedName`: it is now either
a lexical name or `{ reference, status: "unavailable" }` when the name is
withheld by the private-name policy. A withheld name keeps the readable role
identity ("Translator", "Character") and links to the reference where the
viewer may read it.

Make every web consumer render both forms:
- `work-levels/connections.tsx` and `relation-rows.ts`;
- `entity-page/**` (fixtures and tests included);
- `wiki/entity.ts`;
- `zones/official/franchise-wiki/slots.tsx`.

An unavailable name shows a neutral localized label ("Name not shown") with
the role kept; never an empty string, the raw IRI or a crash. Update the
fixtures to the new shape. `franchise-wiki/slots.tsx` is an official Zone
package file, so its approval digest changes; say so in the handoff.
