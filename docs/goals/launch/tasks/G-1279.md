## Outcome

Every collection read tells its caller whether it returned everything:
`scripts/static/list-convention.test.ts` requires `response.complete`, plus
`items` for lists, and it is red on three launch reads:

- `GET /v1/me/library-loans` and `GET /v1/works/{id}/copies`
  (`routes/library-copies.ts`, added by G-1239);
- `GET /v1/resources/{resource}/discussion` (`routes/work-activity.ts`).

Make each response follow the convention the neighbouring list reads use
(read one passing example first, for example another `/v1/me/...` list), with
`complete: false` whenever a `nextCursor` is present. Keep the existing
cursors and paging.

Keep the matrix condition on `/copies`: it returns only the viewer's own
copies; another person gets an empty page and an anonymous request 401 or an
empty page (the integration test already proves it; keep it passing).

## Do not

Do not add the routes to the convention's debt baseline, change paging limits
or authorization, or change other routes.
