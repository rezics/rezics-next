## Outcome

G847 (`tests/qa/integration/g-847-reading-position.test.ts:380-383`, QA
20261008t101207-4129be) fails at the D2 rule ("G-835 treats Library 'read' as
finished, including Session projections"). After the reader clears progress
and finishes a Session on chapter 1, the early character's page is still 404.

The cause is launch's G-1365 (75474eed6). The reader's position became one
indexed owner range in the progress order index (`progress/order.ts`,
`progress/order-projection.ts`, fed only by `ProgressStore.write`).
`reading-position/chooser-position.ts` dropped Sessions and Library status as
sources, because paging them would walk the series. That bound is right. D2
was lost with it.

Keep both: project at write time. When a Session reaches `finished`, or a
Library status becomes read or finished, write the same completed-progress
record the order index already takes for that target, in the same transaction
or through the progress owner's existing idempotent path. The read side stays
untouched: one indexed range.
- Cost per write is constant: one target, no series walk.
- Undoing it is symmetric. A Session reopened or deleted, or a Library status
  moved back, removes only the completion that source contributed. A
  completion the reader recorded directly through progress stays.
- Replays and concurrent writes are idempotent, with one completion per
  target and source.
- The privacy rules of G-1365 and G-1414 hold. The projection is the reader's
  own private record, and an unreadable or foreign target is not projected
  and not revealed.
- Existing Sessions and Library statuses: if a backfill is needed, report it
  under PROPOSED TASKS with its size and cost. Don't add a migration without
  approval.

Tests in `services/main/tests/progress-from-sessions.test.ts`:
- a finished Session and a Library read each move the resume position;
- reopening each one moves it back, while a direct progress completion stays;
- concurrent finish and reopen;
- replay;
- a foreign target;
- the projection's queries are the same for a 10- and a 1,000-chapter
  series.

## Do not

Don't touch `reading-position/` or change any test assertion. G847 isn't
yours: G-1421 reruns it after this lands. Don't page Sessions or Library on
read.
