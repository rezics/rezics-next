## How to decide

Same rules as G-1240. A **stale test** (the product changed on purpose)
changes only after you show the new behavior is intended and name the commit
or decision; then it asserts the same user outcome against the current
product. A **product defect** in an unclaimed file (`task goal -- owner`) gets
the minimal fix, listed under OWNER CHANGES. Hand off with evidence instead of
fixing anything authority- or disclosure-related (item 4, if campaign art can
be written without Zone configuration authority, is a defect to report, not
to loosen), or anything in a file another task claims.

## Do not

Do not delete or skip tests, loosen assertions until they pass, or raise a
budget without the evidence above.
