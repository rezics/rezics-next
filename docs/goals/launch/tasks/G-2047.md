## The API filter is launch's (manager, 2026-10-12 12:35 UTC)

Main's Zone browse read has no year filter: `zoneBrowseQuery`
(`services/main/src/modules/zone-modules/contract.ts:70`) rejects it, and so
does `compileZoneBrowse` (`zone-modules/browse.ts:93`). Both files are in
launch's area, so this task adds the filter:
- `publicationYear` (a single year, or a bounded range if the contract's
  other filters use ranges) joins the browse query schema and the compiled
  graph query as a FILTER in the same read;
- the continuation and any counts or facets come from that same read;
- the contract document for Zone browse gains the field.
Then the web adapter sends the year to the API and drops the client
intersection. Tests: an API test where a year's eligible Works sit beyond the
first member pages, paged to a second page; the web second-page test.
`browse.ts` is changed by kernel's G-1972 (merging now) and `contract.ts` by
G-1855: rebase over G-1972 first; if a path is claimed, the manager lends it.
