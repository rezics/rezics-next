## Outcome

Two checks fail on main in launch's area:
1. `apps/web/tests/closed-operations-guard.test.ts` reports
   `features/realm-appeal/read.ts: /v1/realms/${id}/member-ban reaches
   getV1RealmsByRealmMember-ban (platform:realm-appeals)`.
   - The member-ban read calls an operation that is closed behind a platform
     grant, without `operationOpen` or the typed closed outcome.
   - Use the same gate other closed-operation reads in `apps/web/features`
     use, so a closed operation reads as closed (no request, no error panel).
   - Add a unit test for both the closed and the open case.
2. `task ast-grep -- scan` reports `no-assumed-direction` at
   `apps/web/features/zone-editor/navigation.test.ts:109`. That line asserts
   `pageNameOf` with `direction: 'ltr'` in its input.
   - If the test needs a fixed direction to describe a resolved value, use the
     rule's sanctioned form: read the rule in `rules/` for what it accepts.
   - Record a reasoned exception only if the rule's own docs allow one for
     this case.
