## Outcome

A signed-out reader can't tell a private Work from a Work that doesn't
exist. G-1372's journey (`g-530-m4.e2e.ts`, the private/missing equality
assertion) found the opposite:
- a signed-out request for a private Work returns HTTP 404;
- a nonexistent Work returns HTTP 200;
- both pages read "Work not found".

The status difference discloses existence, and a 200 for a missing page is a
soft 404. Both must return the same 404 status with the same body and
headers, apart from per-request noise. Find where the two paths diverge (the
route, the not-found boundary, or the API read it calls) and make both take
one path. Fix any equivalent divergence on the Work's other routes (read,
edit) the same way.
