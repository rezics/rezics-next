## Outcome

The maintainer's decision 55 (`docs/contracts/source-lifecycle.md#platform-imports-and-user-contributions`):
imported text, facts and covers show their source's credit and licence, and
user contributions carry the source their contributor gave. Kernel's rights
read is on main (G-1524). Work descriptions and statement reads expose each
material's rights:
- an `unassessed` status (which is also the hidden shape), or an `assessed`
  one with its instrument and obligations;
- obligation kinds: attribution, share_alike, notice_retention,
  change_indication, non_commercial, no_derivatives and other, each with its
  instrument and notice.

The field names are in `services/main/src/modules/work/read-contract.ts`
(`wikiDisplayObligations`), `read-header.ts`, `statement/subject-read.ts` and
`generated/openapi/main/public.json`. Read them there; don't guess.

Build one generic rights mark in `apps/web/features/rights-mark/`, with no
source-specific UI and no source names in code:
- `attribution` shows the notice text, linked to its source where the
  obligation gives one;
- the instrument (e.g. CC BY-SA 3.0) shows as a link to the licence;
- `share_alike`, `change_indication` and `notice_retention` show as short
  plain-language notes;
- `unassessed` shows nothing, never a guess.

Place it:
- under a Work's description on the Work page;
- beside a fact or statement row in the entity view (`views.tsx`), once per
  run of rows with the same rights, not on every row;
- on a cover, if the avatar read carries rights. If it doesn't yet, report
  that under PROPOSED TASKS.

It must stay compact on a phone (390 px) and readable in all eight locales.
Strings are in all eight, with non-English marked for native review.

Add `apps/web/tests/rights-mark.test.tsx`:
- assessed with attribution and share-alike;
- assessed with only an instrument;
- unassessed renders nothing;
- one mark for a run of rows with identical rights.

Add stories for these states, and screenshot them at 390 px and 1280 px.

## Mechanisms

rights-evaluation: consume — the mark only displays what the Rights module's read returns and decides nothing
