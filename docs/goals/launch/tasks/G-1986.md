## Outcome

L29 audit pass 1, class A1 (program, 2026-10-12 05:42 UTC). Principle: not
loading a persisted value is not an instruction to delete it. The full class
is staged at `.temp/ref/product-audit-pass-1.md`, section 1.

Today `your-edition.tsx:35` and `series-progress-panel.tsx:198` read only the
first edition page (20 items). A saved edition on page two is absent from
`offered` (lines 76–81) and becomes `edition:null` on an unchanged Save
(lines 92–97), and the UI reports success. Editions in later-page content
languages disappear from the chooser.

Fix: preserve the saved resource and revision until the person explicitly
changes or clears it. Load the current choice independently, and expose the
edition continuation (`tracking/api.ts:133`), reusing the paged pattern in
`tracking-sheet.tsx:22,73,175`. A failed continuation keeps the choice and
offers recovery. Do not merely raise the first-page size.

## Acceptance (as tests)

- With 21 or more editions, save edition 21, reopen each form, and Save
  unchanged: the resource and revision survive (both forms).
- Edition 21's language, outside the eight UI locales, is selectable.
- A continuation failure keeps the saved choice and shows a retry.
