## Outcome

Acceptance VIEW04 ("Malformed/unknown historical Block": safe isolated
rendering; no execution or authoritative rewrite) has no test. The backend scope
excludes it as rendered-client behaviour (`scripts/qa/backend-scope.ts`), so it
belongs to the web.

`DocumentBody` in `packages/ui/src/components/document-body.tsx` renders stored
Content documents for the Work reader, author notes, reply trees, Studio
conflicts and the Zone home document. Add
`apps/web/tests/historical-blocks.test.tsx` with one test whose name starts with
`VIEW04:`, rendering a stored document that holds, between two ordinary
paragraphs:
1. a node of an unknown type with content and attributes;
2. a known node with malformed attributes (for example an `image` without a
   source, a `heading` with a level outside 1–6, a `link` mark with a
   `javascript:` href);
3. text that looks like markup (`<script>…</script>`, `<img onerror=…>`).

The test asserts that both paragraphs render, that each bad node renders as one
isolated placeholder (or is dropped where the type has no visible meaning) with
no thrown error, that no markup is executed or inserted as HTML, that no
`javascript:` href reaches the DOM, and that the input document object is not
mutated.

If any assertion fails, fix `DocumentBody` so it isolates the node. Keep the
renderer's output for valid documents unchanged; do not add a new renderer.
