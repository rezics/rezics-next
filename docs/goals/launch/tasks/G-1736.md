## Outcome

Inventory item L15 (class A). The browser reaches Main through `/api/main`
(`apps/web/features/api/browser.ts:14`). The BFF turns the session cookie into
a bearer (`app/api/main/[...path]/route.ts:10`, `features/api/bff.ts:72`). So a
read the page means as public, such as a catalogue face, a concept's public
detail or a signed-out continuation, still runs as the signed-in person
whenever a cookie is present. Kernel (2026-10-11): the server-side read `mode`
is not scheduled, and launch needs nothing from kernel for this. Use the
existing anonymous browser option (`{ anonymous: true }`, credentials
`omit`); a helper without a token is not proof of anonymity.

Kernel's call-site inventory is staged at
`.temp/ref/kernel-g1713-launch-handoff.md`. It lists every browser call site with
the mode it should have:
- **public**: the call is meant as the same answer for everyone;
- **viewer**: a signed-in personal list, picker, Home tab or Following topic;
- **Mine**: the person's own private reads.

The earlier launch list of public reads that send a cookie without an acting
subject:
- `concept/concept-works.tsx:26`;
- `discover/query.ts:14`;
- `discover/shelf.tsx:88`;
- `communities/setup-checklist.tsx:26`;
- `post-composer/composer.tsx:142,178`;
- three unscanned cookie clients.

1. For each browser call site in the inventory and that list, decide public or
   personal from what the page shows a person, and say which in RESULT. First
   pages and continuations of the same list must take the same transport.
2. Make every public one use the anonymous browser option. Leave viewer and Mine
   reads on the session.
3. Add `apps/web/tests/public-reads-anonymous.test.ts`:
   - each public browser read is built with credentials `omit`;
   - each personal read keeps the session;
   - a list's continuation uses the same transport as its first page.

   Use the clients' request construction; no network.
4. Report call sites outside your claim under OWNER CHANGES instead of editing
   them.

Do not:
- add a server-side mode parameter;
- change a route, or Main;
- make a personal list public to get around a refusal.
