## Land review 3 (program, 2026-10-12 09:00 UTC): the last short round, then merge regardless

Both user-visible defects must be gone:
- **Triage is merged by revision.** A badge poll never overwrites a row's
  triage flags or `triageRevision` with older state; Save's success always
  lands (`notifications-view.tsx:402`). Story: Save, a poll starts, Save
  succeeds, the row shows saved, and the next edit succeeds.
- **The count fence is keyed per producer.** A triage or page response
  neither discards nor is discarded by a count. A reset's recount always
  completes (`unread.ts:70`). Story: reset, delayed count, then Save or Show
  more, and the badge shows the generation-2 count.
- **The cost fixture builds production-shaped history.** It commits enqueue,
  then triage, separately, at three sizes, and the bound holds
  (`notification-pagination.test.ts:363`).
