## Outcome

Regression run 5 (program G-1487, cluster `library-import-still-pending`)
fails 4 integration files deterministically since 131ee7729 ("Make import
lease expiry cancel the apply and seal atomically with the apply receipt").
`apply-worker.ts` is named as the owner. After an interrupted apply, the
receipt stays pending with 0 completed. The tests' resumable path ("interrupted
apply and resumable complete bundle re-import") expects the job to resume and
complete. Since that commit, lease expiry cancels the job instead of letting a
new lease resume it.

Make lease expiry release the job for resumption, not cancel it:
- a later worker or a resume request takes a new lease and continues from the
  sealed progress;
- a cancel stays an explicit act;
- keep what 131ee7729 fixed: lease expiry and the apply receipt seal
  atomically, and no row is applied twice.

Find the test cases that pin each behaviour and keep them all passing.
