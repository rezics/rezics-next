## Outcome

`POST /v1/compositions/{id}/stages` has required the `platform:catalogue-import`
exposure since G-1235 (ffa8883e4). Four reading-position integration tests
build Main without platform access, so stage creation answers
`403 platform_closed` before anything they test runs (QA
20261008t032120-ae05fb): g-954's second test, g-1021-reading-cost,
g-1022-reading-cost and g-1022-multilingual-stage.

The fixture principal that creates stages must hold the ordinary
catalogue-import platform grant. Give it that grant through the same API or
fixture helper other tests use for platform grants, so the app is built the
way production builds it. Use one shared helper if two or more of these files
need it.

## Do not

Change no product source, no exposure and no assertion. Don't bypass
`bindPlatformExposure`, and don't seed with raw graph writes. If a test then
fails for another reason, report it with the QA ID; don't edit around it.
