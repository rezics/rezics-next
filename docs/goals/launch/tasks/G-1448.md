## Outcome

The program's bisect (G-1428) routed two failures on main to launch:
- `apps/web/tests/zone.test.ts` fails because
  `apps/web/zones/official/franchise-wiki/slots.tsx:24` (`withheldCredit`,
  from G-1317 6de68bf48) holds the literal `https://rezics.com/id/`, which the
  official-package scan forbids. A package can't know Main's IRI form. Decide
  "this is a reference, not a name" without the literal, the way the other
  official packages test a withheld value: through the SDK or the value's
  shape the platform documents. Keep the behaviour: an empty value or a
  reference is never printed as a name.
- `services/main/tests/saved-filter.test.ts:84` reads
  `migrations/access/1331_saved_filter_inventory.sql`, which G-1231's merge
  renumbered to `1428_saved_filter_inventory.sql`. Point it at the new file and
  change nothing else in the test.
