Assertions, for one anime and one manga:
1. The hub shows the Work's recorded date (first release or publication) as
   the API returns it, and no date when none is recorded.
2. A reader chooses another release or edition (by keyboard in the browser),
   saves it, reloads, and the hub names the chosen one.
3. A second reader still sees the default; preferences are per reader.
4. API only: concurrent saves of two choices settle on one, and replaying the
   same request returns the same result.

Change no product code. If an assertion fails for a product reason, stop and
report the cause under BLOCKERS. Report every exact test title; the manager
records them in the registry.
