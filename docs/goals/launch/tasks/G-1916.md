## Outcome

Program decision (2026-10-11 21:57): the public search response's `population`
(a count of the whole public inventory before disclosure) is removed. It is the
one number the gated-reads design says a read must not certify, and a reader does
not need it. Kernel removes the field from Main in its public Content step, after
this lands, so main is never red.

The web reads it in one place:
- `search-results.tsx:60` renders `t.searched({ count: page.population, scope })`
  ("Searched N published texts in {scope}");
- the value comes from `read.ts:103` (`population: page.population`), typed
  at `types.ts:57`.

1. Make the web independent of the field: drop `population` from the page type
   and from `read.ts`, and do not read it even if Main still sends it.
2. Replace the `searched` line with the scope alone, for example
   "Searched published texts in {scope}", with no count. Keep `t.count(page.total)`,
   the match total, as it is. Update the message in all eight locales and
   delete the plural form that is no longer used.
3. Update the tests and stories that asserted the count. Run the search story
   file and review its PNGs (English and one CJK locale).

Change no Main code.
