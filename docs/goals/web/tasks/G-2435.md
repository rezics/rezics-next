## Outcome

On main at 03:41 UTC on 2026-10-14, `bun test apps/web/` in one process gave 3,734 pass and 45 fail. Seven files fail when run alone (`.temp/ref/web-red-alone.txt` has each first error): `g-516-localized-adapters` (1), `public-read-credentials` (1, "browser Main reads match the route class"), `closed-operations-guard` (2), `g-855-library-import` (2: `library/loans/books-loans-recorded-page.ts` and its test compare a title as text), `release-browse-signed-in` (1), `features/work-page/hub-actions.test.tsx` (2). `game-progress.test.ts` passes alone (42 of 42) and fails 36 tests when other files ran first in the same process; `g-944-shared-browser` failed once in that run. A landing gate runs its selected files in one process, so both kinds stop landings, and gates now excuse some of these as failing on main.

Afterwards every one of these passes alone and in one process with all web files, and each fix is the right one:

- For each failure, find what changed (`git log -S` or bisect on the file and what it imports) and decide which side is wrong: the product, or a test that still describes a behaviour main changed on purpose. Say it per test in the handoff with the commit that changed it.
  - Known for one: `hub-actions.test.tsx` "workshop keeps copy text … gating Try it" fails since `0286b4040` (Try it destinations are approved by the host and passed into the Zone card slots; the card alone renders none). The gate moved to the host and is tested in `apps/web/features/zones/ai-workshop-actions.test.tsx`, so this case must render through the host or go, not be bent.
- A test whose subject moved elsewhere is moved or removed only where the new place proves the same thing; name that test.
- A product defect inside the claim is fixed with its failing test first. A product defect outside the claim is not fixed here: hand off its file, line, request and expected answer, and the program routes it.
- For the one-process failures, find the file that leaks into `game-progress.test.ts` (state left in a module, a global, a timer, a DOM) and stop the leak where it starts. Use the module replacement helper on main (G-2416); do not reorder files or isolate the victim.

Do not build: a skip, an exemption list entry, a weaker assertion without the reason above, a change to the gate's selection or retry.
