## Outcome

Implement the program-read design in this task and attempt. The host decides
whether the viewer may open the Hub Work and passes the result as data: add one
optional Try destination field to the slot item or its props. Prefer
`WorkCardSlotProps.tryHref?: string`, filled by the host only for an open Hub
Work, unless the actual item construction requires the field on `ZoneWork`.
AI Workshop shows the Hub Try action only when that field is present, using
the supplied destination and host Link. Non-Hub actions continue using `work.href`.

D129 passes without weakening the official Zone package import boundary.
When `getV1HubWorksById` is closed for the viewer, an AI Workshop Hub card's
Try action stays absent; when it is open, that action has the same destination
and localized link behavior as today. Non-Hub cards retain their current action.
Official packages use only React, the SDK, Rezics UI, icons and their own files.

Evidence: `apps/web/zones/official/ai-workshop/slots.tsx` imports the web shell's
`OperationGate` across the package boundary and wraps its Hub action with
`operation="getV1HubWorksById"`. `apps/web/tests/zone.test.ts:472` rejects the
import. G-2201 correctly left the gate intact because its claim prohibited SDK
changes. The existing SDK `ZoneSlotProps` supplies a host Link but no viewer gate.

The web shell remains the sole decision owner. The SDK receives no gate
component, evaluator or operation identifier. Remove the official package's
OperationGate import without weakening the package-boundary assertion.
`cardRenderer` in `zone-home.tsx` constructs `WorkCardSlotProps`; `WorkshopCard`
and `Actions` in `slots.tsx` consume them. The present gate reads
`useOperationGate` in the client shell, while `cardRenderer` is synchronous.
Trace the existing host decision before wiring the field. If the slot host
cannot know the answer when it builds the item, hand back the exact place where
it must learn it, with the current data flow and missing input, before adding
anything larger. Do not replace unknown with open or silently omit open actions.
If an additional host file is needed, claim it before editing; another task's
claim is a handoff, not permission to change it.

Do not build: an SDK gate component or evaluator, an SDK operation identifier,
another permission store or evaluator, a new API operation,
server-side authorization replacement, broader imports, changes to unrelated
cover props, or a test exception for AI Workshop.
