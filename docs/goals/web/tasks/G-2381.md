## Outcome

A Zone whose API presentation names an attached Realm serves that Realm's
browse page in the site's production frame when `/z/<zone-key>/browse` has
no mount. Its Space address may carry only Zone capability. A Zone whose
presentation names no Realm stays standalone. The Realm's Browse and Works
links use its attached Zone's canonical address, including when the Realm
and Zone occupy different Spaces.

## Design note

The Realm community frame's site link and the attached Realm's browse route read `GET /v1/realms/{realm}/zone`.
Resolve that Zone's presentation address through existing operations; add no API or store.
