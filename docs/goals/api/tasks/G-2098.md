**Rights and credit for the publishing rows**

For both hub and catalogue proof, the proposed minimal fixture is an original, synthetic game description/composition:

- Text publication uses `POST /v1/contribution-publications` with `rightsBasis: original-contribution`; structured Work publication uses `POST /v1/work-publications` with the same literal basis.
- Own-work creation records the supplied author Agent as a native author credit. The credited author must be the fixture author’s Person, not the operator, moderator, importer, or REZICS.
- Main selection and Realm adoption are separate authority decisions. Publishing uses contribution/Work publication authority; Main selection uses `publication.select`; Realm adoption uses `publication.adopt`.
- Imported catalogue facts must retain source/contributor provenance and source-reported creator credits. Catalogue submission is not evidence of owning the game or permission to publish copied description/art.
- Work headers expose `descriptionObligations`, including `unassessed`. That value is not permission. No real game text, artwork, or external licence should be invented for the pilot.

The current G fixture credits `game-editor` through own-work creation, but never publishes or adopts its games. It therefore proves neither publishing row’s rights/credit outcome.
