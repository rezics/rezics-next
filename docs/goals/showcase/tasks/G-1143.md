## Outcome

Four small fixes found in review.

1. **Cropped art before renditions.** While a selection's width renditions are
   still pending, Zone heroes and the Work header draw the uncropped original
   in a frame sized for the crop (`deliveredShowcaseImage` in
   `apps/web/features/realm/adapt.ts`). Draw the Use's `xywh=percent:` crop from
   the original instead, as the editor does, so the frame never shows more or
   less than the author chose.
2. **Editor preview in view.** On wide screens the showcase art editor's
   preview stays in view while the form scrolls.
3. **Kind verbs on the Work page.** Its library action reads "Want to read"
   for games and software. Use the Work kind's verb as showcase slides do
   (read, play, install or use, open a recipe) wherever the Library's statuses
   allow; if a status cannot be named per kind without a model change, say so
   in the handoff instead of building one.
4. **Campaign seed.** Give the seeded link slide (`autumn-contest`) campaign
   art through `POST /v1/zones/{id}/campaign-art` (G-1140), idempotently.

This task shares the worktree `showcase-ui` with G-1124. The manager runs the
one web dev server there and lists it in `.temp/goal/shared.md`; start none of
your own, and commit only your claimed paths.
