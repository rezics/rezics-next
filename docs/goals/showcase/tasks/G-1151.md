## Outcome

Fix findings F4, F8 and F9 of the independent review
(`/home/edge/projects/rezics/rezics-next/.temp/research/showcase-review-report.md`;
read each finding there first).

1. **F4.** A read offers a codec's `srcset` candidates only once that codec's
   ladder for the crop is complete; until then it offers none, and the stage
   draws the crop from the original.
2. **F9.** The worker decodes each source once per crop and writes every width
   and codec from that decode. The stage serves AVIF through
   `<source type="image/avif">` before WebP (AVIF is Baseline widely
   available), so the encoding work is used.
3. **F8.** The pending-crop fallback draws exactly the authored crop in every
   engine (Firefox and Safari included), not only where `object-view-box`
   exists; for example, size and offset the image inside an overflow-hidden
   frame from the crop percentages.

Smallest change; disclosure and the Zone read are G-1150's.
