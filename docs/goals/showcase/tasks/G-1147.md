## Outcome

1. **Uploaded art is not hidden by default.** Art uploaded in the Work
   showcase art editor and the Realm showcase editor arrives with an unknown
   NSFW value, so the stage masks it for every reader until someone labels it.
   The [media contract](../../../contracts/media.md#image-presentation) lets
   client classification initialize an unknown NSFW value; the document editor
   and profile settings already do it (`apps/web/features/document-editor/image-inference.ts`,
   `record-inference.ts`). Run the same classification for every showcase
   upload, record it, and let the author mark an image as adult content
   themselves; explain in words what readers will see.
2. **Shared art cards.** The file picker, drop area, panel and footer exist
   twice (`showcase-editor/cards.tsx` and `showcase-zone-editor/art-card.tsx`);
   keep one.
3. **Japanese at 390 px.** The Work art editor's preview window switch
   overflows; apply the fix the Realm editor's `preview.tsx` uses.
4. **Kind words everywhere.** The Library's labels (`features/library/labels.ts`)
   and the Work page's "N want to read" count (`work-page/ratings.tsx`) use
   `shelf-words` as the Work page action does (play, cook, use). Stored
   statuses do not change. New strings in all eight locales.

Start no dev server; the manager runs one for this worktree and lists it in
`.temp/goal/shared.md`.
