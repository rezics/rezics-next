## Outcome

A chapter Post can carry an author's note before and after its text, kept apart
from the chapter's text as
[Posts, texts and Works](../../../contracts/work-and-release.md#posts-texts-and-works)
decides: an author's note is a separate part of the Post, not counted,
translated or carried into a release of the Work.

1. **Shape.** A Post's Content revision may hold `notes: { before?, after? }`,
   each a document body in the same format as the chapter text and bounded
   (8,192 UTF-16 units each). `body`/`document` stay the chapter text only, so
   every consumer that reads them (length, word counts, search MatchUnits,
   feed and notification excerpts, fixed releases, translation basis) excludes
   the notes without change; prove that with tests rather than editing those
   consumers. Only Post targets admit notes. Add a new content shape version
   if the stored model changes; never edit a persisted profile in place.
2. **Languages.** Notes belong to their language variant: a translation may
   carry its translator's own notes or none, and a missing note is never
   filled from another language.
3. **Reads.** Exact chapter reads return the notes beside the text.
Steps 4 and 5 (reader and Studio) are a second phase: the manager resumes
you with their claims after the surfaces task (G-1080) merges, because it holds
those files now. Finish 1–3 first and exit with a handoff.

4. **Reader.** Shows the notes before and after the chapter text, labelled as
   the author's note in all eight UI locales and visually distinct from the
   text; absent notes leave no trace.
5. **Studio.** The chapter editor edits both notes per language variant, with
   the same draft, publish and conflict behaviour as the text.

Smallest change that satisfies the decision. Do not build: notes on Works,
replies or contributions, note comments, note search, rich note layouts beyond
the existing document format, or a separate note resource.

Generated artifacts (`generated/**`, `packages/model/src/generated/**`) are
regenerated with `task gen` and allowed at merge; do not hand-edit them.
