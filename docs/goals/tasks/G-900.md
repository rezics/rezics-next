## Outcome

Reviews of G-867, G-838 and G-839 each found user-facing strings naming the
internal service "Main" ("Main didn't answer", "Main refused this change",
"Main is still applying this decision"). Readers don't know what Main is.
After this task no UI catalog names an internal service (Main, Access,
Content, Account relay, Fuseki, Jena), and a test keeps it that way.

## Approach

- A catalog test (`apps/web/tests/g-900-service-names.test.ts`) loads every
  message catalog in every locale and fails on the service names as whole
  words, with an allowlist for real domain terms: "Main Version" (a release
  term), "Main navigation" (landmark label).
- Reword each offender in all eight locales to say what the reader needs:
  "The server didn't answer. Trying again usually helps.", "This change was
  refused: …", "This decision is still being applied …".

## Do not build

No copy changes beyond the offenders; no new keys.

## Checks

`task i18n:check`; `bun test apps/web/tests/g-900*`; `task web:typecheck`.
