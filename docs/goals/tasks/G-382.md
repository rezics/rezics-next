## Outcome

The maintainer named Goodreads' author page as a reference
(https://www.goodreads.com/author/show/16669648.Ferdia_Lennon): portrait,
name, facts, a short bio, the author's books with covers and ratings, stats,
followers, and links onward. Study it and two others (StoryGraph's author
page; Open Library's `/authors/OL…A`) in a real browser, then build REZICS's.

Today a native author (Lin Mei) has `/@lin_mei`, which shows "Author" with
Works first. An external author has nothing: Jane Austen, Arthur Conan Doyle
and the other classics' Open Library authors appear on Work pages and Zone
cards with a name and a generic icon and lead nowhere.

- **External authors.** `/authors/open-library/<OL…A>` (locale-prefixed like
  every public page) for every author a REZICS Work credits. Show what the
  source model allows: the name and other factual fields (lifespan, key
  identifiers), never copied prose. Source author facts are projected
  field by field with provenance (`source/author-name.ts` projects only
  `/name`, basis `facts`); extend that projection to the factual fields you
  show, with the same provenance, cost bounds and tests. Bios are not
  facts, so leave them out and say in the handoff how a REZICS-native bio
  could be written instead.
- **Every author page** (external, and the native profile's author view if
  it helps to share components): the author's Works on REZICS, cover-first,
  with the average rating and count; totals (Works, ratings, readers);
  follow if the model supports following an author, otherwise say so; and
  a "More from this author's readers" row if G-381's also-enjoyed read has
  landed on `main`, otherwise leave a slot.
- **Reach.** Link author names to their page wherever the author is shown.
  Work pages and cards are held by G-375 and G-377: list their call sites and
  the exact href helper under PROPOSED TASKS instead of editing them.
- Look like Goodreads' author page in quality: clear hierarchy, cover-first
  Work list, generous whitespace, the same `WorkCover` as the catalogue.
  Add English and zh-Hans strings only.

Migrations: Content 410–414 are reserved for you. Main reads go through Eden,
as other features do.
