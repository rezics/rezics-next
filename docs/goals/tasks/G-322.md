## Outcome

G-309 put names and ratings on discovery and paged search cards but left two
gaps, so many cards still show no author:

1. **Open Library author names**: source conversion keeps author keys but no
   names. Retain author display names from Open Library under the rights
   decisions already recorded for that source (`docs/research/source-data-rights.md`
   and the source rights records in code), with provenance, refresh and
   removal, and resolve them for credits on discovery, search and Work pages.
2. **Unpaged search cards**: `/v1/queries` results lack the card fields
   (credits with names, rating summary, tagline, completion, cover). Design a
   bounded hydration that keeps the query's whole-request cost bounds — for
   example hydrating only the first page window and returning a cursor for
   more — and say why.

Backend only, no dev servers.
