## Outcome

G-833 (merged) accepts external evidence URLs on realizations in its schema,
but `services/main/src/modules/realization/command.ts` serializes them with the
native-only `iri()` helper, so a command with an external URL returns a
reconciling response instead of a committed one. After this task an external
evidence URL is written as the kind of value the realization profile declares
for evidence (check the profile; use the existing helper for external URLs
elsewhere in Main), and the command commits.

## Do not build

No profile change, no new helper if one exists.

## Acceptance

API: create a realization with an external evidence URL → committed, and the
read returns the URL unchanged; a native IRI still works.
