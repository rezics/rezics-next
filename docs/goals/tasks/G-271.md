## Outcome

The scope bar and the search scope selector can only offer the Realm named in
the URL, because there is no public way to list or find Realms. Add a public
Realm directory: paginated list (by activity, members estimate, newest) and a
name/description search (en and zh-CN, CJK-aware), returning the public Realm
profile fields published by G-249 (name, icon, short description, member count
exact/estimated/unknown), with disclosure rules (private Realms never listed)
and a cost contract in the style of the other read families
(`services/main/src/modules/realm-reads/**` is the template).
