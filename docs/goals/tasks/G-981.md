## Outcome

Ten stories still fail on `main` (`.temp/manager/verify-g978-stories.log` in
the main checkout, read-only):

1. language-select (7) and studio-work "Chapters": G-958's shared focus helper
   rejects with "Focus did not settle inside the target". A combobox keeps

   keep it strict enough to catch the original lost-keystroke flake.

   `/en/z/ai-workshop/w/…`. This is a product bug: official Zone package links
   must carry the locale and go through the address module (the zone SDK's
   link helpers). Fix it there for every official package.
3. work-overview "Global": an attribute assertion fails; find whether the link
   or attribute regressed and fix the right side.
