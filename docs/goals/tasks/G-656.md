## Outcome

R49 B1 is gone. `/v1/game-facts/{work}` and `/v1/software-facts/{work}` no longer
exist; migration `965_drop_vertical_facts.sql` drops `access.game_facts`,
`access.game_facts_receipt`, `access.software_facts` and
`access.software_facts_receipt`; the seed no longer writes facts documents and instead
gives each seeded game and app its `pitch` as the Work's English tagline. Nothing in
Main or the web reads these tables today (only `official-zones-step.ts:327-363`
writes them), so no reader changes.

## What to read

- `.temp/research/R49-silo-audit.md` row B1.
- `services/main/migrations/access/835_game_facts.sql`, `836_software_facts.sql`.
- `services/main/src/modules/game-facts/*`, `software-facts/*`, `routes/game-facts.ts`,
  `routes/software-facts.ts`, and their wiring in `app.ts:40-41`, `index.ts:91,425-427`,
  `routes/dependencies.ts:194-197`.
- `scripts/dev/seed/official-zones-step.ts`: `verticalFacts` (327-363), its call (823)
  and `describeWork` (around 150), which already writes taglines.

## Approach

Delete the two modules, both routes, their wiring, the two unit tests and the QA
integration test. Write the drop migration (`DROP TABLE IF EXISTS`, receipts too;
never edit 835/836). Replace `verticalFacts` with a loop calling `describeWork` with
the pitch as tagline (seed key per game/app, English). Keep `games-catalogue.ts` and
`software-catalogue.ts` unchanged: they are source data for the deferred Games and
Software manifests.

## Do not build

No replacement store, Statements import, property definitions, release records, media
or relations: nothing reads these facts, and Games/Software are deferred. Do not touch
the web or `packages/zone-sdk` (G-658 removes the SDK types), `modules/package`,
`modules/zone-modules` (G-657) or generated OpenAPI (the manager regenerates).

## Acceptance

API: on an isolated backend in the worktree (`task dev -- --backend`), migrations
apply, the four tables are absent, `GET /v1/game-facts/<any>` returns the router's
404, and a fresh `task dev:seed` finishes with the games and apps carrying their
taglines (read through the Work read). Class guard: `services/main/tests/g-656*.ts`
asserts that no route in the Main app's OpenAPI operation list matches `-facts/`;
G-659 adds the domain-table check.
