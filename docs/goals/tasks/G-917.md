After this task operators configure a primary and a backup responder
(Account subjects, operator configuration — the maintainer has not named the
backup yet, so the template says so), and a bounded durable job alerts the
primary when a safety deadline approaches and the backup when it passes or

## Approach

Follow the reviewer's fix brief. Reuse the notification producer and
Account-owned delivery; one small table only if a durable alert record needs
it (Access migration 983 reserved). Recovery: a restarted Main re-drives
unsent alerts idempotently; a failed provider acknowledgement is never
reported as delivered.
