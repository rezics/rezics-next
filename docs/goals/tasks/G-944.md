## Outcome

Read [Sidebar](../../plan/frontend.md#sidebar) and
[Follow, Join and notification](../../contracts/community-interactions.md#follow-join-and-notification).
G-938 is putting the model in Main and is in review; it is not on `main` yet.
Read its committed contract with `git show goal/g-938:<path>` (routes, schemas,
`generated` OpenAPI after `task gen` in your worktree is not available for it),
keep the web's Main client for it in one file, and code against it; the manager
merges G-938 first and adjusts that file if review changes the contract. Its
model: Follow of any target with level, source and pin,
Join that writes its follow, `GET /v1/me/memberships`, Watch, and the list shape
`{ items, nextCursor, complete }`. Today the sidebar shows Realm and Zone follows
capped at 8 with a "Show all" that can never appear, the web follows after a
join with a second command, and buttons say Follow or Join without a level.

After this task:

1. **Sidebar** in the documented order: Pinned; Communities and sites (joined and
   followed Spaces by recent activity with new-activity dots, a few by default,
   "Show all" expanding an inline list with a name filter and continuation);
   Moderation; Official Zones only while the reader follows nothing. Phone uses
   the same model in the navigation sheet.
2. **One relationship control** (`features/relationships/`) used wherever a
   person, Space, Work, Concept or Collection is shown: Follow or Join as the
   primary action, the notification bell (All, Highlights, Off) once related,
   and an overflow with Pin, Mute and Block. Joining is one command; leaving
   keeps an explicit follow. Replace the current Follow, Join, Concept follow
   and proposal Watch controls with it.
3. **Following manager** at `/{locale}/following`: every follow and membership
   with search, type filter, sort, continuation and bulk unfollow, level and
   pin, built on the shared `EntityPicker` patterns and Main's list shape.
4. Stories for each state (signed out, empty, thousands of follows, failed
   read) in all eight locales, and a browser test against the shared stack:
   follow, set a level, pin, join, leave, unfollow from the manager, and the
   sidebar updating.
