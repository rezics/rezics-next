## Outcome

REZICS must be able to publish public-domain books, the classics above all,
without claiming they are the publisher's own work. Today it can't. G-387
stopped before seeding Project Gutenberg texts
(`.temp/goal-orchestration/runs/G-387/attempt-1.last.md`) for these reasons:

- `content-publication/draft.ts` hardcodes draft provenance as
  `admitted-original-contribution-v1` with `rightsBasis:
  'original-contribution'`;
- `POST` content search in `routes/content.ts` and the
  `content-search-eligibility-v1` shape (`rv:rightsBasis hasValue
  rv:OriginalContribution`) accept only original contributions;
- the rights module already knows `public_domain` assessments
  (`modules/rights/schema.ts`), but nothing connects an assessment to a
  Content draft.

Make a second, explicit path. The rules are the manager's decisions:

- **Who.** An Agent who may edit the Work (the North Star Editions
  organisation in the seed) may publish a text as public domain only while
  the Work has an **accepted `public_domain` rights assessment** on record.
  The draft cites that assessment. If the assessment is withdrawn or
  superseded, the text stops being public and searchable, the same way
  erasure and revocation already suppress content.
- **What is recorded.** Provenance says what the text is and where it came
  from: `rightsBasis: public-domain`, the assessment, the transcriber
  (acting Agent), and the source (provider, record or edition identifier,
  URL, byte digest, retrieval time). Attribution stays with the Work's
  credited author; the transcriber is never shown as the author.
- **Search.** Public-domain revisions are eligible for public search on the
  same terms as original contributions, with their own model revision of the
  eligibility shape. Existing original-contribution data keeps validating
  unchanged.
- Keep the change inside the model's versioning rules: new profile or model
  revisions, never a silent change to an existing one. Regenerate the model
  artifacts (`task gen`) and say whether the Fuseki image changes. Content
  migrations 420–424 are reserved.

Tests cover publish with an accepted assessment, refusal without one or with
a withdrawn one, suppression after withdrawal, search eligibility and
unchanged validation of existing data. When this lands, the manager resumes
G-387 to seed the Gutenberg texts, so state the exact request shape in the
handoff.

## Verify

Against the shared stack after the manager refreshes it: as the seed
operator acting for North Star Editions, record a `public_domain`
assessment for Pride and Prejudice, publish one short public-domain passage
through the API, find it in public search, then withdraw the assessment and
show the passage leave search and public reads. Use only the backend; no web
dev servers.
