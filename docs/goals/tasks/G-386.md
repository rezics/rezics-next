## Outcome

G-376 fixed Studio's chapter list and found two causes in Main
(`.temp/goal-orchestration/runs/G-376/`, PROPOSED TASKS 2 and 3):

- **Work language.** `POST /v1/works` records `en` when no language is sent,
  so the seed's Chinese Works (雨夜书店, An Wu's recipes) carry English
  titles. The Studio inventory (`modules/studio/works.ts`) also falls back
  to `en`. A Work's language is a fact the author states: require it on
  creation (an explicit `und` is allowed for "I don't know"), never invent
  `en`, and show `und` honestly. Update every caller that omits it: the web
  new-work form (`features/studio/new-work-form.tsx` already asks, so check
  it sends), tests and fixtures. The seed's `works-step.ts` belongs to
  G-375; tell it in the handoff if it still omits the language.
- **Studio chapters in one read.** `readChapterFacts` in
  `apps/web/features/studio/read.ts` makes up to 20 per-chapter
  content-variant reads plus probes. Add
  `GET /v1/me/agents/{agent}/works/{book}/chapters`. It returns each
  chapter's title, position, writer Agent (and whether that Agent is
  another of the caller's identities), state (draft, published, or
  published with unpublished changes) and language, in one bounded call
  with the usual disclosure rules: private chapters by other people are
  not described. Switch Studio to it and delete the probes.

Tests cover language validation (missing, `und`, invalid tag), the chapters
read's disclosure for own, other-identity and other-person chapters, and its
statement budget.
