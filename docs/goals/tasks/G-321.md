## Outcome

Recent handoffs reported failures outside their claims that keep broad
integration and recovery runs red or flaky:

1. **Account recovery**: the recovery inventory is missing tables added by
   recent Account work (admin panel, display preferences, passkeys, locale),
   so the Account recovery test fails in the broader run `20260927t222841-7362f1`
   (G-314). Make the inventory derive from the schema or fail with the table
   name, and cover every current table.
2. **Representation fixture ordering**: a representation integration test
   passed only on isolated retry (G-314); find the order dependency and make
   the fixture independent.
3. **Grouped-search isolation**: grouped search failed when run after the
   Realm-directory tests (G-298); isolate their fixtures.

Fix causes, not symptoms: never weaken an assertion or add retries to hide a
race. Backend only, no dev servers.
