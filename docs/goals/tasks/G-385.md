## Outcome

Every review judges REZICS on the local seed, and the second milestone review
(`.temp/manager/milestone-review-2.md`) found it too thin to show the product.
All six Realms are official Zones, and there is no community Realm. Every
Realm has 6 members. No Work has a review. Only Daniel's library is public,
so G-381's "Readers also enjoyed" read (`/v1/works/:id/also-enjoyed`) can
only fall back to "similar", and Home's Reddit-like feed has little to rank.

Make the seed look like a young but real REZICS, through Main's and Account's
APIs as the seed already does (idempotent `seedKey`s, no direct database
writes):

- **Community Realms (3–4).** Next to the official Zones, for example a
  Chinese web-novel book club (读书会), a Minecraft modding help Realm, a
  prompt-craft Realm, and an English classics reading group. Each has rules
  and moderators among the seed people, plus a few more people (add seed
  accounts in a new `community-plan.ts`; `plan.ts` is held by G-375).
- **Discussions.** Each community Realm gets 5–10 threads with replies and
  votes. Include questions, recommendations, a chapter discussion with a
  spoiler flag and a mod-compatibility help thread. Write natural text in
  the Realm's language (zh-Hans, en, some ja), spread over the past weeks,
  not all "1 hour ago". If the API cannot backdate, say so in the handoff
  and propose how the seed could show time depth.
- **Reviews and ratings.** 20–40 reviews with ratings across the classics,
  the serial and a few mods and prompts, some long and some short, with a
  helpful vote or two. Ratings spread so histograms have shape.
- **Reading lives.** At least eight people with public libraries: shelves
  (want to read, reading, read), progress on the serial, and ratings that
  overlap, so "Readers also enjoyed" shows `co-readers` for at least Pride
  and Prejudice, 雨夜书店 and one mod.
- **Keep it fast and repeatable.** A second `task dev:seed` replays
  everything without duplicates. The whole seed stays within the
  data-preparation budget (`docs/storage/workload-budgets.md#data-preparation-and-import`);
  report the seed's time before and after. `checks-step.ts` asserts the
  new invariants (community Realm count, reviews, co-reader basis).

## Verify

On the shared stack, run `task dev:seed` twice. Then show:

- `/v1/works/:id/also-enjoyed` returns `basis: "co-readers"` for the three
  Works above;
- the Home feed has community posts;
- a Work page read returns reviews.

Take one browser screenshot each of Home, a community Realm and Pride and
Prejudice's Work page as Daniel, using `task web:dev` only for those shots,
then stop it.
