## Outcome

Every record a wiki publishes (an entity's existence, a name or alias, a Statement, a
relation occurrence) carries a revelation position: an occurrence of a composed Work in one
continuity. Reads that return such records take a position and withhold everything revealed
later, before delivery: the entity page's statements and relations sections, Zone index and
detail routes, Collection member pages, resource summaries, and their counts and cursors.
Signed-in readers default to their own furthest position (G-835); anonymous readers
default to the start; anyone may pass `position=<occurrence IRI>` or `position=all`.
Records without a revelation row are unaffected, so nothing else in the catalogue changes.

## Approach

- Content 727: `reading_position.revelation (record, record_kind, continuity_work, occurrence, receipt)`, primary key `record`; written by G-846's apply and by a reviewed correction, never by readers. `modules/reading-position/store.ts` owns writes and a batch lookup for at most 50 records per call.
- `modules/reading-position/boundary.ts`: resolve a position to an ordered prefix of occurrences using G-830's order keys (series part order, then the part's own occurrence order), bounded by the composition size; resolve `mine` through G-835 or, for a single hosted Work, the furthest completed `structure.progress` occurrence. Return a predicate `visible(record)`.
- Apply the predicate once in each listed read, after the owner's own disclosure and before counting and pagination, so withheld records never shape a count, a cursor or a "has more" flag. A detail route for an unrevealed entity returns the same 404 as a non-member.
- `GET /v1/reading-positions/{work}` returns the viewer's resolved default and the occurrence list a position chooser needs (paged).

## Do not build

No per-reader stored position (the chooser passes a parameter); no position inference from
page locators or percentages; no spoiler levels, blur or client-side hiding; no filtering
of records that have no revelation row; no change to search ranking; no new model profile.

## Acceptance

- API (`tests/qa/integration/g-847*.ts`), on a fixture series of two volume Works with chapters and wiki records revealed in volume 1 chapter 2 and volume 2 chapter 1: an anonymous reader, a reader whose progress ends in volume 1 chapter 3, and `position=all` each see exactly their records in the entity page sections, the Zone `characters` index and detail route, member pages and resource summaries; counts and cursors match the visible set; an alias revealed later than its entity is withheld while the entity shows; traversal of a 1,000-chapter composition stays within the declared cost.
- Class guard: a test registry lists every read that can return a record with a revelation row; the suite fails if a new such read is added without the predicate (fixture read), and fails on a deliberate removal of the predicate from any listed read.
