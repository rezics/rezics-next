## Outcome

G-903 found that G-552's independent Collection case now returns 422: a
100-item Collection page exceeds its read budget because target hydration
repeats per item (likely since the disclosure gating of G-897/G-904 added
per-target checks in the page path). After this task a Collection page
resolves, discloses and hydrates its targets in one batched pass per page
(through the shared disclosure boundary), the 100-item page fits its budget
with headroom, and `tests/qa/integration/g-552-library-foundation.test.ts`
passes.

## Approach

Find the repeated hydration with a failing test first (count queries per
page). Batch target resolution and the disclosure check per page; never
loosen the budget to pass.

## Do not build

No budget increase, no cache, no new tables.

## Acceptance

The G-552 Collection case passes; a test asserts the query count per page
stays constant as items grow from 10 to 100.
