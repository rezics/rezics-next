## Outcome

Readers can see what a Work is part of, what it contains, how it relates to other
Works and which editions exist, in any UI locale and on phones:

- `/w/{ref}/connections`: the Work's ordered parts with labels ("22 Reverse",
  "SS1"), inclusion and a "Part of" line for each whole; the franchises
  (Collections) that contain it, with a series ⇄ parts grain switch that changes
  the list visibly; typed relations in both directions as structured rows
  ("Reboot of: …", "Spin-offs: …") and role chips from Main's rendering contract,
  unresolved sources shown as unresolved, a withdrawn web text shown as
  unavailable rather than unknown.
- `/w/{ref}/editions`: realizations grouped by language and script (zh-Hant and
  zh-Hans apart) with source continuity, translator, official or unofficial and
  verified or unverified; releases with format, identifiers, platform, territory
  and coverage (an omnibus lists the volumes it covers).
- `/releases/{id}` shows a release with its realizations, Works and Main Versions;
  `/isbn/{isbn}` resolves through Main and redirects there.
- Exported preview components (`PartsPreview`, `ConnectionsPreview`,
  `EditionsPreview`) for the Work hub page and the franchise Zone to embed.

## Approach

- Server components read Main; the client holds no relation semantics, next-part
  logic or grain rules. Each embedded name keeps its own `lang` and `dir` inside
  `bdi`; use M4's shared localized renderer (G-516) where it exists.
- Paginated inventories with "Show more" and stable anchors; UI copy in the
  feature's eight catalogs, relation labels only from Main.

## Do not build

- No hub page layout, tabs or header changes (the M6b hub brief embeds the
  previews); no tracking controls (G-838); no merge actions (G-839).
- No client-side joins that recompute coverage, order or identity.
- No per-type (book, anime, VN) page variants.

## Acceptance

- Browser against the local stack, desktop and phone, with the e2e setup creating
  the records through the public API (or G-840's loader if it has merged):
  Index New Testament lists "22" and "22 Reverse" separately and Genesis
  Testament restarts at 1; SAO's franchise switches between series and volumes;
  Progressive shows Reboot and AGGO shows SpinOff; the bunko Work links to the web
  Work; the Railgun anime traverses to the Index novel with the unresolved link
  visible; volume 1 editions separate zh-Hant and zh-Hans; `/isbn/9780316371247`
  reaches the release, realization and Work. Reviewed screenshots in the handoff.
- Class guard: a component test fails if a relation row is rendered from a
  client-side label map or concatenated fragments.
