## Outcome

The franchise wiki Zone UI (G-849, merged; handoff at
`/home/edge/projects/rezics/rezics-next/.temp/manager/archive/G-849/handoff.txt`)
renders, but published wiki content does not reach readers:

1. `statement/subject-read.ts` drops any Statement whose sources are not
   readable resources; a bundle's sources are `wiki.evidence` IRIs, so wiki
   Statements never appear on the entity page (and bundle Statements are
   never accepted). Relation occurrences need a per-occurrence
   `semantic:read` grant, so anonymous readers see no relationships.
2. Evidence has no disclosure of its own; the page projection should list a
   record's claims with their evidence (locator, short quotation) as the
   public wiki discloses them.
3. `wikiTypes` admits only Character and Role, so Places and Events cannot be
   published (`wiki_entity_type`) — the manifest mounts places and events.
4. Zone route index items for non-Work members carry only `id` and `types`,
   and `POST /v1/resources/summaries` ignores `position`, so the web makes one
   page read per member name.

After this task a published wiki bundle's entities (Character, Role, Place,
Event), Statements with their evidence, and relationships are readable on the
entity page by anonymous and signed-in readers, cut at the reader's position
(G-847: spoilers stay hidden past the reader's position; missing position =
hidden); Zone index items and summaries carry a position-aware display name
in one bounded read per page.

## Approach

Disclosure follows the public Work the wiki belongs to (G-829's rule: public
Work's wiki is public; private stays absent), applied through the shared
boundary, never per-occurrence grants for public content. Admit Place and
Event for wiki bundles through the served type registry (data, not a code
list). Evidence is disclosed with its claim. Keep one bounded query per page.

## Do not build

No new wiki lifecycle, no UI, no per-type branches.

## Acceptance

Integration: publish a bundle with a Character, a Place, an Event, two
contradictory Statements with evidence and a relation, through the API
(G-907's path); an anonymous reader at an early position sees only what that
position reveals, a later position sees more; the Zone index shows names
without per-member reads.
