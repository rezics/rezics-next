## Outcome

Seven stories in `packages/ui/src/components/command.stories.tsx` fail the
Storybook accessibility check with `aria-dialog-name` on the Command content
(the dialog has no accessible name). Give the Command dialog an accessible name
(a visually hidden title or `aria-label` prop with a sensible default such as
"Command palette", overridable by callers) without changing how callers use it,
and make all its stories pass with the a11y check at error level.

## Checks

- `task storybook:test -- ../../packages/ui/src/components/command.stories.tsx` (or the scoped Vitest run) passes twice
- `bun node_modules/typescript/bin/tsc --project packages/ui/tsconfig.json`; `node_modules/.bin/biome lint packages/ui/src`
