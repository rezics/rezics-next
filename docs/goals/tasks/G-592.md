## Likely cause

This wave changed three contracts on purpose (read the commits):
- `209944b5` (G-520): onboarding creates a Person only from a typed public name;
  without one it returns 409 `public_name_required`.
- `810105c8` (G-521): discovery and saved session/main Agent choices require a
  live mandate or attribution (a provision receipt no longer counts), and the
  identity routes require the `agent:create` scope.
- `ceca4117`, `bb12f2bc` (G-538, G-591): translations of another author's
  protected Work cannot publish as original contributions.
Also `3ee9531d` removed the game and software fact routes, and `86bf6978`
moved interface strings into catalogs.

## Approach

Reproduce each failure with `task goal -- test <file>` on your worktree. Fix
the tests, shared test helpers and seed steps so they follow the new contracts
(send a public name at onboarding; hold a live mandate before choosing a
session Agent; request `agent:create` where the identity routes are used). For a
budget test that fails only under load, rerun it alone and report both timings.

## Do not build

Do not change product code to make a test pass by weakening a rule: no
fallback to the Account name, no provision-based authority, no `openid`-only
access to identity routes. If a failure reveals a real product defect, stop
and report it with the file and line instead of changing product code.
