## Outcome

G-375 made single-text and chaptered Works readable, but the classics have
nothing to read. Pride and Prejudice's only text on the stack is a two-line
reading note, because `tests/fixtures` holds Open Library catalogue records
and no book text. The Books Zone, search and shelves all present these
classics as books; reading them must work.

- **Locked fixtures.** Add a Project Gutenberg source to the fixture
  pipeline (`scripts/fixtures/pull.ts`, `tests/fixtures/fixtures.lock.json`,
  sha256 per file, like the Open Library entries), for the demo classics in
  `tests/fixtures/sources/open-library.ts`: Pride and Prejudice, Alice's
  Adventures in Wonderland, Frankenstein, Jane Eyre, The Adventures of
  Sherlock Holmes, Little Women, The Secret Garden. Use the plain-text UTF-8
  editions. Strip the Project Gutenberg header, footer and trademark text
  as its license requires for redistribution without the trademark, and
  record the source URL, edition number and digest as provenance.
- **Seed the text as chapters.** Split each book into its chapters (heading
  patterns per book, tested). Publish each chapter through Main's content
  and composition APIs, in order and with labels, as the author's Main
  Version, attributed to the North Star Editions organisation that
  already edits the classics in the seed. Mark the rights basis as public
  domain the way the source model expects; if the model has no such basis,
  stop and say what is missing.
- **Budgets.** The whole seed stays within the data-preparation budget
  (`docs/storage/workload-budgets.md#data-preparation-and-import`). If
  seven full books don't fit, seed the first N chapters of each and say so.
  A second `task dev:seed` replays without duplicates.

## Verify in a real browser

On the shared stack after `task dev:seed`, check Pride and Prejudice
signed out and as Daniel (credentials in `scripts/dev/seed/plan.ts`):
Contents lists its chapters, Start reading opens chapter 1, and next and
previous move through the text. Check Alice's first chapter and search
for a sentence from Frankenstein. Take screenshots at 1440x900 and 390x844.
Run one web dev server (`task web:dev`) only while checking, and stop it
when done.
