## Outcome

G-897 closed the reproduced suitability bypass (security pass 1, H1) on every
resource read and preview, and found by static evidence that derived
inventories still map, rank, page and count before the shared disclosure
boundary admits each item. Its handoff
(`/home/edge/projects/rezics/rezics-next/.temp/manager/archive/G-897/g-897-handoff.md`,
proposed tasks 1–4) names the sites. After this task every derived list,
page, continuation and aggregate is computed from items the reader is
admitted to see, through G-897's boundary, with absent-equivalent results for
hidden ones. At launch no reader is admitted to assessed r15/r18/r18g targets
(`docs/operations/trust-and-safety.md`), and unassessed content stays visible.

## Approach

Per the handoff, in priority order:
1. Gate raw inventories before mapping, ranking and hydration
   (catalogue-intake search candidates, Realm public decision index).
2. Choose pages and continuations from admitted inventories (sitemap,
   Realm works, rankings, profiles, release reads) — fill pages from admitted
   items; no cursor or count reveals a hidden item.
3. Gate the derivative itself (a Release's own assessment, relation
   traversal occurrences), not only its parents.
4. Recompute or fence serial aggregates (chapter and word counts) against
   currently admitted children.
Use the one shared batched boundary; never copy policy into a module.

## Do not build

No new policy, no age evidence, no new tables or routes.

## Acceptance

Adverse API tests per site: an assessed gated item is absent from results,
pages, cursors and counts for anonymous and signed-in readers; an
unassessed one stays visible; one bounded admission query per page.
