## Outcome

One pure TypeScript module parses, canonicalizes, validates and selects language-tagged text for
Main and the web, and fixes the gaps the contract names
(`docs/contracts/content-languages.md#vocabulary-labels-are-graph-content`):
- direction follows the script (`az-Arab` is RTL, `ku-Latn` and `pa-Guru` are LTR; tags with no
  script use the likely script of the language);
- selection never silently crosses scripts: a `zh-Hant` reader offered only `zh-Hans` gets it
  with a basis that says so (`basis: 'other-script'` or similar), and the same for `sr-Latn`/Cyrillic;
- no twenty-label cap on stored text (bound bytes instead, as the callers already do);
- unknown or absent language stays distinct (`und`, `zxx`, empty = not recorded, `mul` never
  replaces a list); fallback prefers the original, not English;
- the original tag spelling a source gave is kept where provenance needs it; canonical tags are
  for comparison;
- one predicate says whether content in a language satisfies a reader's language list, by the
  same script-aware rules (G-514 uses it for feed filters).

## Approach

Keep the module where it is (`display-language/select.ts`, split into a sibling file only if it
exceeds one screen) and keep its current exports working so concurrent briefs (G-512, G-596,
G-514) compile unchanged. Export it to the web through `@rezics/main` (add a `./language` entry
to `services/main/package.json` `exports`; the web already depends on `@rezics/main`), with no
Node or Elysia imports in what the web entry pulls in. Add one TypeBox `languageTag` schema beside
it for API routes (outside the web entry). Direction: script from
`Intl.Locale(tag).maximize().script`, RTL when the script is in a short RTL-script set (Arab,
Hebr, Syrc, Thaa, Nkoo, Adlm, Rohg, Mand...). Replace the duplicate parsers in the two other claimed
files with imports (`onboarding/languages.ts` is left to G-595 because G-537 claims onboarding). Leave the other ~75 ad-hoc sites for G-595; G-501 adds the ratchet.

## Do not build

No OpenCC or other script conversion, no transliteration, no search analyzers (decision 18 is
separate), no locale registry service, no new package, no class hierarchy. Do not change persisted
profile validators or generated schema patterns in `model/`.

## Acceptance

Table-driven tests: `az-Arab`, `ar`, `he`, `ku-Arab`, `ku-Latn`, `ug`, `zh-Hant-TW`, `zh-TW`,
`sr-Latn`, `ja`, mixed-case input, private use (`x-…` and `en-x-…`), `und`, `zxx`, `mul`, empty,
invalid; 25 stored labels round trip; selection returns actual language, direction and basis for
exact, same-script, other-script and original fallback. A web test imports the same module.
Class guard: the direction test fails if direction is derived from the primary subtag again.
