## Outcome

R49 B2/B3. `GET /v1/facets` lists two new admitted Facets, `status` and `length`.
Zone browse (`GET /v1/realms/{realm}/modules/browse` and `POST /v1/query` with a Zone
scope) compiles its Conditions through `compileQuery`: it admits `type`, `concept`
(any and none), `status` (any, none) and `length` (one range), and refuses any other
Facet with `unsupported_query_shape` before a read. The shared Zone contract
(`modules/zone-modules/*`) no longer has the mod card, the `Minecraft` literal, the
loader, game-version, environment or dependency parameters and counts, the
`zoneBrowseFacets` list or any import from `modules/package`; facet counts are keyed by
admitted Facet names. The web already stopped using these fields (G-658).

## Approach

1. `facet-status-v1`: triple step on `rv:completionStatus`, string values matching
   `^(ongoing|completed|hiatus)$`, operators any/none, source global.
2. `facet-length-v1`: add one generic step kind `units` with a `unit` term (`rv:Word`)
   to the compiler and the served contract, meaning "count of this unit over the
   Work's published composition"; integer values, operator range. Browse evaluates it
   from the composition statistics it reads today. Name it by unit, never by serial.
3. Extend the `zone-browse` template for these Conditions; the browse route builds a
   filter-document-v2 query from its parameters (names = Facet names, plus
   `excludeConcept` as the concept `none` Condition) and calls `compileQuery`, so one
   admission path serves both endpoints.
4. Delete mod evaluation, mod enrichment of `zoneWork` in `read.ts` and the package
   imports; keep the length bands only as count buckets. Leave the `hub` card and
   serial fields (T's generic projection replaces them).

## Do not build

No Facet for mods, platforms or releases (they return later as release statements
through G-624's correlated conditions; deferred), no new template, query grammar,
index, traversal or window change (G-556 owns the window), no status or length store,
no response profile rename. Do not touch `modules/package` or `/v1/mod-*` routes.

## Acceptance

API (`tests/qa/integration/g-657*.ts`): `GET /v1/facets` returns `status` and `length`
labelled in the eight locales; browse with `status=completed` and a length range
returns the same Works for the seeded Fiction Zone as before the change;
`loader=Fabric` returns 400; `POST /v1/query` with a Zone scope and a status Condition
equals the GET result; an unadmitted Facet is refused without a graph read. Class
guard: `services/main/tests/g-657*.ts` fails when any browse parameter or response
`facets` key does not resolve through `resolveFacet`.
