## Outcome

The maintainer's direction for Zones (`docs/plan/frontend.md#zones`; read it
first): a Zone presents information like its field's best site, in REZICS's
shared visual language, and is never Home's post feed. Fiction and Books
follow novel sites. Study these in a real browser:
- 起点中文网 (qidian.com), 晋江文学城 (jjwxc.net) and KadoKado
  (kadokado.com.tw, the maintainer's reference);
- Royal Road (royalroad.com) for English web fiction;
- a bookstore or library home for Books' classics, such as Standard Ebooks
  or Project Gutenberg's bookshelves.

Write down how each presents stories, then build it:
- **Rankings.** Several lists by period: hot, new, completed, recommended.
  Each row shows rank, cover, title, author, category, status, length and
  the latest chapter.
- **Update lists.** The latest chapter first, with its time.
- **Category browsing.** Genre Concepts, status (ongoing or completed) and
  length.
- **Editor picks and new arrivals.** Cover-first.
- **A book's card.** Hook, category, status, length and chapter count.

REZICS has no paid votes. Rank by what Main measures honestly (readers,
ratings, reads, follows), and name the measure on screen.

Work within the Fiction and Books official packages
(`apps/web/zones/official/fiction/**`, `books/**`), using the Zone
modules and slots that exist. Add the Main reads the lists need
(`zone-modules/rankings*.ts`, `updates*.ts`, serial facts), each bounded with
a budget test. G-404 owns the shared Zone host (`features/zones`,
`packages/zone-sdk`, `features/realm`, the browse page) and is returning every
Zone to the shared visual language. If Fiction or Books needs a host
capability (for example a ranking-list module kind or a category browse
page), write it precisely under PROPOSED TASKS instead of editing the host.
Use the query vocabulary in `docs/contracts/queries.md` for filters: Facet
Conditions and Saved Filters, never "category" as a model term. Add English
and zh-Hans strings only. Run `task zones:digest -- fiction` and `-- books`,
and say which digests need approval.
