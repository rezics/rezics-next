## Outcome

Onboarding (G-292) verified in a browser that a fresh person can upload an
image, but `media.avatar` selection for their own Agent returns 403: the
author baseline (G-304, `modules/access/baseline.ts`) maps `media.avatar` only
to an authored Work target. Let a person's controllers select the avatar of
Agents they control (person, pen names; organizations only for their
managers), keep Work covers as they are, and cover allow and deny cases
(another person's Agent, a suspended account, a pen name you no longer
control). Backend only: no web, Storybook or Accounts dev servers.
