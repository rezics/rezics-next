## Outcome

The manager's product audit of the final browser run
(`apps/web/.temp/direction-9/shared-1791029494092/…/discover-works.png` in the
main checkout) shows Discover's Works grid working, with three defects:

1. **Credit line.** Every card shows "1 author credit" under the one author
   it already names. Show a count only when credits exceed the authors shown
   ("+2 more"; "at least" when the bounded preview is full, as G-1001's data
   says), in every locale with plural rules.
2. **Ragged grid.** Covers in one row have different heights (generated
   2:3 covers beside imported ones), so titles start at different heights.
   Give every Work cover the same aspect-ratio box with the image fitted inside
   (the shared cover component, so rails and lists match), and keep titles
   aligned per row.
3. **Two search fields.** Since 2026-10-03 the header search is Discover's
   search ([Discover](../../plan/frontend.md#discover)); on the Discover page
   the in-page "Search everything" field duplicates it. Keep one: the header
   field shows and edits the current query on Discover, and the page keeps its
   topic picker and type tabs. Mobile included.

Stories for each in a Latin and a CJK locale, run under load as G-1015 did
(with 20 other story files, `--maxWorkers=2`, through
`bun scripts/goal/goalctl.ts slot -- task storybook:test -- <files> --maxWorkers=2`).
