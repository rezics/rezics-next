## Outcome

The generic Trackable session replaces the drafts' book-named `reading-session`
module (R49 item 10). A private consumption session records one attempt at an
exact target from G-506: a Work, realization, release or occurrence, never a
Work-only key.

- States `planned`, `active`, `paused`, `dnf`, `finished`; a reread or rewatch is
  a new attempt, never an overwritten one. Start and finish dates keep their
  precision and may be unknown.
- One attempt may name several formats or releases (print and audio) and
  completes once.
- Position for external realizations is a locator (page, percentage or media
  time) with current and furthest kept apart; completion is separate from
  position. Hosted chapter progress stays on the existing Structure progress.
- Writes use expected versions and idempotency keys: a second device with a stale
  version gets a 409 carrying both states, never a silent rewind; a replayed key
  returns the same result.
- The Library status (`want-to-read`, `reading`, `read`) becomes a projection of
  the latest attempt, written through `ReaderLibraryStatusStore`'s own command.
  Legacy statuses without sessions stay; no attempts are invented from them.
- `POST /v1/me/sessions`, `PATCH /v1/me/sessions/{id}`, and an exhaustive paged
  `GET /v1/me/sessions?target=` for M6b's import and export.

## Approach

- Content tables `reader.consumption_session` and its command log in 715–716,
  following migration 370 and `library/status.ts`; register receipt actions with
  `ON CONFLICT DO NOTHING`.
- Resolve targets with G-506's `resolveTargets`; add the `session` row
  (work, realization, release, occurrence) to its `capabilityBases` as a minimal
  owner change.
- Delegated public-Agent access is denied; sessions are private to the principal.

## Do not build

- No copies, loans, import or export (M6b library owner) and no episode or
  anime-specific tracking.
- No change to `modules/progress/**` or the Structure progress route (the M5
  pending-write owner); no second progress store for hosted text.
- No series roll-up or next-part logic (G-835); no public shelves of sessions.
- No UI (G-838).

## Acceptance

- API: start, pause, resume, DNF and reread one Work; add print and audio releases
  to one attempt that completes once; record an attempt with unknown dates; two
  devices race a locator update and the loser gets a 409 with both states;
  furthest position never decreases when current moves back; replay returns the
  same result; a public Agent is denied.
- Class guard: state-machine tests reject ownership as completion, duplicate
  completion per format, fabricated legacy attempts and cleared omitted fields.
