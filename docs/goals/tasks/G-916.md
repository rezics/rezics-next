## Outcome

G-727 (merged) delivers one backup and one restore command. Its launch drill
(`tests/qa/fault-recovery/g-727-launch-drill.test.ts`) has not yet passed at
launch scale. The manager prepared everything outside the timing:

- medium fixture `fx-medium-a4967fbb7f18` (100,000 Works), built in 415 s;
- restored as the persistent QA stack `rezics-qa-fixture-g727-src`
  (run id `fixture-g727-src`) in 249 s;
- throwaway drill keys in
  `/home/edge/projects/rezics/rezics-next/.temp/manager/drill/`: `gnupg-pub`
  (public-only host keyring), `gnupg` (off-host private keyring), `fpr.txt`
  (recipient fingerprint), `hmac.txt` (manifest HMAC key). These are test
  keys made for this drill, not production secrets.

The drill run, from the main checkout:

```
D=/home/edge/projects/rezics/rezics-next/.temp/manager/drill
GNUPGHOME=$D/gnupg-pub G727_LAUNCH_SOURCE_RUN_ID=fixture-g727-src \
G727_LAUNCH_EXPECTED_WORKS=100000 OPS_RECOVERY_RECIPIENT=$(cat $D/fpr.txt) \
OPS_RECOVERY_OFFHOST_GNUPGHOME=$D/gnupg OPS_RECOVERY_FRONTIER=$D/frontier.json \
RECOVERY_MANIFEST_HMAC_KEY=$(cat $D/hmac.txt) \
task test -- tests/qa/fault-recovery/g-727-launch-drill.test.ts
```

fails after 37 s with `TimeoutError: The operation timed out` (an HTTP probe;
log `.artifacts/qa/20261001t053304-58534b/logs/fault-recovery-f1.log`).
Earlier attempts showed the backup requires the private key off-host (now
satisfied). After this task the drill passes: backup and verified restore of
the medium fixture each within 600 s, with measured times recorded in
`docs/operations/recovery.md`.

## Approach

Reproduce with the command above (rm `$D/frontier.json` first). Find what the
probe waits for (likely a service the restored source stack does not run, or
a probe timeout too short for 100,000 Works) and fix the drill or the
command, never by loosening the 600 s budget. Do not rebuild the fixture;
reuse `fixture-g727-src` (restore a fresh copy with
`task fixture:restore -- --fixture fx-medium-a4967fbb7f18 --run-id fixture-<new>`
if the source was mutated). Tear down any extra QA stacks you create.

## Do not build

No budget changes; no new backup format.

The drill command above passes; `bun test scripts/ops`.
