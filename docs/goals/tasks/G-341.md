## Outcome

The shared dev stack's demo data has drifted through many seed versions:
classics read as Lin Mei's own Works, duplicate demo Works exist from an early
G-338 run, and some Works cannot be converted through the public API. The
maintainer judges REZICS on this demo, so it must be clean and true.

1. **Reset**: `task dev:reset` stops the AppHost, removes only the dev stack's
   data (never QA stacks or fixtures; confirm by printing what it will delete
   and requiring `-- --yes`), recreates storage, applies migrations and starts
   the stack again; document it in one line of `docs/development/README.md`.
2. **Classics as imports**: the seed imports public-domain classics (Pride and
   Prejudice, Alice's Adventures in Wonderland, Jane Eyre, 西游记, 三国演义 …)
   through the public source-acquisition path with their authors retained
   (G-322), using the captured Open Library fixtures in `tests/fixtures/sources`
   (no live network), through a seed OAuth client granted the source scopes by
   the fixture operator.
3. **Authors and serials**: demo authors' serials are `own-work` with titled
   chapters (G-338's steps), pen names author their own Works, and the checks
   step fails when a Work has no credited author.
4. **Proof**: `task dev:reset -- --yes && task dev:seed` twice in a row ends
   with no "Public API gaps", and curl shows Pride and Prejudice credited to
   Jane Austen and 雨夜书店 to Lin Mei.

Run the reset only after G-326 (official Zone seed) has merged — the manager
will tell you; until then build and test against an isolated backend
(`task dev -- --backend` in your worktree).
