## Outcome

G-285 added reader status shelves (want to read, reading, read) and kept them
private, because profiles have no library visibility setting. Author and reader
profiles (Goodreads' "X's books" and shelves) need them public when the person
chooses:

1. A profile library visibility setting per Agent (public, followers once
   follows exist, private), read and written with CAS and receipts; decide a
   sensible default (Goodreads defaults to public; say why yours differs if it
   does).
2. A public read of an Agent's status shelves with counts, cursor pages and
   Work summaries, honouring the setting and Work disclosure; the private
   variant for the owner is unchanged.
3. Profile reads report which shelves are visible so the profile page can show
   or hide its Library tab without guessing.
