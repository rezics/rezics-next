The attachment acknowledges the second source's title against an exact native
Work revision verified before the Source write. It does not let Source create or edit that head, infer consent from a
matching value, grant publication authority, or treat a missing source field as a
withdrawal. Preserve old immutable receipts and keep each new disposition tied
to its own source binding. No cross-owner atomic backup frontier or current-head
at-commit guarantee follows from the two-database lock envelope; those remain
explicit qualification work.
