## Outcome

REZICS gets a public about site that wins users and states the direction. It
lives in this monorepo as `apps/about` (Astro with React components for
interactive islands), so it shares the Rezics UI tokens, fonts, brand and eight
UI locales with the main site. This task builds its foundation; G-481 writes
the final copy and page designs on top of it. The old `../about` and the old
site's about pages are outdated: do not copy from them.

Deliver:

1. **Workspace and toolchain.** `apps/about` as a Yarn workspace; Astro (current
   stable), `@astrojs/react`, Tailwind v4 through the same setup as
   `packages/ui/src/styles.css`; static output that a Cloudflare Worker with
   static assets can serve. Add `task about:dev`, `about:build`, `about:check`
   (types, lint, format, tests) and `about:e2e`. Record every new tool and
   version in `docs/development/toolchain.md` in this change.
2. **Locales.** The eight UI locales of `apps/web/i18n/define.ts`, as path
   prefixes (`/en/`, `/zh-Hant/`, …) with `hreflang` alternates and `x-default`;
   the root negotiates from `Accept-Language` and a cookie. All copy lives in
   typed per-page catalogs (English defines the shape); a test fails when any
   locale misses a key. Content language and direction are set per block
   (`lang`, `dir`).
3. **Design system.** Import the Rezics UI tokens and fonts; reuse
   `packages/ui` components where they fit (buttons, badges, cards, menus,
   theme). Brand rule from `packages/ui/src/styles.css`: the logo red
   (`--brand`) never carries text; coloured text and filled buttons use ink blue
   (`--primary`). Light and dark themes without a flash. Editorial and calm, not
   a template: large type, generous space, real product components rendered as
   illustrations (a Work card, a shelf, a series timeline) instead of stock
   images. Load the `frontend-design` skill before designing.
4. **Information architecture.** Header with the product lines and a clear call
   to action; footer with open source, trust and language links. Page shells,
   each with its sections laid out and placeholder copy marked for G-481:
   - `/` Home: the promise, the four first scenarios, product lines, why REZICS
     (natively multilingual, your data is portable, open source, API- and
     agent-first), call to action;
   - `/reading` reading and the portable library;
   - `/light-novels` series tracking across editions and translations;
   - `/serial-fiction` writing and reading serials;
   - `/acgn` visual novels, anime and manga;
   - `/wikis` wikis and worldbuilding, including agent-built wikis;
   - `/communities` Realms;
   - `/distribution` publishing and selling books and games;
   - `/developers` API, MCP, SDK and bring-your-own agents;
   - `/trust` safety, ratings, AI disclosure, privacy, portability, open source;
   - `/roadmap` the direction with honest Now / Next / Later status.
   Every feature statement carries an availability status (available, in
   development, planned) from one typed registry, so the site sells the future
   without claiming what does not exist yet.
5. **Call to action.** Registration is not open yet. A "Get notified" form posts
   to a small Worker endpoint that stores the address and chosen locale in a
   Cloudflare D1 table (local development through Wrangler), with a
   confirmation state; plus links to follow development. No third-party
   trackers; no cookies beyond locale and theme.
6. **SEO and quality.** Per-page titles and descriptions per locale, Open Graph
   images generated at build time, canonical URLs, `sitemap.xml` with alternates,
   `robots.txt`, Organization and SoftwareApplication structured data.
   Lighthouse-level budgets: no client JavaScript except islands; pages pass axe
   and keyboard checks; phones at 390 px and desktops at 1440 px, light and dark.
