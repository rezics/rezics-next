## Outcome

People who write on REZICS need an authoring home as good as the best web
fiction and publishing tools (Royal Road's author dashboard, AO3's posting
form, Wattpad's writer, Substack and Ghost editors). Today Studio is a
title-and-type form. Build the Studio slice in `docs/plan/frontend.md`
(`/studio/@{agent}/…`: the acting Agent lives in the route and is shown before
every submit, never silently replaced):

1. **Studio home**: my Works as the chosen Agent (drafts, published, in review
   in a Realm), switching Agent (person, pen names, organizations), a clear
   "New work" entry.
2. **Create and edit a Work**: full metadata (title, type, languages,
   description, cover, tags) through `POST /v1/works` and
   `PUT /v1/works/:id/metadata` with `expectedHead`.
3. **Write chapters**: a calm, CJK-friendly editor for chapter content with
   autosave (debounced draft saves through `POST /v1/content-drafts` with
   `expectedHead`), visible save state ("Saved · 2 min ago", "Offline — kept
   on this device"), and a recoverable conflict view when the head moved
   (compare, keep mine, take theirs). Choose the editor with care (content
   format comes from Main's content drafts); record any new library in
   `docs/development/toolchain.md`.
4. **Publish**: a publish dialog that states who publishes, where and what
   readers will see; optional submission to Realms (`POST
   /v1/realms/:realm/submissions`, `GET /v1/my/submissions` for status).

Missing or awkward APIs (for example, there is no write route to create a
version) go to PROPOSED TASKS with the exact contract you need, not client
workarounds. Encode the flows in `docs/experience/studio-workspace-and-contributions.md`
as stories and browser tests, then delete that page and repair its links.

Put strings in your features' `messages.ts` (English and `zh-Hans`); another
task is moving catalogs to per-locale files and will tell you the recipe.
Build internal links with `features/shell/localized-link.tsx`.

## Verify in a real browser

Use Claude in Chrome if available, or Playwright from `apps/web`, against the
shared stack (demo sign-in credentials print from `bun scripts/dev/seed/cli.ts --dry-run`).
Write, autosave, go offline, force a conflict from a second tab, publish and
submit to a demo Realm. Screenshots at 1440x900 and 390x844, light and dark,
en and zh-Hans. Stop dev servers before handing off.
