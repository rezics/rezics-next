## Outcome

Web features keep English in `messages.ts` and every other locale in
`messages/<locale>.ts`, registered in `apps/web/i18n/catalogs.ts` (see how
`feed`, `home`, `manage`, `profile` and `shell` do it). Seven features still
keep locales inline: auth, catalogue, discover, onboarding, search, settings,
work-page. Move their non-English entries into per-locale files exactly as
the split features do (renaming nothing, changing no English text), register
them, and create empty per-locale files for the other six locales in every
split feature that lacks them (realm and zones have only `zh-Hans`). Leave
`studio` and `work` alone: G-316 is changing them.

Keep each `catalogs.ts` entry on as few lines as you can: the file is merged
with git's union driver, which has dropped closing lines of multi-line
entries before. If `scripts/i18n/check.ts` lists features explicitly, keep it
in step.
