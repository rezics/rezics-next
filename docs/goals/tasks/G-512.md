## Outcome

A Work's title and a Space's name are stored with the language the caller declared, through the
normal command, replay and restore paths. Today every title edit stamps `@en`
(`title-control.ts` writes `language: 'en'` and `rdfs:label …@en`, control field `"title:en"`;
`work-title-control-v1` is "One native Work English title control epoch"), protection proposals
and source-managed titles do the same (`protection/work.ts`, `routes/source-supports.ts`
`titleLanguage: t.Literal('en')`), activation defaults to `'en'`, `space/create.ts` stamps names
`@en`, the Java policies reject any other language, and `reconcile-restored.ts` repeats the stamp
on recovery. A Japanese light-novel title therefore reads as English to every adapter.

## Approach

Commands carry the title's language. Omitted keeps the current head's language (never `en`); an
unknown language is `und`, not English. Add `work-title-control-v2` (language-neutral title control
field plus the declared language) because v1's persisted meaning is English-only; keep v1 readable
and its receipts replayable. Space names: take the declared language in the create command; add a
Space profile version only if the persisted payload changes. Relax the two Java policies to accept
any valid tag and require it to match the command. Apply the same change to the matching lines of
both `reconcile-restored.ts` files. Remove the `untitled chapter|未命名章节` sentinel regexes in
`work-contents/read.ts`, `continue/chapters.ts` (and `feed/cards.ts` via G-596) if nothing writes
those labels any more; if seeds do, leave them and say so. Content migration 502 is reserved only
if a Content receipt action must be registered.

## Do not build

No per-language title-control epochs, no multi-title control model, no historical relabelling
(existing `@en` values stay as recorded), no new modules or helpers beyond what two call sites
need. Localized per-language titles stay in `work-metadata-details`; do not merge the two.

## Acceptance

API: create, edit, protect, source-confirm, replay and restore a Work with a `ja` title, a
`zh-Hant` title and an omitted language (keeps the head's); read the stored literal language
back; a Space created with an `ar` name reads back `ar` and `rtl`. Java tests for the policies.
Class guard: a matrix test over these command paths fails if any path writes `@en` for a
non-English input.
