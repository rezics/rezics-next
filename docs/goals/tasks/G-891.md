## Outcome

G-824 (merged) gave Main a keyset shelf endpoint: `sort`, `order` and `cursor`,
exact counts, owner placeholders for unavailable Works, and yearly totals
folded into `/v1/me/reading-stats`. The web library still sorts on the client
and caps pages. After this task the web reads one Main page per rendered page,
keeps the cursor and sort in the URL, shows the exact counts Main returns,
renders owner placeholders for unavailable Works, and has no client-side sort
or page cap.

## What to read

The G-824 route and schema (`services/main/src/routes/library.ts`, the shelf
read) and the current web library feature.

## Do not build

No client-side sorting, filtering or counting; no new API.

## Acceptance

Browser (phone and desktop, one non-English locale): page through a shelf of
more than 240 Works in each sort; counts equal what is listed; back/forward
restore the page. Class guard: a unit test fails if the library feature sorts
or slices Main's items.
