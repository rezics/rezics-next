## Outcome

A holder's agent can ask Main two things through the API (and MCP once G-580 is in):
which existing entities its extracted names match, and whether an extraction bundle is
acceptable. `POST /v1/wiki/candidates` returns, per name, `matched | new | ambiguous |
unavailable` with candidate IRIs. `POST /v1/wiki/validations` checks a `wiki-extraction-v1`
bundle and returns a preview (entities to create or reuse, claims, relations, source-unit
to occurrence alignment, quotation use) or typed problems. The bundle's wire format is an
Apache-2.0 protocol published from `packages/wiki-toolkit/protocol/`, which imports no
AGPL code. Main enforces the versioned quotation policy: a per-passage limit and a
cumulative per-Work limit across accounts, realizations and Zones, counted on applied
quotations. Nothing here stores a proposal; submission, review and publication are G-865's
lifecycle with G-846's adapter.

## Approach

- Create the package skeleton: `packages/wiki-toolkit/package.json` (`@rezics/wiki-toolkit`, `"license": "Apache-2.0"`, not private), `LICENSE` (Apache-2.0 text), `NOTICE`. Do not register the workspace (G-848 does, with its dependencies); Main and `@rezics/model` import the protocol files by relative path until then, Main only through `services/main/src/modules/wiki/protocol.ts`. Move `packages/model/src/locator.ts` unchanged into `protocol/locator.ts` (G-510 kept it self-contained for this) and re-export it from `@rezics/model` so no consumer changes.
- `protocol/wiki-extraction.ts` (TypeBox, SPDX header): target Work IRI and wiki Zone IRI (the validator checks the Zone mounts that Work's franchise Collection); continuity IRI; source `{ representationSha256, mediaType, language, rightsBasis (the rights enum), method { agent, model, inference: 'local' | 'provider' } }`; `units[]` (holder unit id, ordinal, label, `occurrence` IRI or null); `entities[]` (temp id, registry type IRI, names with BCP 47 tag, name kind and `revealedAt` unit, optional `match` IRI); `claims[]` (subject, predicate from the relation lexicon or registry property, object, modality `narrated | said | rumoured | hypothetical`, continuity, `revealedAt` unit, 1–16 evidence `{ locator, quote }`). Every string has a `maxLength`; no free-text body field exists. Emit JSON Schema files next to it.
- `modules/wiki/validate.ts`: schema check; `resolveTargets` for target, continuity, `match` and occurrences; unaligned units flagged; quote length and cumulative budget from `modules/wiki/quotation.ts` (`WIKI_QUOTATION_POLICY = { version: 1, passageCodePoints: 200, workCodePoints: 10000 }`; identical quote plus locator counts once). Content 725: `wiki.quotation` (work, representation, locator digest, code points, policy version, applied receipt) written only by G-846's apply; 726 registers receipt actions if needed.
- `modules/wiki/candidates.ts`: at most 64 names × 16 candidates, NFKC label and alias match over `rv:Character` and other registry types, scoped to the members of the target wiki Zone's `characters`, `places` and `events` Collections (G-846 fills them; read them through the Collection member read, any target after G-650); unreadable matches report `unavailable`, never their names.
- Scope `wiki:propose` in `services/account/src/oauth-scopes/wiki.ts`. Export `capabilities` with `mcp` tool names `wiki_candidates` and `wiki_validate` in G-580's shape (harmless until G-580 merges).

## Do not build

No proposal store, review state, queue or withdrawal (G-865); no publication (G-846); no
reservation of budget for pending bundles (apply rechecks); no embeddings, fuzzy or
transliteration matching, no automatic merge; no server-side model call; no generic
contribution framework or plugin registry (one payload profile); no new model profile.

## Acceptance

- API (`tests/qa/integration/g-845*.ts`), on the Pride and Prejudice fixture Work: candidates for "Elizabeth", "Lizzy", "Miss Bennet" give matched, new and ambiguous; a restricted Character gives `unavailable` with no name; a valid bundle previews its creates and reuses; a 201-code-point quote, a bundle that would pass the Work budget after another account's applied quotes, an unaligned unit used by a claim, and a continuity on another Work each return their typed problem; a request without `wiki:propose` is refused.
- Class guard: a test walks the emitted JSON Schema and fails if any string lacks `maxLength` or any property admits text longer than the passage limit (except IRIs and hashes); an import-boundary test fails if anything under `packages/wiki-toolkit/protocol` imports outside the package or `typebox`.
