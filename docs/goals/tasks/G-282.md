## Outcome

**Maintainer direction (2026-09-28):** the main site's home page becomes a
Reddit-like feed, as the old site (`/home/edge/projects/rezics/rezics`, see
`apps/web/features/explore/home.tsx` and `features/content-feed/**`, read-only)
had. Read `docs/plan/frontend.md` (principles "A feed home, like Reddit").
Main has no feed or activity timeline and no follow model for Realms/Zones.

Design and implement:

1. **Follows.** A person (acting as their Agent) follows Realms, Zones, Works
   and Agents; list "what I follow" (for the left navigation: followed Realms
   and Zones with icon and name), follow/unfollow with receipts, public counts
   where policy allows. Reuse subscriptions/notification owners if they already
   model this; otherwise add a small owner.
2. **Home feed.** `GET` a feed of public activity items: new Works, new
   chapters/contributions, Realm adoptions and decisions, discussions and
   replies, collections — from followed communities (signed in) and
   REZICS-wide (signed out and "All"), sort `best` (score with time decay,
   defined and tested) and `new`, filters by kinds, content languages, Realms
   and tags, cursor pagination, bounded cost. Each item carries what a card
   needs: kind, actor Agent (name, handle), target summary (title, cover,
   excerpt, language), Realm, time, score, vote state for the reader, comment
   count, and links. Disclosure: private and unreviewed content never appears.
3. **Votes on feed items** if no vote owner covers them (up/down with one vote
   per person per target, score projection), or reuse the existing vote/rating
   owners — explain the choice.

Follow the read-family template (`services/main/src/modules/work/read-contract.ts`,
`modules/discovery/**`) and the command patterns; integrate with the outbox
relay (every new event kind needs a relay reader; see the inventory test).
Extend the demo seed (`scripts/dev/seed/**`, unclaimed) so follows, votes and
a lively feed exist, through the APIs.
