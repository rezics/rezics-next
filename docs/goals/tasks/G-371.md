## Outcome

Zone module reads (for example `GET /v1/realms/{books}/modules/new-adoptions`)
return Work cards whose Open Library credits have `displayName: null`, while
the Work page names the author (Pride and Prejudice → Jane Austen). The
module reads resolve only native Agent names. Resolve retained source author
names (G-322's resolver, also used by discovery and search) for every credit
on Zone and Realm module cards, within the module reads' cost bounds, with a
test. This lets the Books "Authors to follow" module (G-353) show on the
shared stack. Backend only, no dev servers.
