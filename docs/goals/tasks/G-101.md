Environment repair (maintainer direction: the manager owns the environment).
`yarn fixture:build --profile small` now fails (`20260926t194619-a739af`): it stored
1,001 Access scope gates while planning 1,000, because later owner migrations
(for example G-047's `access:representation-topology` gate) seed their own rows.
Make the builder's plan and verification count only rows it inserts (or read
seeded rows into the manifest), so owner migrations that seed rows never break
it. Then build the `medium` profile once, save its backup, and prove
`yarn fixture:restore` of that backup plus minimal readiness finishes within
600 seconds on current `main`. Report the reusable fixture source ID and exact
restore command in the handoff so every worker restores it instead of building.
Checks: fixture unit tests and the registered load test through `goalctl test`.
Keep G-045's design (`docs/storage/workload-budgets.md#data-preparation-and-import`).
