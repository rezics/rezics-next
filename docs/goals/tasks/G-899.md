## Outcome

Eight Storybook interaction stories fail on main in every worker's run, so
real regressions hide among them (G-838 review,
`/home/edge/projects/rezics/rezics-next/.temp/manager/reviews/G-838.md`):
language-select "Typed Tag" and "No Match"; app-shell "Communities Chinese"
and "Phone Communities" (fails almost every run); rules "Rule Written In
Japanese"; studio-work "Chapters"; library-page "Read History"; queue "Keep Or
Remove Report". After this task each passes reliably (three consecutive
runs), or is fixed at its real cause.

## Approach

Run each failing story alone (`task goal -- slot -- task storybook:test --
<story file>` or the equivalent filter) and read the failure. Classify each:
stale expectation after a merged copy or contract change (update the story);
timing (wait on the accessible state the user waits for, never sleep); or a
real component defect (fix it if it lies in the story's own feature file;
otherwise list it under OWNER CHANGES with file:line and do not edit it).

## Do not build

No new stories, no test-runner changes beyond a timing setting the cause
proves, no skipped or deleted stories.

## Acceptance

`task storybook:test` over the six files passes three consecutive times;
handoff names each story's cause.

## Checks

`task goal -- slot -- task storybook:test` over the six files.
