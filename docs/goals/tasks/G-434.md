## Outcome

G-427 moved Search, Discover and Concept pages onto the shared Query with
include/exclude Concept Conditions, and G-426 gave Concepts a shared scheme
with English and Chinese labels. The manager used Search on the shared stack
(zh-Hans, signed in, query 雨夜, include the Concept 悬疑) and found:

1. **The active Condition chip shows an id fragment**, "f45a75ce ×" (aria
   "移除f45a75ce"), instead of the Concept's label "悬疑" / "Mystery". Every
   chip, on Search, Discover and Concept pages, shows the label in the
   reader's locale (falling back through the scheme's labels), with the
   include/exclude sign.
2. **The match reason reads "类型：此类型"** ("Type: this type") on the result.
   It should name why the Work matched ("悬疑" or "Mystery").
3. **Choosing a suggestion does nothing until Enter.** Picking an option adds
   the Condition immediately (keyboard and pointer), clears the input and
   keeps focus for the next one.
4. **Two "悬疑" suggestions.** The picker offers "悬疑" (the new Concept) and
   "Mystery · 悬疑" (a G-425 English-only proposition the seed replays so it can
   reject its old decisions). Superseded or retired propositions must not be
   offered: suggestions come from the current scheme only. The seed creates
   those legacy propositions even on fresh stacks; create them only when
   they already exist (replay), or retire them explicitly.
5. **Discover's remaining views** (G-427's handoff): top-rated, Mine and
   exclude-only views run on the Query too, with the same Condition bar.

Home's Filters are not in scope: G-431 is building pinned Home tabs on the
Query and owns `apps/web/features/home` and the feed controls.
