Environment task (maintainer direction: the manager owns the environment and may
use Grok). FACT05's method-calibration clause (`docs/testing/information-verification.md`,
`docs/contracts/information-verification.md`) needs representative labelled
held-out evaluation data; the repository has only 13 authored labels.

1. Find a public, licence-compatible labelled claim-verification dataset from
   primary sources (for example FEVER, CC BY-SA 3.0; check the licence page
   yourself). Record source URL, version, licence, citation and the exact
   download checksum.
2. Select a deterministic, stratified calibration subset (a few hundred items,
   balanced across labels and domains) with a fixed seed, and store it under
   `tests/qa/fixtures/fact-calibration/` as JSON Lines with a `README.md`
   (provenance, licence, selection method, attribution). Keep the file small.
3. Add `tests/qa/unit/fact-calibration.test.ts` proving the subset is
   reproducible from its manifest (checksum, seed, counts per stratum).

Do not change product code. Use only this worktree; no secrets. Check:
`bun test tests/qa/unit/fact-calibration.test.ts`. Commit once and end with the
handoff format in `docs/goals/worker.md`.
