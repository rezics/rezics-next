## Outcome

Browser (e2e) runs in different QA slots collide on a fixed web port 3003
(`scripts/qa/e2e.ts:116,129,135`, `scripts/qa/cli.ts:329` redirect URI,
`apps/web/playwright.config.ts:8` default), so a worker waits for another's
run or fails (G-914). After this task each e2e run picks a free port (or a
port derived from its slot), passes it to the web worker, the OAuth redirect
URI and Playwright's base URL, and two e2e runs in different slots run at the
same time.

## Approach

Allocate the port once per run (`assertPortAvailable` becomes "find a free
port"), thread it through the existing environment variables
(`REZICS_WEB_E2E_BASE_URL`, `WEB_ORIGIN`, the redirect URI registered for the
run's OAuth client). No other harness changes.

## Checks

A unit test that two allocations in one process return different free ports;
`task goal -- test` one existing e2e file to show it still passes.
