## Outcome

Discover (G-256) works but is hampered by three API gaps:

1. **Automatic refresh.** Discovery generations go out of date after any write
   and nothing rebuilds them; Discover shows "out of date" until an operator
   rebuilds (the discovery README names this). Implement bounded incremental or
   scheduled refresh driven by the outbox/relay (the relay is being repaired in
   parallel by G-266), with activation CAS as today and measured bounds.
2. **Richer items:** primary credits and a few classification tags with
   localized names on discovery items, and the localized name of a matched term
   so term shelves can title themselves.
3. **Rating Context listing:** `GET` the standing rating Contexts available per
   scope (Global, a Realm), with question and scale, so "Top rated" does not
   need a Context id in the URL.
