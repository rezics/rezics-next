## Outcome

G-655's review: a card for a Work outside a Zone's population (an editorial
list over an unmounted Collection, or a discussion about a Work whose adoption
was removed) links to a Zone URL that returns 404. The web must not decide
membership. After this task Main's card and route projections mark each item
`inZone: true|false` (from the same population check G-630 uses for detail
routes), so the web links members inside the Zone and others to `/w/{id}`.

## Do not build

No second membership rule; no per-card extra query beyond one batched check.

## Acceptance

API: a Zone index listing a member and a non-member returns `inZone` true and
false respectively; the check is one batched query per page.
