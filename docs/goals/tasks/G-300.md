## Outcome

People can choose a handle (G-284) but cannot change their display name,
avatar or short bio, and pen names and organizations need the same. Add CAS
writes with receipts for an Agent's public profile fields: display name
(Unicode, length-limited, trimmed, no control characters), avatar (a media
reference through the existing media owner, with the size and type rules it
already enforces), and a short bio with a language tag. Only the Agent's
controllers may write. Profile, handle and every Agent-naming read return the
new values; the change emits an event so projections (search, feed, notifications
display) refresh. The web settings page (G-292) will call it.
