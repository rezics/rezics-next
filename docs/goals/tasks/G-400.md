## Outcome

The maintainer decided REZICS's query vocabulary on 2026-09-28
(`docs/contracts/queries.md`; read it first, it is authoritative). Anything a
reader can filter by is a Resource. A **Facet** is one admitted, versioned
path from the queried Resource to such a value, with labels, value domain,
operators, Statement source and cost. This task is the first milestone of
moving to that contract: the Facet definitions themselves.

- **Definitions.** Add Facet definitions in `model/definitions`, generated
  like profiles by `model/compiler` (labels in all eight UI locales,
  DefinitionRefs, versioning). Cover what exists today first:
  - `type` (`rdf:type`);
  - `concept` (accepted Concepts, per Context), and genre and form as
    Concept Facets if the contract's examples need them;
  - `author` (primary credit, native Agent or source author);
  - `language`;
  - `realm` scope;
  - `rating` (question, population, scale);
  - relation `role`, as in the grouped Statement read.

  Each states its path, value domain (a class, a Concept scheme, a
  datatype), operators (any, all, none, range) and Statement source (Global
  or Context).
- **Facets define queries; data never references them.** No Facet, Path or
  Sense wrappers enter stored data (see `presentation.md`, which the contract
  cites).
- **A read for clients.** `GET /v1/facets` (public, cacheable) returns the
  admitted Facets with labels and operators, so clients stop keeping their
  own tables.
- **Map today's profiles.** Show, in a test, that each public search
  profile in `services/main/src/routes/search.ts` (`public-*-phrase-v1`,
  classified, realm and title-body) is expressible as Conditions over these
  Facets. This is the basis for the next milestone, the Query compiler; do
  not build the compiler here.

Refine `docs/contracts/queries.md` only if something must change, in a
separate, explained commit; never silently. Follow the new vocabulary in
every name: type, Concept, Facet, Filter, Saved Filter. Never "kind",
"interest", "Sense" or "category".

Don't commit generated artifacts; the manager runs `task gen` at merge. Say in
the handoff whether the Fuseki image changes.
