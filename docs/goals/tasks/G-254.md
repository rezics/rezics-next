## Outcome

All ~95 Rezics UI components now have stories (G-209–G-211, G-213) and the web
shell is on Rezics Aura (G-202). Several parallel story workers left
cross-cutting items, and the 18 components from G-213 never got a screenshot
review. Make the library consistent and verified as a whole:

1. **Global theme toolbar** in Storybook (light/dark, and zh-CN locale if cheap)
   so stories no longer need per-file `.dark` wrappers; keep
   `packages/ui/src/stories/support.tsx` helpers only where still useful.
2. **Contrast and tokens:** dark `muted-foreground` on `accent` is 4.48:1
   (Listbox works around it) — fix the token pair in `styles.css` so Menu and
   Select items pass too; badge success/info/warning use `text-*-foreground`
   (verify done); Button must not overwrite a caller's `aria-disabled`
   (use `isLoading || props['aria-disabled']`).
3. **Whole-library visual review:** open every story in a real browser
   (Playwright), light and dark, and review the screenshots yourself for
   consistency with Aura and with each other: radius roles, shadows, focus
   rings, heights (32/36/40/44), spacing, typography (Manrope loaded), icon
   sizes, disabled and invalid states. Fix material inconsistencies in place.
   Give extra attention to carousel, chart, circular-slider, color-picker,
   image-cropper, json-tree-view, marquee, qr-code, signature-pad, swap, timer,
   tour, float, show, presence, client-only, locale, download-trigger (never
   screenshot-reviewed).
4. **design-system.md:** record the reasons for material component decisions
   only (checkbox uses 6px radius because 12px reads as a radio; Input chrome
   for Input Group/Number Input/Native Select; accent surface for pressed
   toggles; Aura tab tray for Segment Group; `--rating` for Rating; Separator
   `border/60`). Keep it short; the code is the reference.

Do not change component APIs that `apps/web` uses (run the web typecheck).
Another Opus worker is building the Work page in `apps/web/app/w/**` and
`apps/web/features/work-page/**`; do not touch apps/web beyond `.storybook`.
