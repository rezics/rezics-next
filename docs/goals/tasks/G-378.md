## Outcome

The plan ships eight UI locales (`apps/web/i18n/define.ts`). The second
milestone review (`.temp/manager/milestone-review-2.md`, finding 5;
screenshots `loc-ja-fiction.png`, `loc-zh-Hant-home.png`, `loc-fr-fiction.png`
in `.temp/manager/milestone-2/`) found:

- ja prints `{{count}}人のメンバー` and `公式 Zone · {{count}} 人のメンバー`;
  zh-Hant prints `{{count}} 位成員`. Find every message whose placeholder is
  not interpolated (a plain string where `insert(...)` is needed, or a
  mismatched placeholder name) in every locale and fix it.
- "Home, Discover, Library, Create" and the rest of the navigation are
  English in zh-Hant, ja, ko, de, fr and es.
- In ja, ko, de, fr and es every Zone module heading is English (Latest,
  Charts, Editors' picks, New chapters, Newly added, Completed, New and
  rising, Recent decisions, Fresh from readers). They live in
  `apps/web/features/zones/messages.ts`; give zones per-locale files like
  the other features if it has none.

Then translate every web feature's missing keys into the six locales
(zh-Hant, ja, ko, de, fr, es). zh-Hans is complete and is a good second
source beside English. Keep the product words the plan fixes
(`docs/plan/frontend.md`, Languages and themes): "Realm" is "Realm" only in
English; other locales use their plain word for a community
(社群/コミュニティ/커뮤니티/Community/communauté/comunidad); "Zone" stays
"Zone". Use natural, short UI language, as each locale's large reading sites do.

Make `task i18n:check` catch this class of bug: it fails on a message that
would render a literal `{{`, on a placeholder a locale drops or renames, and
on a web feature missing from its list (library and profile are missing
today). A missing key may still fall back to English at runtime, but the
check reports how many keys each locale lacks.

Other tasks are running on Work pages, Studio, catalogue, home, feed, search,
profile, manage, library and official Zone packages; they add English and
zh-Hans only. Touch only the six locale files, zones' messages and the i18n
code in your claim.

## Verify in a real browser

Against the shared stack signed out: home, `/r/fiction`, `/r/books` and a
Work page in each of the six locales at 1440x900 and 390x844, with no English
navigation, no English Zone headings and no `{{`. Run one web dev server
(`task web:dev`) at a time, only while checking, and stop it when done.
