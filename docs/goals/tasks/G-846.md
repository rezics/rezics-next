## Outcome

A holder's agent submits a validated `wiki-extraction-v1` bundle as a G-865 proposal of
kind `wiki-bundle`. A steward reviews its preview (new and reused entities, claims,
relations, evidence quotes with locators, revelation positions, quotation use) and
applies it. Apply creates the new entities as semantic resources, records each claim as a
Statement or relation occurrence with its continuity and evidence, writes revelation
positions (G-847), records the quotations, links each published entity to its Work with G-539's Work link
when the target Work is public (which is what makes it publicly readable), and adds them to the wiki Zone's mounted Collections so their Zone pages resolve. A
retried apply finishes the same bundle once. A later retraction goes through G-865's
compensation; nothing is deleted by omission (G-693 adds chapter deltas on this adapter).

## Approach

- `editorial-review/wiki-adapter.ts`: `validate` and `preview` call G-845; `apply` walks items in dependency order (entities, then claims and relations that cite them). Each owner command uses the deterministic key `wiki:<proposal revision>:<item>`, so a retried apply replays settled items and continues; the receipt lists every created IRI. An item whose dependency was rejected fails with `dependency_rejected`; apply rechecks the quotation budget in the same transaction that writes `wiki.quotation` and returns `budget_exhausted` as a G-865 blocker.
- Claims map to existing records: a property claim to a Statement (applicability = continuity, evidence = IRIs of `wiki.evidence` rows); a relationship or appearance to a relation occurrence with lexicon roles (narrative role and prominence stay distinct roles). Names become language-tagged labels; hidden names are aliases with their own revelation position.
- Content 728: `wiki.evidence` (id, representation hash, locator JSON, quote, method, submitter Agent, rights basis). `GET /v1/wiki/evidence/{id}` serves it with the claim's disclosure and withholds the quote under a rights restriction.
- Disclosure is G-539's, decided once in Access. When the bundle's target Work is publicly readable, apply writes G-539's Work link for each entity it creates or reuses, with the steward's edit authority and the same deterministic key; for a private Work it writes no link, so the entities stay private. A later restriction is G-539's Access policy, not a wiki flag.
- Collections: add each new entity to the target Zone's Collection mounted at `characters`, `places` or `events` by registry type, and each cited occurrence to `chapters`, appending in reading order.
- Shorten the "missing today (R51)" paragraph of the wiki contract to what remains missing.

- From G-845's review: apply locks per Work (one transaction per Work) so two concurrent applies cannot both pass the 10,000-code-point quotation budget; past 512 wiki members candidate lookup needs an indexed read (note it if you hit it).

## Do not build

No second review queue, state machine or notification path (G-865, G-866); no automatic
approval or self-review exception; no generated prose; no entity merge (G-869); no wiki
page payload, per-Work Zone creation service or template engine; no deletion of accepted
claims on resubmission; no copy of graph facts in Content beyond evidence and quotations; no disclosure rule, flag,
table or read check of its own (G-539 owns disclosure).

## Acceptance

- API (`tests/qa/integration/g-846*.ts`), Pride and Prejudice fixture: submit a chapter 1–3 bundle via G-865, request changes, revise, apply; characters, relationship claims, evidence and positions exist; the character's Zone detail route resolves for an anonymous reader; the same bundle applied for a private Work writes no Work link and its characters give 404 to anonymous readers; replaying a lost apply response returns the same receipt with no duplicates; an item depending on a rejected entity fails alone; a rights restriction on one evidence row withholds its quote everywhere; a self-review through a second Agent of the same operator is refused (G-865 rule, exercised for this kind).
- Class guard: G-865's adapter conformance suite runs for `wiki-bundle`; a test fails if apply writes any graph record without a revelation position or any claim without evidence.
