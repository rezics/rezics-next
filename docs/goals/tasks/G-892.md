## Outcome

Catalogue fixture query 1: "list one Main Version per series Work in a
franchise, excluding releases; changing the grain to volumes or seasons
changes the list explicitly." Today the web decides series versus parts
itself (G-837 review). After this task Main serves a Collection read at a
requested grain — `series` (one entry per series-level Work) or `parts` (the
member Works' parts via G-830 composition) — with complete cursor traversal,
public-disclosure filtering (G-829's gates) and no releases.

## Do not build

No new storage, no per-medium grains, no client decision about grain.

## Acceptance

API over `tests/fixtures/catalogue/franchises.yaml` (SAO): `series` returns the
web Work, the bunko series, Progressive and Alternative GGO once each; `parts`
returns their volumes; releases never appear; private members never appear or
count.
