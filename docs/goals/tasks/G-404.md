## Outcome

The maintainer clarified the Zone direction on 2026-09-28
(`docs/plan/frontend.md#zones`; read it first). Official Zones exist to
present information the way their field's best site does. They are not
there to change REZICS's visual language, and they are never Home's post
feed. Zones keep the shared visual language unless a Zone explicitly asks
otherwise. The current official packages (fiction, books, mods, ai-workshop)
each carry their own colours and themes; bring them back to the shared
visual language, keeping the package mechanism (slots, digests, safe mode)
for layout.

This task owns the shared Zone host, and makes Mods the first vertical done
properly, modelled on **Modrinth** (with CurseForge and Nexus Mods for
contrast). Study them in a real browser first:
- the home;
- search and browse, with filters by game version, loader, category and
  environment (client or server);
- a project page: gallery, description, versions with their game versions
  and loaders, dependencies, changelog, links, downloads, followers and
  updated date.

Then:

- **Host capabilities every vertical needs.** A Zone can have a browse page
  (`/r/<zone>/browse`) with facet filters, sort (relevance, downloads,
  follows, updated, newest) and a list or grid of listing cards, next to its
  editorial home. Package slots can present a Work's listing card and
  detail sections per type. Filters use the maintainer's query vocabulary
  (`docs/contracts/queries.md`): Facet Conditions and Saved Filters, never
  "kind", "interest" or "category" names. G-400 is defining Facets now.
  Build on what exists (Main's genres read with Sense IDs, Discover's term
  filter), and keep the filter shape ready to move onto the Facet Query
  input.
- **Mods like Modrinth.**
  - The Zone home leads with search and filter chips.
  - Listing cards show icon or cover, name, author, one-line summary,
    downloads or follows, updated time, game versions and loaders.
  - Mod detail sections: versions with compatibility, dependencies,
    changelog and gallery.

  Add the Main reads the presentation needs in `zone-modules` and `package`
  (for example version lists and a mod's dependency list), each bounded
  with a budget test. Access migrations 815–819 are reserved. Where REZICS has
  no data (download counts), show what it has (readers, follows) and say
  so; never invent numbers.
- **Other Zones** (fiction, books, ai-workshop): return them to the shared
  visual language in this task. G-405 owns the Fiction and Books layouts; its
  host needs come to you through the manager.

Add English and zh-Hans strings only. After changing packages, run
`task zones:digest -- <slug>`, and say which digests need approval.
