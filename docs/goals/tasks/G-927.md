## Outcome

The M7 exit (G-704; findings at `/home/edge/projects/rezics/rezics-next/.temp/manager/archive/G-704/findings.txt`) found P1 F2: when a reviewer who lacks
`statement.record`/`statement.withdraw` applies a delta's reversal, the
proposal reads `applied` while its owner command `delta-restore:0` is
`rejected` with `owner_authority_required`, and nothing warned the reviewer.
After this task an application whose owner command is refused never reaches
`applied`: the lifecycle fails closed to a recoverable state that names the
refusal, and before apply the read surfaces missing owner authority in
`blockers`/`allowedActions` so the UI never offers an action that cannot
succeed. A conformance case in the adapter suite covers every adapter.

Also F5 (manager decision): a proposal belongs to the person who proposed it,
not to the credential. A replacement credential of the same proposer (same
Agent, current authority) can revise or withdraw that person's open
proposals; a different person still cannot.

## Do not build

No new lifecycle states unless "refused" cannot be expressed with existing
ones; no UI.
