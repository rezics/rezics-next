## Outcome

(`tests/qa/unit/fixture-manifest.test.ts` goes to G-387, which holds the fixture tests.)

Worker handoffs today reported failures that are not theirs and that every
wave now has to explain away. Make each one pass for the right reason: fix
the code when it's wrong, and the test when it's out of date. Say which, with
the commit that changed the behaviour.

- **`tests/qa/unit/dev-seed-plan.test.ts`**: fails on main (G-383 saw it).
- **`tests/qa/fault-recovery/coordinated-owner-cut.test.ts:191`**:
  `account.verify` now returns `accountDisplayName` and `currentAssertion`
  before the fence assertions run (G-383, QA `20260928t062101-155d1a`).
- **`recommendation-generation` integration**: fails in a shared QA
  project with "Operator permission required" during Account setup, and
  passes alone (G-383, QA `20260928t062034-798d68`). Make it independent
  of order.
- **Flaky stories**: `manage/members.stories.tsx` "Give Role With Impact",
  "Unban Someone Outside The Roster" and "Changed Meanwhile" fail about
  half their runs under load (G-353, G-375, G-386). Make their waits
  deterministic, not longer. `library-page.stories.tsx` "Move Several" is
  also flaky, but it is held by G-391; list it under PROPOSED TASKS.
- **`apps/accounts/features/account/personal-info.stories.tsx:152`**: an
  unawaited assertion found by oxlint (G-373).
- **QA member for Continue**: the signed-in Continue step in
  `work-page.e2e.ts` is skipped because the QA reader has no library.
  Give the QA member a baseline membership and progress in the QA fixture
  so it runs (G-375).
- **e2e budgets**: `scripts/qa/e2e.ts` gives Playwright 300 s and
  Storybook 180 s. Under host load the Storybook step overruns and fails
  tiers whose Playwright tests passed (G-353, G-375). Split the budgets
  per step, or scale them with measured file counts, and report which step
  ran out.
- **`task dev:stop` in a worktree** leaves an isolated backend's containers
  running; only `-- --backend` removes them, contradicting the task
  description (G-382). Make `dev:stop` remove what `dev` started in that
  worktree, and correct `docs/goals/worker.md` if its advice changes.
- **Sign-in helper**: `apps/web/tests/account-sign-in.ts` gives the sign-in
  redirect 5 s, which times out under load (G-353). Use the harness's
  measured timeout.
