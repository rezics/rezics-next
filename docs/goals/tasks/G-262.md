## Outcome

The operator admin panel of the Accounts site must be **genuinely good to use**
(maintainer direction). The Account service already has stored operator roles
(owner/admin/support), a user directory, user detail, suspension with reason
and expiry, session revocation, required password reset, resend verification,
OAuth client management and an append-only admin audit log (G-205; read
`services/account/src/operators*.ts`, the admin routes and their tests).
Build the panel at `/admin` in `apps/accounts`, following the research in
`/home/edge/projects/rezics/rezics-next/.temp/manager/accounts-research.md`
(read-only; section "Admin panel"):

- **Overview:** work queues, not vanity charts (locked/suspended accounts,
  pending verification, recent admin actions).
- **Users:** one search box with operators (`email:`, `handle:`, `status:`,
  `role:`, `created:>`, `-` negation); exact id/email jumps to the user;
  search as you type (~200 ms); column choice; saved views as named URLs;
  all state in the URL; keyboard (`/`, `j`/`k`, Enter, `x`, `?`); a real
  `<table>` with sortable headers and `aria-sort`; skeleton rows; empty states
  that distinguish "nothing yet" from "no matches".
- **User page** tabs: Overview (status with reason and expiry, key dates,
  notes), Security (methods, sessions, security events), Roles (operator roles
  only for owners), Sanctions (history), Connected apps, Audit.
- **Dangerous actions** with friction matching damage (confirm dialog naming
  the user and consequence; typed handle plus re-authentication for the worst),
  required reason code plus text, optional message to the user, duration where
  it applies; server-confirmed pending states, never optimistic.
- **Staff & roles**, **OAuth clients**, **Audit log** explorer (filters,
  default last 7 days, CSV export).
- Cmd/Ctrl-K palette with the same confirmations; density toggle remembered per
  admin; `event.isComposing` respected.

If the Account API lacks something the panel needs (for example directory
filters, bulk actions as background jobs, notes), add it in `services/account`
within your claim with tests, or propose it.
