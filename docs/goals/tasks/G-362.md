## Outcome

1. **Discovery build time**: after the dev stack's clean reset, a discovery
   build of 47 Works took about six minutes, and seed writes cancelled several
   builds before one finished (G-357). At the qualified corpus sizes this
   cannot work. Profile the build (graph queries per Work, rating and
   classification reads, serial counts, credits), make it incremental from the
   outbox where the design allows, bound its per-Work cost, and stop concurrent
   writes from cancelling a build that could finish against a pinned position.
   Add a load test with a target (for example 10,000 Works rebuilt in under a
   minute on this host, and a single changed Work refreshed in under a second)
   and report the measurements before and after.
2. **Baseline failures** reproduced by G-354 on `main` with its own changes
   reverted: a context migration fails with `rating_aggregate_unavailable`, and
   a Statement search returns zero results where two are expected. Find and fix
   the causes without weakening tests.

Backend only, no dev servers.
