## Outcome

Deleting all text from a chapter or text draft saves an empty revision with its digest and
receipt through Main and Content; reopening on another device shows the empty draft, not the
earlier text. Publishing an empty revision is refused with a typed problem. Omitted or non-string
bodies stay invalid; comments keep their own non-empty rule.

Verified defect in both draft paths and the client: `services/main/src/routes/content.ts`
(content-draft `body: t.String({ minLength: 1 … })`) and `saveAdmittedContentDraft`
(`!input.body` in `modules/content-publication/draft.ts`); `routes/contributions.ts` (both
`body` schemas, `minLength: 1`) and `!input.body` in `modules/contribution/draft.ts` and
`edit.ts`; Studio refuses locally (`manuscript-editor.tsx`, `save: body.trim() ? … :
failed`, and the `emptyNotSaved` notice in `change`). Content itself accepts `{"body":""}`
(`services/content/src/core.ts` checks serialized bytes, not text).

## Approach

- Routes and both modules accept `""` (type check stays: `typeof body === 'string'`, byte limit).
- Both publish paths refuse a revision whose body is empty with one typed problem
  (`empty_body`, 422) before any admission side effect; drafts stay valid.
- Studio: remove the `trim()` save guard and the `emptyNotSaved` notice; keep publish disabled
  for empty text. Leave the now-unused `emptyNotSaved` catalog key for the catalog owner to delete
  (locale files are claimed by the catalog briefs). Add an "empty draft saves" story.

## Do not build

No block format, draft deletion endpoint, "clear draft" action, tombstone or Content schema change.
No new message copy. Do not touch comment validation.

## Acceptance

API (integration, `g-526`): save text → save `""` → read the exact revision and digest from a
fresh session; retry with the same key returns one revision; a stale device saving old text on
the old head gets 409, not a silent restore; `body` omitted or non-string is 422; publishing the
empty revision is 422 `empty_body` and the previous publication stays current; a revoked writer
is denied. Same matrix for text contributions. Browser acceptance (two contexts) is in G-530.
