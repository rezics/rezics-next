## Outcome

The maintainer's Zone direction (`docs/plan/frontend.md#zones`): each Zone
presents information the way its field's best site does, in REZICS's shared
visual language. G-404 built the shared Zone host with browse pages. Read
`docs/research/reference-stores.md` first; it has the Steam, Flathub and
AlternativeTo findings.

- **Games, like Steam.**
  - The Zone home is media-first: a capsule carousel, then curated, new,
    upcoming and topical shelves, with review context shown as words ("Very
    positive · 128 reviews"), tags, and platform, language and release status.
  - A game's card and detail sections carry screenshots, the pitch, tags,
    platforms, release date and status, and the review summary.
  - Seed an official Games Realm and about 12 games: well-known public
    information with generated covers, a mix of released and upcoming, a few
    with mods linking to the Mods Zone, and some reviews. Set their type with
    the Work type command (a game type admitted by the model, or
    `schema:VideoGame` if admitted).
- **Software, like Flathub and AlternativeTo.**
  - The Software Zone (an official Realm on tokens today) gets a package.
  - App cards and detail sections show screenshots, platforms and
    architectures, license, source and maintainer, install hand-off per
    platform (REZICS links out; it never implies it installs), current
    version and changes, and attributed alternatives.
  - Seed about 10 real open-source apps with public facts.
- **Main.**
  - Add the reads these need (game facts, app releases per platform,
    alternatives), each bounded with a budget test. Access migrations 835–839
    are reserved.
  - Never invent numbers: show "not tracked" where REZICS has none.

G-404's host (`features/zones`, `packages/zone-sdk`, `features/realm`) is
free, but G-424 is changing the Mods package and the browse host. If a
vertical needs a host capability, say it exactly under PROPOSED TASKS rather
than editing the host. The Work page layouts for games and apps come in a
follow-up after G-415's typed Work pages. Run `task zones:digest -- games`
and `-- software`, and say which digests need approval.

## Verify in a real browser

After `task dev:seed` on the shared stack: `/r/games` and `/r/software`, their
browse pages and several cards, next to screenshots of Steam and Flathub, at
1440x900 and 390x844, en and zh-Hans. Use BrowserOS in your own tab, or
Playwright. Run one web dev server (`task web:dev`) only while checking, and
stop it when done.
