## Outcome

G-947's Space visibility UI (four settings, join inbox, outsider components,
person listing switch) is in this worktree (merge `aa782bee9`). It was built
against G-946's first contract. G-946 is now on `main` and in this worktree
with immutable join requests, an append-only decision table, the manager
decide command and the requester's withdraw command.

1. Point `features/manage/settings-api.ts` and the request client at the merged
   contract (`services/main/src/routes/realm-admin.ts`, `realm-reads.ts`,
   `profiles.ts` here) and remove anything written against the old one.
2. Complete the inbox: server-side search with continuation, approve and
   decline through the decide command, and recovery from stale decisions.
3. The requester's side: request, pending, declined and withdrawn states that
   survive reload, and withdraw.
4. Request managers who lack settings authority see the inbox but not the
   settings.
5. Stories in all eight locales for each state, and a browser test file
   (`g-948*`) for the flows; the manager runs it.
