## Outcome

Implement the web side of [durable addresses](../../product/urls-and-seo.md#durable-addresses)
and [surfaces and routers](../../contracts/space.md#surfaces-and-routers); read
both first. The codec, slug derivation and name normalizers are on `main` in
`packages/model/src/address` (`@rezics/model`). G-937 is building Main's name
registry, resolver and the `address` on summaries in parallel; read its
in-progress contract read-only in `.temp/worktrees/g-937` (routes and schemas)
and code against it, keeping the web's Main client for it in one file so the
manager can adjust it when G-937 merges. Do not wait for it.

Today `/r/[realm]` serves both the community and a Zone site (a Zone's
catch-all loses to the fixed tabs), `resolveRealm` guesses a Zone segment then
a Realm handle, a person without a handle is `/@agent-{uuid}`, and links are
built by hand in about 80 files.

After this task:

1. **One address module** (`features/address/`): parse a path segment into
   `sid`, `sid-slug`, name or legacy UUID; build the canonical href for an
   address from Main's address shape, the page locale and the displayed name
   (derived slug); and decide the one 301 from any other form.
2. **Community router** `/{locale}/r/{space}`: the fixed community routes only
   (feed, about, rules, members, discussions and threads, submit, decisions); no
   catch-all.
3. **Site router** `/{locale}/z/{space}/[[...path]]`: the Zone frame and every
   Zone route, home and browse included, moved from `/r`. A Space with both
   links the two surfaces both ways.
4. **Identity and name forms** for Agents (`/@{handle}` and `/a/{sid}[-slug]`),
   Works (`/w/{address}` and `/w/{sid}[-slug]`), other resources
   (`/e/{sid}[-slug]`) and Concepts (`/concepts/{sid}[-slug]`). Every
   non-canonical form, legacy UUID and old name answers one 301 to the
   canonical URL; the canonical answers 200 with a `<link rel="canonical">`.
5. **Redirects**: old `/r/{zone segment}/…` site paths go to `/z/{space}/…`;
   `/r` (the directory) goes to `/discover?type=communities`.
6. The module and redirect logic have unit tests over every form, and a browser
   test walks a Realm, a Zone, a Work, a person with and without a handle, and
   an old link.

Leave the other ~80 hand-built links alone: they keep working through the
redirects, and a later sweep moves them onto the module with a lint rule.
