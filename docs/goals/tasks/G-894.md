## Outcome

G-840 found that catalogue query 6 fails partly because `GET` progress
summaries return 404 `work_unavailable` for a Work that has no composition (the
web Spider serial). A readable Work without parts is its own unit: its summary
reports finished, reading or not started from the reader's own sessions and
Library status (a Library "read" counts as finished, as G-835 decided), and
never completes a different Work linked by Rewrite.

## Do not build

No new storage; reuse G-835's policy and G-834's sessions.

## Acceptance

API over the Spider fixture (`tests/fixtures/catalogue/franchises.yaml`):
finishing the web Work gives the web Work "finished" and leaves the book Work
unchanged; a private Work still gives the same 404 as absent.
