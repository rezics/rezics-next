## Outcome

The Accounts site (`apps/accounts`) ships eight UI locales with per-key
English fallback (G-288). Translate every English message into **ko** and
**de**: one file per feature and locale,
`apps/accounts/features/<feature>/messages/<locale>.ts`, typed as a
`Partial` of that feature's `en.ts`. The files exist; fill them.

- Translate meaning for people managing their account, in the register Google
  Account uses in that language; for account, security, passkey, two-step
  verification, session, connected apps and similar concepts, use the terms
  Google Account's own UI uses in that locale. Keep `REZICS`, product names,
  URLs, email addresses and code-like tokens unchanged.
- zh-Hant follows Taiwan usage (帳戶, 登入, 密碼金鑰); never convert zh-Hans
  character by character.
- Keep every `insert()` placeholder and `plural`/select structure exactly.
- Do not change English, code or other locales.
