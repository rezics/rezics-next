## Outcome

A Realm can define a rating and review context whose grain is release, realization, occurrence or resource.
Ratings and reviews then target the exact object:

- an edition (a release);
- a translation (a realization);
- a chapter (an occurrence).

A review no longer requires a score. Aggregates state their scope: the question, the grain, the population and
the counted target.

This makes catalogue fixture query 5 pass through the API: edition, story and translation reviews of `sao.bunko`
volume 1 filter separately. Its UI follows through G-644's target-parameterized widgets.

## Approach

1. **Profiles.** Add one pair, `realm-target-rating-context-v1` and `realm-target-rating-observation-v1`.
   - The context fixes `rv:targetGrain` to one of `rv:Release`, `rv:Realization`, `rv:Occurrence` or
     `rv:Resource`.
   - The observation carries `rv:target` (an IRI). The command checks its base through G-506, not SHACL class.
   - The binding is registry-only: no Java case.
   - Existing MainVersion and FixedRelease profiles and observations stay untouched.
2. **Resolver table.** Widen `review` and `rating` in G-506's capability table to these bases. Aggregates for the
   new grain use the existing per-rater aggregation policies.
3. **Migration 960.** In `access.reader_review`, make `rating`, `rating_observation` and `rating_revision`
   nullable together, enforced by a CHECK. Make `main_version` nullable for grains that are not MainVersion.
4. **Reviews.** A review names a context and a target. The score is optional, and when present it proves the
   rating as before.

## Do not build

- A profile per grain or per domain.
- Aspect enums; story and translation are context questions.
- Derived statistics that combine grains.
- Rating import.
- UI (G-644's widgets already take a target).
- Changes to existing rating profiles.

## Acceptance

Through the API:

- **Separate grains.** Create contexts for the release and realization grains. Rate and review one Yen Press
  release and one realization of volume 1. Filters by context return disjoint sets, and the bunko story aggregate
  is unchanged.
- **Score optional.** A review without a score succeeds and appears in the list.
- **Grain checks.** A realization context rejects an occurrence target with 422.
- **Class guard.** A test fails if an aggregate response lacks its scope fields, or if a new-grain observation
  changes a MainVersion aggregate.
