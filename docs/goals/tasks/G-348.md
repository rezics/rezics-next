## Outcome

The maintainer wants official Zones to use full custom CSS and JS "for the
best effect". Fiction has a first-party package (G-296, polished by G-326);
Books, Mods and AI Workshop now have content and modules (G-326) but only the
token-and-layout fallback. Give each a package with its own character, within
the Zones decision in `docs/plan/frontend.md` (named slots, digest-gated,
fallback intact, `?safe`, nonce CSP, 40 KB CSS / 50 KB JS gzipped):

- **Books**: a literary magazine — Goodreads' book-page seriousness with
  editorial columns, "Readers also enjoyed" style carousels (the maintainer's
  screenshot in `.temp/manager/refs/goodreads-readers-also-enjoyed.png`),
  author spotlights.
- **Mods**: a game-mod hub in the spirit of Modrinth and Nexus Mods — game
  and loader filters up front, trending and updated this week, compatibility
  badges, download-first cards.
- **AI Workshop**: a gallery of Skills and Prompts — copy-first cards, tested
  models, "try it" affordances, collections by task.

Study the references with a browser, keep every card's "Why here?" and
author, compute each package's digest with `task zones:digest` and record how
an operator approves it (the theme lifecycle, G-290), and verify with and
without the package (fallback) at desktop and phone, light and dark, en and
zh-Hans. Run one web dev server at a time, only while checking.
