## Outcome

The shell needs a bell with an unread badge and a `/notifications` page like
GitHub's or Reddit's. Main already has the inbox list, the hint WebSocket, read
watermarks and preferences (`routes/notifications.ts`), but items carry only
purpose/topic/subject references and there is no unread count.

1. Return **display-ready items**: actor Agent (name, current handle, avatar),
   a verb the UI can localize (a stable kind enum, not English text), target
   summary (title, excerpt, language, link target), Realm when relevant, time
   and read state. Enforce current disclosure at read time: an item whose
   target the reader can no longer see is omitted or redacted, never leaked.
2. **Unread count** (exact up to a cap, then "99+" semantics), mark one, mark
   all read, and group repeats ("3 people replied to your chapter") with a
   bounded group size.
3. Check which product events already notify (replies to my contributions or
   replies, submission decisions, moderation outcomes, Realm role changes) and
   add the missing producers among those; follows arrive with G-282, so leave a
   typed hook for them rather than editing its module.
