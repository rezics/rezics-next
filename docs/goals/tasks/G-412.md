## Outcome

REZICS models Home on Reddit, and G-401 made posts and threads read like
Reddit's. Three things Reddit users do first are still missing:

- **Create a community.** There is no way to create a Realm from the web; the
  seed creates them through the API (`/v1/spaces`). Build Reddit's "Create a
  community" flow: name and handle, description, public or restricted,
  topics (as Concepts, per `docs/contracts/queries.md`), rules, icon and
  banner. The creator becomes owner and lands in Manage. If Main only lets
  operators create Realms, add a public creation path in Main with sensible
  limits (account age or verified email, rate limits), and tests.
- **Browse communities.** Add a `/r` directory: search, sort (popular, new,
  growing), filter by topic Concepts, and Join from the list, like Reddit's
  community list. Main's `GET /v1/realms` is the start.
- **Start a post.** "Create post" from Home's header or `+ Create`, and from a
  Realm, like Reddit's composer:
  - choose the community;
  - title, then a rich text body;
  - optionally attach a Work;
  - a spoiler flag;
  - drafts that survive a reload.

  Posts follow each Realm's rules and review settings. Where review is
  required, say so clearly before posting. If Main's replies need a Work
  today, add Realm-level posts in Main (a discussion not about any Work),
  keeping the feed's post/Work split from G-401.
- **A person's posts and comments.** Profile tabs list a person's posts and
  comments with links into threads, like Reddit's profile.

Use `@rezics/ui` controls, never a native select. Add English and zh-Hans
strings only. Access migrations 825–829 are reserved. Study Reddit's flows in
BrowserOS (`browseros` MCP, your own tab) or from its public help pages, and
don't sign in to Reddit.

390x844, light and dark, en and zh-Hans. Run one web dev server
(`task web:dev`) only while checking, and stop it when done.
