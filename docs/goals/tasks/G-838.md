## Outcome

Readers record attempts and see honest series progress on phone and desktop:

- The existing status button keeps its one-tap shelves and gains "Details": a
  sheet listing attempts (planned, active, paused, DNF, finished), rereads,
  formats and releases of an attempt, unknown dates, and page, percentage or time
  position with current and furthest shown apart. Edits send expected versions;
  a 409 from another device shows both states and lets the reader choose.
- A series progress panel on `/w/{ref}/connections` shows G-835's four states as
  separate lines, the next part with its reason, and the edition preference picker
  (realization or release, and language).
- Where G-831 records a correspondence, the panel offers "Also mark … as read"
  as an explicit action that writes a session; nothing completes silently.
- `TrackingControl` and `SeriesProgressPanel` are exported for the hub page and
  Library to embed.

## Approach

- Extend the reader store with session reads and writes; keep the shelf
  projection as Main returns it. The client computes no progress, next part or
  coverage.
- Compose from `@rezics/ui` components; copy in the feature's eight catalogs.

- From G-834's review (manager, 2026-10-01): state DNF and two-device semantics in the UI — marking a Work DNF ends the open attempt; two devices that both start an attempt create two open attempts, which the tracking view must show and let the reader close one; page positions need an edition or realization chosen first.

## Do not build

- No episode tracking, loans, import or export screens (deferred or M6b).
- No client-side percentage conversion between editions or languages.
- No hub page or Library page layout changes beyond exporting the components.

## Acceptance

- Browser, two browser contexts as two devices, desktop and phone: start an
  attempt on SAO volume 1 in print, add the audiobook, pause, finish, start a
  reread; the second context's stale edit shows the conflict. Index Original in
  zh-Hant reads "caught up with available material" separately from "finished
  the published parts"; the omnibus plus volume 1 count once; finishing web
  Spider leaves book Spider unstarted until the reader accepts the offered action.
  Reviewed screenshots in the handoff.
- Class guard: a component test fails if the panel renders a state that Main did
  not return or merges two states into one line.
