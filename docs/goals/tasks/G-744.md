## Outcome

On release images built by `task release:images` from one pinned commit, run as
a fresh `ops:bootstrap`, a risk-directed security review of the launch surfaces
finds no open High finding, or lists each one with an owner fix brief and a
failing test. The safety drills that `trust-and-safety.md` requires before
readiness run as executable tests and pass: the public report route used without
an account and from a suspended account; an NCII request tracked to removal of
the item and its known identical copies within 48 hours, with the deadline alert
firing; a scanner outage holding new uploads for review; an appeal decided with
reasons; deletion under a preservation hold; optional notifications missing
while safety mail still arrives; a responder absent, so the backup is alerted.

- M5's reporting, NCII, DMCA, appeal and upload-clearance flows (G-564–G-573 or their successors) that the drills exercise.

## Approach

- Review by reading and by targeted exploits against a disposable stack. Write findings to `.temp/goal/g-744-findings.md` in the worktree (severity, evidence, exploit in words, fix owner) and attach them to the handoff.
- For every High and Medium finding, add a failing test in `tests/qa/integration/g-744*.ts` and name the owner brief. Fix a High yourself only when it lies in no open brief's claim and needs ten lines or fewer; list that fix under OWNER CHANGES.
- Declare the drills in `scripts/qa/cases/launch-safety.ts` and implement them in `tests/qa/fault-recovery/g-744*.ts` over the existing flows. A drill that needs a missing capability becomes a named blocker, never a mocked pass.
- Record in `security.md` only what code cannot carry: the reviewed commit, scope and residual accepted risks.

- Manager (2026-10-01): run now on current main rather than waiting for
  every merge; a short final pass covers what merges after you (G-836 merge
  and unmerge, G-693 wiki deltas, G-854 library import). Security pass 1
  (`/home/edge/projects/rezics/rezics-next/.temp/manager/archive/G-895/report.md`)
  found H1 (closed by G-897/G-904) and M1 (closed by G-898); verify both, do
  not repeat them. Launch decisions to respect: no age assurance (gated
  targets withheld from all, `docs/operations/trust-and-safety.md`); first
  administrator from operator configuration (G-724). Release images: if
  `task release:images` cannot run on this host, review the source at one
  pinned commit and say so.

## Do not build

Product features, a scanner, a paid tool, a SIEM, penetration against anything
but local disposable stacks, or rewrites of flows owned by open briefs.

## Acceptance

The findings file, tests and drills are in the handoff. No High finding lacks a
failing test and an owner. Every drill passes on the pinned images, or is a
named blocker. `task test -- tests/qa/integration/g-744 tests/qa/fault-recovery/g-744`
runs green except for the tests that pin open findings, which are listed.
