## Outcome

Two structural web changes, done now while no other web slice is running:

1. **Locale-prefixed public routes** (decision in `docs/plan/frontend.md#main-site-routes`):
   public pages live under `/en/…` and `/zh-CN/…` (for example
   `app/[locale]/w/[ref]/…`, `app/[locale]/search`, `app/[locale]/discover`),
   each with `hreflang` alternates and a canonical URL; unprefixed paths redirect
   by the locale cookie, then `Accept-Language`; the language switcher keeps the
   current path. Auth, BFF (`/api/*`) and other non-page routes stay
   unprefixed. Internal links, navigation config, stories and e2e specs follow.
2. **Sign-in through the Accounts origin** (the Accounts app on :3004 is the
   public Account origin, G-204). The Accounts worker specified what the web
   must change; do it:
   - `/auth/start` keeps state, PKCE verifier and cookies, then redirects the
     browser to `${ACCOUNT_ORIGIN}/api/auth/oauth2/authorize?response_type=code&client_id&redirect_uri=<web>/auth/callback&scope&state&code_challenge&code_challenge_method=S256&resource=MAIN_RESOURCE`
     (optionally `ui_locales=<web locale>`, or `prompt=create` for "Create account");
   - drop server-side get-session/authorize fetches with the web's cookies and
     the 503 consent path; `/sign-in` and the header link redirect to
     `/auth/start?next=…`;
   - delete `SignInForm` and the `/api/account/*` proxy so passwords and the
     Better Auth cookie never touch the web origin;
   - `/auth/callback` also checks `iss` equals `${ACCOUNT_ORIGIN}/api/auth`;
   - sign-out revokes the refresh token at `${ACCOUNT_ORIGIN}/api/auth/oauth2/revoke`;
   - add "Manage your REZICS Account" to the account menu, linking to `${ACCOUNT_ORIGIN}/`;
   - the dev web-auth fixture marks test identities email-verified (the Work
     page worker kept a fixture email fix in `scripts/dev/web-auth-bootstrap.ts`;
     the integration test should require verified email).

Keep every existing test green, update e2e specs for the new routes and
sign-in, and verify in a real browser with Playwright (the Codex browser plugin
is broken on this host) against the shared stack: sign in via the Accounts
origin, switch locale on a Work page, sign out. Stop your dev servers before
handing off.
