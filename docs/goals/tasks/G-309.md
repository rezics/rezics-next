## Outcome

The catalogue redesign (G-283) put covers, authors, ratings and taglines on
every card, and found that Main cannot fill them everywhere:

1. **Author names**: discovery items' `primaryCredits` have no display names;
   return the credited Agent's name and current handle (native credits) and
   resolved source authors (Open Library), so cards can show "Jane Austen".
2. **Search results** carry what discovery items carry: credits with names, a
   rating summary, tagline, completion status and cover, without widening the
   query's cost bounds.
3. **Popular genres**: a read of the most-used classification terms per
   population (global and per Realm, per language), bounded and cached, so
   Discover's "Popular in {genre}" rows are chosen by the data, not by the
   first books.
4. **Agent works**: `GET /v1/agents/:id/works` items gain types, rating
   summary and tagline, for author pages.

Reuse the summary and serial fields G-291 added rather than computing them
again. Keep disclosure rules and the read-family cost contracts.
