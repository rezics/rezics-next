## Outcome

The maintainer compared the new Home with Reddit and X and found it
uncomfortable: too tight. G-401 took posts from 237–303 px down to about
80–110 px, which overshot. The maintainer's decisions
(`docs/plan/frontend.md#home`):

- Posts breathe like X's: X's padding, type size and line height, with
  generous space between the meta line, title, preview, Work attachment and
  action bar. Comfort wins over fitting more rows.
- Home has one view. Remove the card/compact switch and the cookie that
  carries it. Dense lists belong to catalogues (search results, shelves),
  not the feed.

Measure first, in BrowserOS (`browseros` MCP, your own tab; never sign in):
- X's post rows on a public profile page, and Reddit's card rows on a public
  subreddit: row padding, gaps, avatar, title and body sizes, line heights,
  action bar height, divider, and hover tint;
- REZICS Home next to them at 1440x900 and 390x844.

Write the measurements into the handoff as a table. Then set Home's rows from
them, together with the Realm Discussions list and thread view that share
the row anatomy: X's comfort with Reddit's order (meta, title, preview,
attachment, actions). Keep everything G-401 built: dividers, whole-row click
and hover, spoiler veils, Join, votes.

The CJK line height stays at 1.8 (`docs/plan/frontend.md`), so check zh-Hans
rows as well as English. Add English and zh-Hans strings only. Use
`@rezics/ui` controls.

## Verify in a real browser

On the shared stack signed out and as Daniel (credentials in
`scripts/dev/seed/plan.ts`): Home Best and New, a Realm's Discussions and one
thread, next to your X and Reddit screenshots, at 1440x900 and 390x844, light
and dark, en and zh-Hans. Run one web dev server (`task web:dev`) only while
checking, and stop it when done.
