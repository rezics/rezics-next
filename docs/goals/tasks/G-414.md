## Outcome

Library already matches Goodreads' "My Books" for shelves, ratings and dates.
To make REZICS a reader's home, add what makes people move in and stay,
modelled on Goodreads and StoryGraph:

- **Import.** Upload a Goodreads library export (CSV) or a StoryGraph
  export. Match rows to REZICS Works by ISBN, title and author through
  Main's existing source adoption and search. Show a review step: matched,
  ambiguous (the reader picks), not found (offer to add from Open Library
  through the source flow). Import shelves, ratings, read dates and review
  text, and let the reader choose each review's visibility. Use idempotent
  batches, so re-importing adds nothing twice.
- **Reading stats**, StoryGraph-style:
  - books and chapters read per month and year;
  - genres from accepted Concepts;
  - average rating given;
  - languages read in.

  Show them on Library and optionally on the public profile (following the
  privacy setting). Add a bounded Main read.
- **A yearly reading goal** with progress.
- **Want-to-read count** on the Work page next to "currently reading" (G-394
  left it). Count public libraries only, and add the Content index G-394
  proposed (`reader.library_status (work, agent) WHERE status =
  'want-to-read'`). Content migrations 425–429 are reserved.

Add English and zh-Hans strings only. Use `@rezics/ui` controls. Study
Goodreads' import and StoryGraph's stats pages from their public help pages
or BrowserOS in your own tab, and don't sign in to them.

## Verify in a real browser

On the shared stack as a new reader: import a small Goodreads CSV (write one
with 10 rows covering the classics, 雨夜书店, one ambiguous row and one unknown
book), review the matches, and see shelves, ratings, stats and the goal. Check
the Work page's want-to-read count at 1440x900 and 390x844, en and zh-Hans.
Run one web dev server (`task web:dev`) only while checking, and stop it when
done.
