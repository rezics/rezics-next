## Outcome

Studio v2 (G-316) found two author journeys Main cannot serve:

1. **Submitting a Work, not a text.** Realm submissions accept only text
   contributions, so a chaptered Book is submitted through its published
   introduction. Add submission kinds for a Work (the whole serial, with its
   chapters following as they publish) and for a content publication, reviewed
   under the Realm's review mode (G-298), with the same receipts, withdrawal
   and audit as today's submissions.
2. **Tags by name.** Authors cannot propose tags: `classification.proposition.define`
   is not in the author baseline, and statements need concept IRIs with no
   label lookup. Add a bounded, CJK-aware concept search by label (per
   language, including Realm-local concepts) and an author tag proposal on
   their own Works that a Realm or the global classification then accepts or
   rejects — never a tag the author can make true alone.

Allow and deny tests for every grant. Backend only, no dev servers.
