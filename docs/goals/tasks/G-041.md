Read-only phase-0 scout for the [Goal program](../README.md). Change no tracked
file and make no commit. Write the closure map to `.temp/goal/closure.md` in
your worktree (at most about 250 lines), then hand off with a summary of at most
40 lines. No QA runs, builds or services. Budget about 30 minutes; be terse.

**Scope IDs:** WORK01–WORK10, BOOK01–BOOK10, COMP01–COMP08, WIKI01–WIKI06, VIEW01–VIEW09 (not VIEW04), RECIPE01–RECIPE06, SEARCH01–SEARCH20. Case text lives in docs/testing/native-work.md, book-and-creation.md, content-composition.md, wiki-composition.md, presentation-and-addressing.md, recipes.md and search.md.

For every ID read its row (full assertion text) in the testing page, its row in
`docs/plan/backend-operations.md`, any complete-case declaration in
`scripts/qa/coverage.ts`, and tests whose names carry the ID (`rg -l '<ID>'`
over `tests/`, `services/*/tests/`, `model/tests/`). Inspect code only enough
to decide. Apply `docs/plan/backend-acceptance.md#backend-only-scope` (backend
clauses of mixed cases stay; VIEW04 is excluded). Candidates must be re-judged
against the current, strengthened case text, not their old claim.

`closure.md` sections:

1. **Case table:** ID | status (`candidate-ok` = declared and covers every current
   assertion; `candidate-gap`; `partial`; `missing`) | owner module, existing
   routes/tables/migrations | missing assertions (terse) | depends on | bundle.
2. **Owner schemas (phase A):** per domain, tables/constraints/RDF shapes the open
   cases need that do not exist; existing ones to reuse; duplicate-concept hazards
   (a second receipt, outbox, grant or revision model).
3. **Operation-family templates (phase B):** for protected command write, exact
   revision/history read, query/page, authority decision, recovery-covered owner
   and external source adapter: the verified template files to copy, or missing.
4. **Proposed bundles:** two to six cases closable together. Each: cases, effort
   (`medium` template-following, `high` non-trivial semantics, `xhigh` owner
   schema/first template/authority/transactions/erasure/recovery), disjoint path
   globs to claim, migration directory needs, shared slots, dependencies,
   template to follow, estimated minutes. Flag any case needing an external
   prerequisite (credential, live provider, host capacity) and name it.
