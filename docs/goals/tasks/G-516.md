## Outcome

Text that came from content (titles, names, bodies, rules, excerpts) carries its own `lang` and
`dir` to the DOM, and a name embedded in an interface sentence is bidi-isolated, so a Japanese
title in a Korean interface gets Japanese glyphs and an Arabic name keeps its order. Today about 15
adapters in 7 files build content values with `dir: 'ltr'` or `lang: ''` whatever the text is
(`realm/adapt.ts` ×3, `realm/modules.ts` ×5, `zones/browse-view.ts`, `zones/adapt-cards.ts`,
`manage/parts.tsx`, `library/library-import.tsx` ×3, which also labels import matches with the UI
locale; authoring payloads are G-515's),
and nothing in the web uses `<bdi>` or Unicode isolates; `work-page/credits.tsx` joins names with
commas after translated prefixes.

## What to read

`docs/contracts/content-languages.md#vocabulary-labels-are-graph-content` (bidi isolation);
the claimed files; `packages/zone-sdk/src/index.ts` (`ZoneText`); G-504's `@rezics/main/language`
(`direction`, selection result); `.agents/skills/storybook-ui-review/SKILL.md`.

## Approach

Add one `LocalizedText` component to `packages/ui` that renders `<bdi lang dir>` (or `<span>` for
block text) from a `{ value, language, direction }` value; unknown language renders without a
`lang` claim. `packages/ui` does not import Main: adapters in the web compute a missing direction
with G-504's `direction()`. In each adapter, pass through the
language and direction the API returned, or derive direction from the language; when the API gave
no language, keep it unknown instead of inventing one. Use `LocalizedText` for names inside
interface sentences in credits and the Work header byline. G-501 adds the
`no-assumed-direction` rule that keeps these literals out afterwards.

## Do not build

No ruby, emphasis or vertical text (reading owner), no typography system, no redesign of cards,
no new copy. Leave `post-composer/*` to G-515. Do not touch `apps/web/features/work-page/types/**`
or label maps (served type registry, G-506/G-629).

## Acceptance

Storybook specimens: Japanese title in a Korean interface (`lang="ja"` present), Arabic Realm name
inside an English sentence (order kept, isolated), Hebrew author in credits, unknown-language
title (no `lang`). Browser on the local stack: a Realm page and a Work page with a non-Latin
title render with the right `lang`/`dir` (inspect the DOM). Class guard: adapter tests
(`apps/web/tests/g-516*.ts`) fail if an adapter returns `ltr` for Arabic input or a language for
untagged input.
