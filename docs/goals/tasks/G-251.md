## Outcome

The first real main-site slice: the Work page, which every other surface links
to. Read `docs/plan/frontend.md` (principles, route map: `/w/{slug|id}` with
tabs) and the design research it summarizes: Goodreads/StoryGraph-style header
and rating distribution, Modrinth-style version selection, AniList-style tags
with relevance and hidden spoilers, Wikipedia-style history. Scope is always
visible: a scope bar under the header (Global | a Realm | Mine) re-scopes
ratings, classification and adoption, and empty states name their scope and
offer the neighbouring one; never silently fall back to Global.

## APIs (Main, typed through `treaty<MainApp>`; server reads with `mainApi()` from `features/auth`)

Merged: `GET /v1/works/{id}`, `/versions`, `/rating-contexts`, `/ratings`,
`/classifications`, `/adoptions`, `/credits`, `/history`, `/v1/works` (recent);
read `docs/plan/read-api-design.md` and `services/main/src/modules/work/read-contract.ts`.
In flight in parallel (use them if merged when you get there, otherwise show an
honest "not available yet" region): Work contents/reader (G-235), discussion and
chronological history (G-236), Agent credits/handles (G-238), metadata
completeness (G-241). Slugs resolve through `GET /v1/addresses/work/{slug}`.

If an API is missing or awkward for this page, do not work around it in the
client: note it under PROPOSED TASKS with the exact read the page needs.

## Deliver

- `app/w/[ref]/…` routes: Overview (header with cover, title in the Work-title
  face, original title, type, Main Version label, credits; primary action by
  type — Read for text, later Install/Copy; rating summary with distribution,
  count and Context label; classification chips with relevance and spoiler
  hiding; Realm adoption badges), Versions (filter by language and kind), History,
  plus Contents and Discussion tabs wired to G-235/G-236 reads if merged.
  Tabs are links (own URLs); scope lives in the URL (`?scope=`).
- Server Components fetch regions in parallel with Suspense and skeletons;
  each region fails independently with retry ("Ratings unavailable · retry").
- Redirect the old `/works/[revision]` route to the new one where possible
  (it is in G-202's claim; if G-202 is still open, propose the one-line change).
- Per-feature messages in `features/work-page/messages.ts` (en, zh-CN),
  registered with one line in `i18n/catalogs.ts` (union-merged).
- Stories for every region and state (populated, empty per scope, partial
  failure, long CJK titles, metadata-only Work) with play tests; a Playwright
  e2e against the local stack.
