## Outcome

On an empty production-shaped stack, `task ops:bootstrap -- --plan tests/fixtures/launch/plan.yaml`
creates the first operator through Account's one-time owner bootstrap, then the
official Realms and the Light Novels and Visual Novels Zones from the served type
registry and Zone manifests, and the shared launch vocabulary. It creates no demo
people, Works, posts or ratings. It then runs the launch catalogue: bounded,
rights-cleared dump imports as resumable Main tasks through the API, each source
with a pinned dump version and checksum, dated rights evidence and a named
steward. A re-run changes nothing; an interrupted import resumes.

## Approach

- The plan is data (`tests/fixtures/launch/plan.yaml`): operators, Realms, Zones, vocabulary, sources (dump URL, version, checksum, licence, rights evidence date, steward and backup, bounds). `scripts/ops/bootstrap/` only executes it through public APIs and Main tasks, with the operator's own scoped grants. Any authority the API lacks is a blocker to report, not a fixture shortcut.
- The first source set is what the LN/VN launch needs within its terms: the VNDB dump (ODbL attribution), Wikidata (CC0) and Open Library (per its terms). Bangumi and RanobeDB wait for their terms review. Where a steward is not yet named, the plan carries `steward: TBD`, and bootstrap refuses to import that source in production mode.
- Import size is bounded by the plan. Record the resulting counts per type for G-727's timed drill.
- `docs/operations/production-install.md` is the first-installation and bulk-import runbook.

- Manager, 2026-10-01: Work levels are merged (G-830 composition, G-833 realizations and multi-Work release coverage, G-834 sessions), so imports create series and volume Works, realizations for translations and releases with coverage — never one Work per translation or edition. G-852 (M6b) owns the VNDB-to-graph source mapping as data; this task owns the executor, the plan and bootstrap. Until G-852 lands, prove the executor with a small admitted fixture slice. Bootstrap also provisions the relation-lexicon definition-steward authority that G-832's seed loader needs (`authorizeDefinition`), and the platform moderation scope G-509 documented (`governance:platform`).

## Do not build

A new importer or mapping (a missing mapping is a blocker for the source owner), a full-dump campaign,
live publisher feeds, direct database writes, demo content behind a flag, or a
bootstrap UI.

## Acceptance

- On an isolated QA stack in production mode: bootstrap from empty completes. A second run is a no-op with the same receipts. Killing an import midway and re-running resumes without duplicates. Public reads show the LN and VN Zones, the vocabulary and the imported catalogue, with source attribution. No demo identity exists.
- Class guard: a test fails if bootstrap code imports any `scripts/dev/seed` step that creates people, Works or interactions, or writes a database directly.
