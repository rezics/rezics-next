## Outcome

Every key in `apps/web/features/studio/messages.ts` (English source) and
`messages/zh-Hans.ts` has a natural, idiomatic translation in zh-Hant, ja, ko,
de, fr and es, with identical placeholders. The translation lanes G-502 and
G-503 skipped Studio because G-591 held these files.

## Approach

Follow the existing translated catalogs of other features (for tone, terms and
formality, e.g. `apps/web/features/settings/messages/*.ts`). Keep product terms
consistent with them (Work, Realm, Zone, Studio, chapter). Traditional Chinese
is written for Taiwan, not converted character by character from Simplified.

## Do not build

No new keys, no English copy changes, no code changes.

## Checks

`task i18n:check` reports zero missing keys and zero placeholder mismatches for
`studio` in the six locales; `task web:typecheck`.
