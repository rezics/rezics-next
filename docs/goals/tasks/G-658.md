## Outcome

R49 F1/F3, the web half. `ZoneWork` in `packages/zone-sdk` has no `mod`, `game` or
`software` field and the SDK no longer exports `ZoneModRelease`, `ZoneGameFacts` or
`ZoneSoftwareFacts`. The Games, Software and Mods packages render only generic card
fields. Zone browse offers `type`, Tags (`concept`), `status` and `length` only, labelled
from `GET /v1/facets` (already read as `readFacets`); the mod-environment cookie, its
preference control, `readModExact` and the `Minecraft` default are gone. A mod Work page
keeps listing its releases from the package capability's own `/v1/mod-releases` read.
This runs first: Main still sends the mod fields until G-657 removes them, and the web
simply stops using them.

## Approach

Delete, do not replace. Drop the mod entries from the browse facet list and URL
parameters (keep the other parameters and their URLs stable), the cookie helpers and
`withModPreference` calls in `routes.tsx`, the exact-compatibility read and selection in
`work-sections.tsx`/`mod-sections.tsx` (keep the release list), the bag mapping in
`adapt-cards.ts` and `realm/modules.ts`, the facts panels and links in the three package
`slots.tsx` files (leave their `strings.ts`: G-503/G-531 own them), and the fixtures,
stories and now-unused `features/zones/messages*` keys in all eight locales. Recompute
the three package digests; the manager approves them when it re-seeds.

## Do not build

No replacement compatibility UI, platform or release filter, client-side filtering,
generic SDK section API (G-644 designs it) or new copy. Leave the `hub` field, the
serial fields and `kind` alone. Do not touch `apps/web/features/work-page/**` (G-655).

## Acceptance

Real browser on the local stack, phone and desktop: the Mods, Games and Software Zone
homes and browse pages render without mod chips, empty facts panels or console errors;
browse by status, length and Tags still narrows results with the same URLs; a mod Work
page lists its releases. Screenshots inspected. Class guard: `apps/web/tests/zone.test.ts`
asserts the exact key set of `ZoneWork`, and `apps/web/tests/g-658*.ts` fails when the
browse facet list names a Facet absent from the admitted-Facet fixture.
