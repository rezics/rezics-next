## Outcome
A platform staff member opens Manage → Safety on a phone or desktop and can:
- see the platform queue with urgent and overdue cases first;
- filter by category, language, urgency and due time;
- claim a case and read its evidence and correspondence;
- decide, with the statement of reasons previewed as the party will see it.

Every decision is a G-565 API call, and so is every later revisit. Staff can
revisit a decision, see appeals and counter-notices, and reverse or uphold.
- An NCII case shows its receipt time and its time left.
- A DMCA case shows the earliest and latest restoration dates.
- Urgent evidence is visible only to the specialist role. Other staff see that
  it is restricted.

## Approach
- Reuse the Realm queue components and parametrize them by jurisdiction; do not fork them. The site frame hosts the platform queue at `/manage/site`.
- Simple mode shows one case with its permitted decisions. Advanced mode adds keyboard triage and the log.
- The reason dialog takes a rule and its revision, facts, scope and duration, marks whether automation was involved, and previews the statement.
- Keep all strings in the manage messages for eight locales.

- Manager (G-565 merged): the public case status now carries `statementOfReasons` (facts, scope, duration, automation, appeal route, rule ref/revision/digest) and `operation`. Show the statement of reasons on the reporter's/party's case page (`features/safety/case-view.tsx`) as the API returns it; staff decisions in Manage write those reasons. No Storybook/web dev servers.

## Do not build
- No new API or client-side status logic: show what G-565 returns.
- No undo button.
- No bulk moderation, analytics or dashboards.
- No Realm workspace redesign.
- No evidence download for restricted cases.

## Acceptance
- Browser, against the local stack:
  - A staff user claims an NCII case, sees its deadline, restricts it and reads the recorded reasons.
  - A second tab shows the claim.
  - An appeal arrives, the staff user reverses it, and the content is visible again. G-542 is checked by opening its page.
  - Non-specialist staff see "restricted evidence" on a child-safety case.
  - Run at 390 px, keyboard-only, and in `zh-Hans` and `ko`.
- API parity: the network log shows only G-565 calls, and decisions carry idempotency keys.
- Stories cover the queue states (empty, overdue, urgent, claimed by another) and the decision dialog.
