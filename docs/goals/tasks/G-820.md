## Outcome
On phone and desktop, in all eight UI locales, people can do the following in a
real browser:
- Report from a profile, a post or a reply. The Report action opens the report flow for that target. The Work hub (G-850), Zone and wiki pages place the same `ReportAction`; that is their work.
- Open a public `/report` page without signing in and choose a category. Each category shows its short form: the NCII and copyright forms show the required declarations, and the counter-notice form warns that contact details are disclosed.
- Submit, then land on a private status page they can bookmark. There they read the status, the outcome and its reasons, send follow-up, and, as the affected party, appeal or send a counter-notice.
- Signed-in reporters see their own reports.
- Uploading a cover, avatar or community image shows `Checking`, `Visible`, `Under review` or `Not accepted` from G-571's states. A spent budget shows when to retry (G-543's `Retry-After`).

## What to read

  - intake, categories and declarations;

  - a feature `messages/` folder with eight locales.
- `.agents/skills/storybook-ui-review/SKILL.md`.

## Approach
- One shared `ReportAction`, built from the target id and a label, lives in `features/safety/`. Each named surface adds it with one line to its existing menu.
  - Zone and wiki pages consume the same component; that is the Z and wiki areas' work.
- Keep the case credential out of server logs and referrers:
  - Put it in the URL fragment.
  - Read it on the client, send it in a header through the BFF, and set `Referrer-Policy: no-referrer` on `/report`.
- Upload controls map G-571's states to one shared status line. Delete the old "done means visible" assumption in `cover-api.ts`.

## Do not build
- No moderation UI; that is G-821.
- No new API calls beyond G-564, G-571 and G-543.
- No evidence or image upload field.
- No client-side category logic that the server does not state.
- No account-required step, and no CAPTCHA.
- No redesign of the host surfaces.

## Acceptance
- Browser, against the local stack, at 390 px and at desktop width:
  - Report a reply while signed out. Reopen the status link in a new browser and send follow-up.
  - Submit NCII without an image and see the 48-hour notice.
  - Appeal as the affected party from a suspended account's email link.
  - Upload a fake-flagged cover and see "Under review", then "Visible" after G-565 clears it.
  - Keyboard-only runs; `zh-Hant` and `ja` render.
- API parity: the network log shows exactly G-564's calls, and no credential appears in any URL path or query.
- Class guard: a test lists every surface in one table and fails if a surface lacks `ReportAction`.
- Stories cover each category form and each upload state.
