## Outcome

Goodreads' "Readers also enjoyed" row is the part of its book page the
maintainer called beautiful and worth copying
(`.temp/manager/refs/goodreads-readers-also-enjoyed.png`: four to six
cover-first cards, each with title, author, average rating and rating count,
paged by arrows). REZICS's Work page has "More by" but nothing like it. Build
the read in Main; a later web task renders it on the Work page.

`GET /v1/works/:id/also-enjoyed?language=&limit=&cursor=` returns Work cards
(the same card fields the catalogue and Zone reads return, with author
credits and rating summary) for Works that readers of this Work also enjoyed:

- **Signal.** Readers who rated this Work 4 or more, or shelved it as read
  or currently reading, and who also rated another Work 4 or more or shelved
  it as read. Only public signals count: private shelves and libraries
  never contribute, and nothing reveals who. Weight by overlap relative to
  each Work's popularity so the most popular Works don't fill every row.
- **Fallback.** When fewer than four co-readers exist (the common case on a
  young site), fill with Works that share the Work's accepted
  classifications, then type and language, then the same Realm's picks,
  and say which basis each card came from (`basis: "co-readers" |
  "similar" | "realm"`) so the UI can title the row honestly ("Readers also
  enjoyed" vs "Similar books").
- **Exclusions.** Not the Work itself, not chapter Works, not the same
  author's Works (that is "More by"), nothing the viewer can't see.
- **Cost.** Bounded like the other Work reads (`work/read-session.ts` budgets;
  the recommendation README's cost contract is the model). If the signal
  needs a derived table to stay within budget, follow
  `modules/recommendation/README.md` and say why in the handoff; reserve an
  Access migration range with the manager first if you need one.

Register the route in the OpenAPI operations and add it to the Main client so
the web can call it through Eden. Tests cover the privacy rules, the
fallback, the exclusions and the budget.

## Verify
