## Outcome

A short exit report in the handoff that maps each M4 exit clause in `GOAL.md` (counterexample
fixtures pass; simple edits keep richer state; denied and revoked operations fail correctly; the
language and profile guards fail on deliberate regressions) to passing tests or browser runs with
their run IDs, plus a `product-audit` pass over the M4 areas listing any open P0/P1 class. Two new
test files carry the lasting evidence; production defects go back to their owners.

Draft covers: not reproduced as a disclosure. Studio uploads covers as `public` assets
(`apps/web/features/studio/cover-api.ts`), but `/v1/media/avatars/:selection`
(`services/main/src/routes/media.ts`) delivers a Work's avatar only when `readResourceSummaries`
admits the reader, and a draft Work (no public Main selection) is restricted, served with
`private, no-store`. This brief locks that behaviour with a matrix instead of changing it.

## Approach

- `tests/qa/integration/g-530-draft-cover.test.ts`: for a draft Work with a cover, anonymous,
  a stranger and a revoked writer get the same unavailable answer for the avatar URL and summary;
  the writer gets the bytes with `private, no-store`; after replacement the old selection is
  unavailable; after publication the cover becomes public with `public, no-cache`.
- `apps/web/tests/g-530-m4.e2e.ts`, desktop and phone widths, one non-UI content language:
  record read dates in the library, change status from a card and from the Work page, reload,
  dates remain; empty a chapter draft, see it saved, reopen in a second context, still empty,
  publish disabled; Concept page with two additions on "any" shows only Works with the page
  Concept; a signed-out context sees no draft cover.
- Deliberate regressions in this worktree only, reverted before handoff: edit a constraint in an
  accepted profile (`task gen:check` must fail), delete one key from a locale catalog
  (`task i18n:check` must fail), make the status store treat an omitted date as null (G-517's
  tests must fail) and `setStatus` send nulls again (this brief's journey must fail), and skip one
  authority fence named in G-508's handoff (its tests must fail). Record each result.
