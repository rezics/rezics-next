## Outcome

The Realm home read (G-239, merged: `services/main/src/modules/realm-reads/**`)
returns null or unknown for description, banner, community rules, public roster
counts and moderators, because no owner publishes them publicly. A Realm home
modelled on Reddit's community sidebar needs them. Add the public owners:

- **Publication commands** for a Realm's public profile: localized name and
  description (en, zh-CN at least), banner and icon (through the existing
  media API), community rules (ordered, localized, with short titles and
  bodies; distinct from the governance rule engine, but link to it where a rule
  is enforceable), with Access admission (Realm managers only), receipts and
  revisions like the existing command families.
- **Public roster facts**: a member count that is exact or explicitly
  estimated/unknown, and the public moderator list (only Agents who chose a
  public moderator role; private grants never imply public membership).
- **Reads**: make the Realm home read return these fields; keep the cost and
  disclosure contract in `docs/plan/read-api-design.md` and update its row.

Follow the Realm reads template in `services/main/src/modules/realm-reads/**`
and the command patterns in the existing Space/Zone owners. Owner schema first,
then the command path, then reads; tests for denied, stale, concurrent and
disclosure cases.
