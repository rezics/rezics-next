## Outcome

G-382 added author pages for Open Library authors (`/authors/open-library/<OL…A>`),
but nothing links to them, and its "Readers" total counts people whose
shelves are private.

- **Privacy (manager's decision).** An author page's "readers" counts only
  people whose library is public, the rule G-381's also-enjoyed read already
  follows: private shelves never feed a public number. Change the Main read
  and its tests.
- **Work page links.** `work-page/credits.tsx` links Open Library authors to
  openlibrary.org; link them to their REZICS author page with
  `authorHref({ kind: 'external', key })` from `features/author/route.ts`.
  Link native authors with `authorHref({ kind: 'agent', handle })`.
  `work-page/author.tsx` "About the author" handles only a native first
  author; extend it to an external first author (name, lifespan, "More by"
  from `/v1/authors/open-library/{id}/works`).
- **Discover cards.** `discover/cards.ts` produces card authors as plain
  strings; give them hrefs where the helper can. Catalogue, feed, search,
  profile, library, realm and Zone cards are held by G-377. List the exact
  producer changes they need under PROPOSED TASKS (G-382's handoff names
  them: `catalogue/work.ts:20`, `work-row.tsx:40`, `work-tile.tsx:69`,
  `feed/card.tsx`).

Add English and zh-Hans strings only.
