# Digest construction inventory

Read-only source inventory of services and packages, with scripts included when their values are consumed by a service. Searches covered createHash/createHmac, Bun hashers, Web Crypto, JSON.stringify, key iteration, canonical/stable serializers, and named digest/fingerprint helpers; candidates were followed to callers, retained representations and comparisons. This report makes no implementation change.

Each row identifies a digest with multiple production input paths: independently assembled writer/verifier inputs, admission/owner inputs, old/new paths, or reconstruction from retained state. Object-valued array elements count; primitive-only arrays, scalar/delimited identities and immutable byte hashes do not. Several fixed shared constructors are included to distinguish them from the unsafe class. Quoted code is an excerpt; an ellipsis denotes omitted code. Paths and line numbers refer to this checkout's source snapshot. A named hash site is the digest-producing call, even when its SHA-256 primitive is an imported string helper.

HIGH means separate order-dependent input assembly with a retained representation involved. MEDIUM means separate explicitly ordered/canonical constructors, or a shared constructor retaining caller/spread/nested-object order. LOW means a shared fixed or recursively canonical constructor. Retained storage and verifier paths are code evidence; no live database census was run. The brief supplies the eligibility observation (86 retained receipts verify using API order, zero using reader order); the other HIGH rows are source-derived hazards, not measured failure counts.
