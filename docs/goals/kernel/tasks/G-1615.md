## Outcome

A PURE MOVE (Trust-ops' request after G-1599 landed on main at `0495f0521a1b`: owner removal of a Work co-maintainer; the maintainer set, its owner flag and its receipts are Access state). `services/main/src/modules/work/maintainers.ts` (`WorkMaintainers`, `MAINTAINER_COST`, `MaintainerChange`) and `services/main/src/modules/work/maintainer-proof.ts` (`maintainerControllerProof`, `recordInitialMaintainer`) read and write Access-owned tables (`access.work_maintainer*`) and import Access internals (`controller-continuity`, `topology-control`, `admission`, `baseline`), so they are on the frozen crossing list (`scripts/static/mechanism-dependencies.json`: `modules/work/maintainers.ts -> ...`). Move them into `services/main/src/modules/access/` as `work-maintainers.ts` and `work-maintainer-proof.ts`, register the entry points of the `access-authority` mechanism in `scripts/static/mechanisms.ts` (`work-maintainers.ts#WorkMaintainers`; `work-maintainer-proof.ts#maintainerControllerProof` and `#recordInitialMaintainer` only if code outside Access still imports them after the move: prefer routing those through `WorkMaintainers` or the existing admission sealer so the entry-point list stays minimal), and update every importer.

RULES:
1. BEHAVIOUR UNCHANGED, byte for byte: no SQL, no authority rule, no error text, no cost constant changes. `git diff -M` on the two files shows renames with only import path edits. The owner flag, `remove` action, migrations 1782-1784 and their tests (G-1599) stay exactly as they are.
2. IMPORTERS from the list above: `composition.ts`, `access/admission.ts`, `access/baseline.ts`, `access/realm-management.ts`, `studio/access.ts`, `routes/dependencies.ts`, `scripts/static/mechanism-writers.ts` (a writer registry that names the owner file: update the path and keep its protected-effect row), the four tests and fixtures. A file inside `modules/access/` imports its sibling directly; code outside imports only the registered entry point.
3. `scripts/static/mechanism-dependencies.json` shrinks: remove every pair whose importer is the old file and every pair that disappears because the importer is now inside Access; report the count before and after; NONE may be added. `scripts/static/mechanism-dependencies.test.ts` allowed-file snapshot is updated for the new entry points.
4. NET LINES: report `git diff --stat main...HEAD` for non-test source. A move with no logic change should be about zero; any growth must be a registered export wrapper and be named.

Proof: the existing maintainer tests unchanged and green: `grep -rl "work-maintainer\|WorkMaintainers\|maintainerControllerProof\|recordInitialMaintainer" services/main/tests tests/qa | head -30`, run the unit/owner ones and the integration ones that are cheap (`access-author`, `post-lifecycle`, the G-1599 files `work-maintainer*.test.ts`), report run ids; the mechanism guard tests (`mechanism-dependencies.test.ts`, `mechanisms.test.ts`, `mechanism-writers.test.ts`); `task main:typecheck`, `task gen:check`.
