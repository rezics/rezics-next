## Outcome

Gradual opening (standing direction 11; design record §9 "平台權限與逐步開放"):
an operation that is not public needs a platform grant, and a generic
operation must not become a back door to a closed capability. Trust-ops' T5
(G-1235) provides `requireSelectedPlatformCapability(platformAccess,
principal, { exposure, operationId })` in `services/main/src/modules/access/exposure*`.
Dispatch waits until T5 is on `main`; read its merged code first.

Call it in kernel's generic operations **after** the server has selected the
template, profile or command, never from the client's own description of
what it wants. Trust-ops listed the call sites with reasons:
`/home/edge/projects/rezics/rezics-next/.temp/trust-ops/t5-call-sites.md`
(sections "Kernel query", "Kernel graph", "Kernel export", "Kernel edits").

- **Query:** `compileQuery` and `routes/query.ts` after compilation;
  `routes/search.ts` `/queries`, `/queries/page` and private query selection;
  `routes/content-private-search.ts` and its WebSocket message owner, which
  rechecks each private delivery's selected template. Bind saved-views,
  events, commerce and llm-index to the validated template or profile.
- **Graph:** `routes/graph-queries.ts` at its validated profile selection:
  only the direct one-hop profile is public; multi-hop or SPARQL-shaped
  profiles need `sparql`.
- **Export:** `readExportPlan`, `createAdmittedExport` and
  `readAuthorizedExport`: the server-selected `targetProfile` for fixed
  release, historical or whole-dataset sources needs `dataset-dumps`, decided
  from the selected profile, never from the client's `selection.kind`.
- **Edits:** `semantic/admitted.ts` (semantic and relation changes, bulk
  included) and the content-edits route in `routes/content.ts`: bind events,
  commerce and worldbuilding to the resolved type or command.

The Context and Person-scheme call sites (`routes/contexts.ts`,
`context/command.ts`, `classification/context.ts`) are G-1243's, not this
task's.

A `PlatformClosed` refusal stays a 403 `platform_closed` through every owner
error adapter; it never becomes a generic 503. Resource authority is still
required after the gate passes; an operation-specific grant opens the
capability only for that operation.

Not to build: no second gate, policy table, feature-flag layer or per-route
wrapper; one call per selection point, using T5's function.
