## Outcome

Contract C5, first slice. Design record §5 "接口細節（C1）" and §14 row 13
(`.temp/ref/target-architecture.md`); the read-only scout with line evidence
(`.temp/ref/K7.md`); and a 53-line prototype (`.temp/ref/query-probe/`). All
are staged in your worktree by the manager. C3's local read basis (K4,
merged) is on `main`: reuse its dependency tokens, cursor envelope and
admission fences; do not build another.

1. **Three templates.** `GET /v1/works/{id}/versions`, `/adoptions` and
   `/credits` become reviewed SPARQL templates under
   `services/main/src/modules/query/templates/`: a `.rq`, a declarative schema
   (query IRI and revision, public parameter schema, response schema, scope,
   server-bound inputs, physical access eligibility, budgets) and a fixture
   each. One adapter (`query/template-read.ts`) executes them through the
   existing `/v1/query`; `read-pages.ts` and the three GET handlers go, and
   the web callers in `apps/web/features/work-page/{read,types}.ts` move to
   the query route in the same change (lent by launch for these three reads
   only). The web Work page's visible behaviour stays the same, including
   paging, the partial or `complete` state and empty or closed states; the
   existing work-page tests and stories stay green, and any you touch go
   under OWNER CHANGES.
2. **Typed parameters.** Parameters bind as RDF terms in a thin Jena binding
   operation in the command module (`TemplateQueryService.java`), not by
   string substitution; `ParameterizedSparqlString` text replacement does not
   meet this contract.
3. **Budgets enforced where they belong:** roots ≤ 64 and page default 20,
   max 64 in the request schema and adapter; at most two hops, fixed graphs
   and no `SERVICE` at template review; ≤ 256 candidates before hydration;
   ordering must have a seek path (`ORDER BY … LIMIT` alone is not proof).
   Credits keep bounded source-credit tuples as server-owned bindings with
   confirmed-key precedence.
4. **OpenAPI from the response schemas** via the installed application in
   `scripts/api/generate.ts`; no runtime registry and no hand-kept dispatch
   map keyed by query ID.
5. **The fourth view proves the contract.** Launch's Home needs a public,
   server-selected read of a followed Concept's feed (public items accepted
   under that Concept, newest first, seek-paged). Add it as a fourth template
   that adds only a `.rq`, a schema and a fixture, with no handler or adapter
   change. It is public; saved views stay closed.

`work/read-contract.ts` is held by G-1271 (private names); if you must change
it, stop and hand off the exact change.

Not to build: no arbitrary SPARQL, `SERVICE`, query language, generic write
engine, remote JSON-LD contexts, exact-count scan, runtime registry,
query-ID switch or wholesale migration of `query/compile.ts` (its six
existing kinds stay). Cursors and ETags bind template revision, normalized
inputs and local dependencies; fresh admission precedes any 304.
