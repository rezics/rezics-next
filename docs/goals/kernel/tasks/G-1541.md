## Outcome

Two regressions found by G-1524's cost runs, both caused by Kernel's own earlier landings; neither cap may be raised.

1. **`g-1042` (find the exact file: `ls tests/qa/integration | grep g-1042`)**: `postgresStatements` 12 > 6 on the realm header. Cause: commit `2d7a16eb5` (one admitted-type catalog read per request: `services/main/src/app.ts` request hook calls `beginRequest`/`endRequest`; `modules/types/store.ts`) makes `createMainApp` load the admitted-type catalog on EVERY request, including anonymous requests that never need it: the extra span is an access transaction of BEGIN, two SETs, two SELECTs and COMMIT under the anonymous request hook. Fix: load the catalog lazily on first use inside a request (a request-scoped memo created on first read, no eager transaction in the request hook), and fold the SET/SELECT into the statement that already runs where possible; a request that never touches types must pay ZERO catalog statements. Keep the guarantee G-1517 wanted: a page of 1, 16 and 64 reads the catalog at most once (the test `services/main/tests/page-size-type-catalog.test.ts` stays green and gains a case: a request that never reads types issues no catalog statement). No cross-request cache (stale admission).
2. **`g-1012`** (`tests/qa/integration/g-1012-*.test.ts` and `services/main/tests/g-1012-*`): `unavailablePreviews` is `['serial','credits']` against the expected `['serial']`. Cause: card hydration (`services/main/src/modules/search/result-cards.ts`, changed by the credit-roles work) adds `credits` as unavailable when the test's deps omit a credits owner. Decide with evidence which side is right: if a deployment really has no credits owner then `credits` unavailable is correct and the test's deps must provide the owner (fix the fixture to the production composition: composeMain provides it); if the production code reports `credits` unavailable when the owner exists but the read simply has no credits to show, that is the bug (fix it). Do not weaken the assertion.

Run each affected file alone before and after (`USER=edge LANG=C.UTF-8 LC_ALL=C.UTF-8 task goal -- test <path>`), report run ids and the statement counts. Do not touch `services/main/src/modules/rights/` or the Java command module.
