## Outcome

`scripts/static/list-convention.test.ts` fails because three kernel
collection reads omit `response.complete`:
`GET /v1/posts/{id}/identifications` (post-identifications-v1),
`GET /v1/projections`, and `GET /v1/resources/{resource}/continuities`
(work-continuities-v1). Add `complete` to each response with the meaning the
other collection reads already use (follow an existing read that has it), set
it truthfully from the bounded read, and leave everything else unchanged.
`GET /v1/works/{id}/credits` is being replaced by another task; leave it.

## Checks

- `task goal -- test scripts/static/list-convention.test.ts` no longer lists
  these three operations.
- `services/main/tests/list-convention-kernel-reads.test.ts`: each read
  reports `complete: true` for a short list and `false` when the bound cuts
  it.
- `task gen` then `task web:typecheck` (served contract; list web callers
  that read these under OWNER CHANGES), `task main:typecheck`, oxlint.
