## Outcome

A Zone must filter and sort Works by year, newest first, over the first-publication date Statement (`schema:datePublished`, the qualified retained exception in `statement/qualification.ts`). This is the one literal facet Launch needs (mail `launch-wave2-kernel-reply-1008`); it is a fourth view of the C5 kind: a reviewed SPARQL template with typed parameters, a response schema and access budget, a shared adapter, a fixture. Follow how Work versions/adoptions/credits templates are registered (`query/templates/*.rq`, `services/main/src/modules/query/**`, the `concept-works-v1` template) and reuse the shared adapter; no new handler logic.

Parameters: `fromYear`, `toYear` (integers, optional), a page `limit` and an opaque `after` cursor over (year descending, Work id). The cost is a seek over the accepted Statement tuples for the year range, never a scan of all Works (asymptotic scale: bounded neighbourhood per page; state the access budget). Only accepted, publicly visible Works with an accepted first-publication Statement appear; year is the calendar year of the Statement's typed date (xsd:date/gYear/dateTime), not a string comparison on lexical forms. Include the filter as a combinable facet with the existing concept facets if the facet mechanism allows it without new machinery; otherwise expose it as the template only and report.

Do not build: season, month filters, a general literal-value facet framework, indexes beyond what the template needs (if it needs a native index or projection, stop and report the cost model before building it), web UI.

## Checks

- Unit test `services/main/tests/year-fact-read.test.ts` for parameter validation, year extraction across the three date types, cursor order.
- Isolated integration `task goal -- test tests/qa/integration/year-fact-read.test.ts` with Works across several years, a hidden Work that must not appear and a Work without the Statement; plus a size case of at least 5,000 dated Works showing the per-page cost does not grow with the total (report the measured counters).
- `task main:typecheck`; template registry/model checks the change selects.
