## Outcome

Abstraction audit A1a. `services/main/src/modules/release/command.ts` (331 lines) and `services/main/src/modules/realization/command.ts` (274 lines) carry about 66 identical lines of receipt and cancel envelope: `releaseReceiptIri`/`realizationReceiptIri`, `ReleaseCommandReceipt`/`RealizationCommandReceipt`, `readReleaseReceipt`/`readRealizationReceipt`, `sealRelease`/`sealRealization`, `loadRelease`/`loadRealization` and the cancel/denied/stale/lost-response handling in `setRelease`/`setRealization`. One shared envelope replaces both; a third command family is then a parameter, not a copy.

1. First prove the duplication with `diff` of the two files after renaming (report the exact identical blocks). Extract only what is identical in shape and behaviour into one helper module (`work/command-envelope.ts` or beside `context/command.ts` if `runAdmittedCommand` already holds half of it; read it first and reuse, do not create a second runner). Each family keeps its own record projection, coverage facts and schema; they pass them as parameters.
2. Behaviour is UNCHANGED: denied, stale (expected revision), revoked authority, lost response (receipt reread by admission id), partial dispatch and cancel behave exactly as before. The acceptance is the existing tests: `grep -rln "setRelease\|setRealization\|readReleaseReceipt\|readRealizationReceipt\|commitRelease\|commitRealization" services/main/tests tests/qa` and run every file found (run ids in RESULT). Add ONE focused unit test for the shared envelope covering the five outcomes above with a fake environment, so the next family is proven by the same test.
3. NET LINE DECREASE is the acceptance for the code: report `git diff --stat main...HEAD` for non-test files; it must be a net decrease of at least 40 lines across the two command files plus the helper. If it is not, say why and stop (do not pad). No new framework, no registry, no abstract class hierarchy; functions and a parameter object.
4. Update the module README guidance that says to copy the Release/Realization command for another family (grep `services/main/src/modules/*/README.md` for "copy") to name the shared envelope instead.

Commit after each step.
