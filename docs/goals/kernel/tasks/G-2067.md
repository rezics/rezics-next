Today `readPublicTypeahead` calls `fillPrefixWalkPage` whose `walk` callback hydrates (candidates, disclosure, types, summaries, authors) per native batch of <= 10 entries, up to the 40-entry examined cap. Change it to two phases inside the same session and snapshot:
