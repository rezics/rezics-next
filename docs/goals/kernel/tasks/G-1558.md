## Outcome

Program's tooling audit item 7: `packages/model/src/document.ts` (159 lines) is a legacy BlockNote-shaped document runtime whose only consumers are its own tests (`document.test.ts`, `locator.test.ts`); its `isJson` is an exact copy of `packages/document/src/index.ts:18-34`. Retire it, keeping one representation per meaning (the current one is `packages/document`).

1. First prove the claim with commands, not memory: `grep -rn` every importer of `document.ts` and every symbol it exports (including `packages/model/src/index.ts` re-exports) across packages, services, apps, scripts, tests, docs and generated files. List them in RESULT.
2. Check retained export and archive FIXTURES: any stored fixture, golden file, archive or export test that reads a document in the legacy shape (grep for the legacy block/type names in `tests/`, `services/*/tests`, `scripts/**/fixtures`, `model/`). If one exists, either the current `packages/document` reads it (then convert the fixture, say so) or the fixture proves the shape is still needed (STOP, keep the file, RESULT says what consumes it).
3. If nothing real consumes it: delete `document.ts`, its test, the re-exports from `index.ts`, and any part of `locator.test.ts` that exists only to exercise it (keep the locator assertions that do not depend on it). If `isJson` or another helper is imported from it somewhere, import from `packages/document` instead.
4. Never weaken a test that guards current behaviour; only delete tests whose subject is the removed runtime.

Commit after each step.
