## Outcome

Recipes for the L21 real-data fixtures: pin (1) The Boston Cooking-School Cook Book (Fannie Merritt Farmer, 1896, Project Gutenberg ebook 65, US public domain) and (2) one NON-UI-language recipe book, Pellegrino Artusi, La scienza in cucina e l'arte di mangiar bene (Italian, public domain; find its Gutenberg ebook id by catalog search at pin time and record it). Cases they must prove: sectioned recipes; an ingredient used in two stages (a pastry with flour for the dough and flour for rolling); fractional quantities (1/2, 3/4, mixed numbers); quantity ranges; the Italian book for readable content outside the eight UI locales. Use the existing Gutenberg text pin mechanism (`gutenbergTexts`, the outline and parts pins) and add, for each book, the pinned UTF-8 text plus a RECIPE EXTRACT pin: the exact line or byte ranges of N recipes that prove those cases (N about 20 for Boston, about 10 for Artusi, each with its title, section heading, its ingredient lines and method), recorded as data with the source edition's sha256 so a changed edition fails. Do NOT hand-write recipe records and do NOT parse the whole book into structured recipes (that is the importer's journey, Launch's); the pin is the source text and the extract boundaries. State counts beside each pin: recipes extracted, ingredient lines, the two-stage case ids, the fraction and range counts.

Approved by Program (2026-10-11 pin list, four conditions): size to the CASE not to the book and state the count beside each pin; every id and hash is confirmed at pin time and the task stops on a mismatch (a pin is a fact, never a guess); only licences that fit (public domain, CC0, CC BY-SA 3.0 for Bangumi with summaries included and covers EXCLUDED); VNDB is not part of this task. The pin pipeline is `task fixtures:pull` and `tests/fixtures/fixtures.lock.json` (read `docs/` pins notes and the earlier pin tasks' commits `git log --oneline -5 -- tests/fixtures/sources/gutenberg.ts`: add a source entry, pull online once, commit the seeds and the lock, then `task fixtures:pull -- --offline` must pass). Proof is the unit test of the source file (extend `tests/qa/unit/fixture-sources.test.ts` and `tests/qa/unit/gutenberg-fixtures.test.ts` style).
