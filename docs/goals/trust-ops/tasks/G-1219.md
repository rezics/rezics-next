## Outcome

Media follows the same visibility and safety policy on every path. Three
inherited defects are to be closed.

1. **Private draft covers never become public.** A cover attached to a draft
   or private resource must not be readable to anyone outside the draft's
   audience on any path. The paths are the original, every rendition, the
   cache, the summary batch (`POST /v1/resources/showcase`, `summary*.ts`) and
   export. An earlier audit found draft covers reachable publicly; find the
   paths that still leak.
   - Fix the class in one place: one visibility check every media read goes
     through. Do not patch each route.
2. **A saved image's NSFW label can be corrected.** Today only a new upload
   carries the author's adult mark.
   - Add an authorized revision of the label on an existing image. Use the
     existing media command, with predecessor and receipt.
   - It needs the same authority as editing the image. Its effect on readers is
     immediate.
   - A stale predecessor or a denied principal fails.
   - Launch builds the editor UI (L3), so expose the operation and its contract
     only.
3. **The required safety matcher has an outage adapter.**
   `docs/operations/trust-and-safety.md` (around line 45) says required
   safety-matching outages follow their own admission policy, but no adapter
   exists; SAFETY04 covers only the NSFW classifier outage.
   - Add a required-matcher port with a local provider for development and
     tests.
   - Add the admission policy: while a required matcher is unavailable, new
     media stays private and pending. It is never published unchecked, and it
     never blocks an author's private use.
   - Add a test that drives a real outage of that provider, not the NSFW
     classifier.
   - The production provider is a deployment condition. Name its candidates
     within the zero-budget decision in the handoff, but do not integrate one.

## Do not build

- No second label authority.
- No new moderation queue.
- No per-route visibility checks.
- No paid matching service.
- No change to the NSFW classifier policy itself.

## Checks

- Unit tests of the changed modules; `task main:typecheck`.
- Integration tests through `task goal -- test <files>`:
  - a draft cover is denied on the original, a rendition, the summary batch and
    export for an outsider, and allowed for the author;
  - a label correction succeeds, then is retried with a stale predecessor, then
    attempted by a denied principal;
  - a required-matcher outage keeps a new upload private and pending, and
    recovery publishes it.
- Update `docs/operations/trust-and-safety.md` only where its statement
  changes.
