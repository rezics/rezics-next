## Outcome

Re-verify the safety drill's recovery gap: answers_step_id is globally UNIQUE,
so a cancelled or failed answer can leave its still-due step impossible to
answer again. Allow an authorized replacement after cancellation using the
current case/step locks and generation/CAS, preserving immutable decisions and
confirmed effects. Keep deadlines visible until an effective answer completes;
deny two live answers and stale/concurrent replacement. Review the automatic
counter-notice continuation's reuse of the cancelled decision key too.
Use a minimal owner constraint/index migration only if necessary.

No new decision engine, duplicate case/step journal, deletion of old decisions,
automatic lifting of restrictions or renewed statutory receipt deadlines.

## Checks

Focused real integration through task goal -- test: accepted/partial answer,
cancel, retry/replacement, concurrent responders, confirmed old effects and
completed-answer deadline retirement. Main typecheck; list broader affected
tests. Manager owns migration refresh through the normal heavy queue.
