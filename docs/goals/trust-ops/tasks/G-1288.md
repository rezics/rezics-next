## Outcome

Kernel is widening Content's target checks (`content-publication` draft,
publish, and exact-revision reads) from Work and Post to any admitted target
the server resolves. The first such target is a Zone page, for launch's L4: a
Zone without a Realm whose home page is a Content document.

Access must judge Content's existing draft and publish actions on a Zone page
target by the Zone's editor authority. Today Content baselines are
Work-oriented (`access/baseline.ts`, around line 80).

1. **When the server resolves a Content admission's target to a Zone page,**
   `baselineTargetAllowed` (or the admission path that calls it) requires the
   `zone.edit` authority on `zone:edit:<zone>`. That is the same decision
   `requireZoneEditor` (`routes/zones.ts:211`) and `changeZoneConfiguration`
   use:
   - baseline stewardship through `zoneSpaceCreatorAllowed`
     (`baseline.ts:170`);
   - administrators through `platformAdministratorTargetAllowed`, which
     checks the resource grant plus Zone or Space ownership.

   It is rechecked at claim, as every admission is. Keep Content's own action
   names; only the target's authority source changes.
2. **The Zone page is resolved by the server, never from a client field.**
   Kernel's Content change supplies the resolved target; ask the manager if the
   resolution hook you need is not there.
3. **Reads of drafts** use the same editor authority. Reads of the published
   bundle stay with the Zone's public-visibility rule (`readZonePublication`,
   `zone/publication.ts:23`) plus `discloseContent`. The bundle-membership and
   terminal-receipt checks are launch's; do not build them.

## Do not build

- No new grant kind.
- No per-page permission rows.
- No change to Work or Post authority.

## Checks

- Unit tests:
  - a Zone editor's draft save is admitted;
  - a non-editor is refused;
  - revoking the editor between register and claim refuses the claim;
  - a platform administrator with the resource grant is admitted;
  - Work targets are unchanged.
- `task main:typecheck`.
- The handoff names the exact function Content calls, for kernel.
