## Outcome

CLASS A, found by Kernel's worker on main (137c74707): the disclosure contract (G-1993, on main) has NO PRODUCTION ANCESTRY SOURCE: `grep -rn configureDisclosureAncestrySource services/main/src` returns only the definition (disclosure/read.ts:~476); every registration is in tests (tests/support/disclosure-ancestry.ts, whose header says 'Production sources must establish those facts in owner storage'). `resolveDisclosureSelections` throws `DisclosureUnavailable('Disclosure ancestry source is unavailable')` when no source is registered for the owner, so on the production composition every disclosure that needs an owner-established selection (search, typeahead, summary name/cover gates and the adapters) answers UNAVAILABLE for owners graph, content, media, review and discovery, and bare targets are refused. Main is not shippable for public reads until the SOURCE side exists.

Split (Kernel's proposal, accepted): KERNEL's task builds the graph and content sources (Work ownership, Work-in-Realm via placements, publication, Content revision/placement) and the shared composition function `configureProductionDisclosureAncestry(env, deps)` in the Main composition with the test that every owner in `governanceOwners` has a registered source on the real composeMain. THIS task builds the MEDIA, REVIEW and DISCOVERY sources:
- media: exact Use/attachment: the relationship basis of a media target (Asset+Use pair, owner Use/attachment, the Work or Realm it is attached to: read from the Media store's current-attachment lookup, which G-1981 made bounded; media/store.ts exact-Use read and the migration 2160 lookup), `resourceKind`, the parents tuple (Work and/or Realm per the contract, an explicit empty tuple for an independent publication), tokens for reread.
- review: the review owner's occurrence (review/reply evidence: the Work being reviewed/discussed and its Realm): read from the review/reply store's current rows.
- discovery: discovery/feed/notification source provenance ('discovery/feed/notifications carry current source provenance' in the contract header): the source occurrence receipt and the Work/Realm of the source.
Each source implements `DisclosureAncestrySource` (`read(targets)` and `reread(bases)` returning complete evidence in input order; `reread` returns the current evidence for the exact bases so a changed parent head is detected), bounded (one batched statement per source per submission of <= 64 targets, no per-target query), fail closed on missing rows (status unavailable/incomplete, never visible), tokens bind the evidence to the owner rows read.

EXPORT one registration function `registerMediaReviewAncestry(env, deps)` from `disclosure/ancestry-owners.ts` for Kernel's composition function to call (you do not edit the Main composition or any file another task holds: `goalctl owner <path>` first; if the composition file is free and Kernel's task has not landed, add NOTHING there: the call line is Kernel's).
