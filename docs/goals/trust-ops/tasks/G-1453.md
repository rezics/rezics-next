## Outcome

Security-relevant. Program's bisect (eee142f45): with colored output an ANSI code glued
to `FUSEKI_COMMAND_TOKEN` defeats the `\b` redaction pattern, so a printed token is NOT
removed (`tests/qa/unit/fixture-offline-command.test.ts`, case "a signaled command and a
printed token stay bounded"). Redaction must not depend on color: find the redaction
site(s) used for fixture offline commands (grep the pattern the test exercises) and make
them redact the token value itself regardless of surrounding ANSI escapes or other word
characters, for every place a command's output, log or error text can carry it (stdout,
stderr, thrown messages, persisted logs). Keep bounded-output behaviour unchanged.
Do not strip colors globally and do not weaken the test. Add cases: token directly after
an ANSI sequence, inside one, before one, split across two chunks (stream chunk boundary),
and a near-miss value that must not be mangled.
