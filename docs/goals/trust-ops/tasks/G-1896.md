## Outcome

Decision (trust-ops, 2026-10-11, reply to kernel's G-1873 finding): option A, SCOPED. Kernel's end-to-end proof for imported covers (branch goal/g-1873) passes every stage except the last: after a takedown, `GET /v1/media/representations/:representation/bytes` for a SECOND asset holding IDENTICAL bytes (the same file imported under another source record, for another Work or edition) still answers 200. Cause: `ownerModerationEffects.apply()` (services/main/src/modules/governance/effects.ts) runs the digest-wide `suppressIdenticalCopies()` only for NCII decisions; a COPYRIGHT restriction suppresses only the targeted asset (`MediaStore.changeState()` erases that asset's representations). My earlier scope answer ("the exact revision plus every Use of the SAME BYTES, not the whole Asset") requires the identical copies to come down.

Required change (small, inside the existing Media owner effect plan; no new fence scope, no new policy mechanism):
1. In the effect plan for a COPYRIGHT restriction (and its sibling interim/final forms the existing code treats alike) whose target is a COVER-ONLY imported asset (`media.asset.cover_only = true` with a `media.imported_cover_revision` row): also suppress every OTHER cover-only imported asset revision whose `original_digest` equals the target's, found through the existing index `imported_cover_original_digest_lookup` (bounded: a hard cap on identical copies per decision, e.g. 64, with a typed incomplete outcome beyond it, never silent truncation). Reuse the existing suppression primitive (the same one the NCII digest path uses, `suppressIdenticalCopies` or its per-asset building block), do not write a second one. Ordinary user-uploaded assets are NEVER swept by a copyright decision (different rights positions, licences, counter-notices): the sweep is limited to cover-only imported assets, where identical bytes mean the same rights-holder file.
2. Symmetric lift: restoration of that decision (counter-notice path, `restore`/reverse outcomes) lifts exactly the copies THIS decision suppressed, and nothing suppressed by another decision. Record which decision suppressed each copy in the existing effect/receipt custody (no new table unless the existing effect plan has nowhere to hold it; if it needs a column, say so and stop for manager review).
3. Idempotent and replay-safe like the existing effects (receipt-based, key replay, partial failure resumes through the owner's confirmation machinery).

Tests (new file `services/main/tests/imported-cover-identical-copies.test.ts` plus whatever harness the Media effect tests use; read services/main/tests/*media*moderation* and the NCII digest-suppression tests for the pattern): (a) takedown of cover asset A also suppresses cover asset B with identical bytes (representations erased, bytes route 404 for B too), an unrelated cover and an ORDINARY upload with the same bytes are untouched; (b) restoration lifts A and B, and a copy suppressed by a different decision stays suppressed; (c) over-cap => typed incomplete outcome and no partial silent sweep; (d) replay of the decision does not double-apply. Then run kernel's proof once if you can reach it: it lives on branch goal/g-1873 (worktree .temp/worktrees/g-1873), `tests/qa/integration/rights-public-restriction.test.ts` / the imported cover proof file named in that branch; report the result but do not edit it.
