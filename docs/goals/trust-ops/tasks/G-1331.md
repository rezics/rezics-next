definitionCreatorAllowed already uses the creator Agent's current controller,
while reference-disclosure definition candidates still require the creation
principal. Align those existing proofs without changing definition stewardship:
the immutable creator Agent stays the creator, its active controller can read/
manage after handover, and former/revoked controllers cannot. Preserve exact

fan-out. Do not widen unrelated semantic/public disclosure.
