## Outcome

Telemetry is already allowlisted: trace sanitization, metric and structured
log allowlists, and no HTTP body or header capture in `packages/observability`.
Some console paths bypass it.

1. **`services/main/src/modules/library/backfill.ts`** (around line 107) logs
   Agent, Work and timestamp rows. Replace that with a fixed structured event
   carrying counts and durations only, through `packages/observability` log.
2. **Find the worker console paths in Main and Account that serialize raw
   errors** (`console.error(error)` or similar, which can carry database
   values). Route them through one fixed event that records the error class
   and code, never the message or the row.
   - `library/backfill.ts` is in launch's area. This task changes it only if
     dispatched with `--allow-area` after launch agrees. For other files, run
     `task goal -- owner`.
   - Make the change in unclaimed files.
   - List claimed files in the handoff; do not edit them.
3. **A sentinel test** fails if a log line carries an email address, an IRI
   of a person or Agent, or a raw SQL value pattern.

## Do not build

- No logging framework change.
- No new telemetry.

## Checks

- Unit tests and the sentinel test.
- `task main:typecheck`; `task account:typecheck`.
