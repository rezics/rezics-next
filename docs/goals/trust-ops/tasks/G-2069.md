## Outcome

Readers see no structure (ingredients, scaling, steps) of imported recipes, e.g. Gutenberg "Puff Paste" signed out, because `verifyOriginalWorkStructureContribution` (work/structured-publication.ts) refuses any StructureRevision that carries `rv:importSource` / `rv:importSourceRevision` and so `publishWorkStructure` seals `rights-unavailable`. Program's ruling (class A, a rights rule; decision 55 "an import publishes what its source licenses"):

`verifyOriginalWorkStructureContribution` gains EXACTLY ONE further admitted basis, and nothing else changes:

- the structure revision was written by an IMPORT (it carries `rv:importSource` and `rv:importSourceRevision`), AND the contribution's OWN source evidence (the import's source record that `rv:importSource` names, at that `rv:importSourceRevision`) records a licence in the **publishable set** (public domain for Gutenberg), AND the import's source revision is the one the structure was built from. Find the existing publishable-licence representation (decision 55 in docs, the source intake `rightsEvidence` basis `license`/`exception`, the Gutenberg import's source record) and REUSE it; do not invent a second licence list. If none exists as data, define the publishable set as a small typed constant next to the verifier with the reason in a comment and tests, public domain only, and say so in the handoff.
- never for a member's own entry: a hand-pasted structure (no importSource) stays under the existing original-contribution rule (author-owned, single actor) exactly as today;
- never inferred from the Work or the Work's other sources: only from this contribution's own source evidence;
- a source whose licence is unknown, absent, not in the set, or whose evidence cannot be read: refuse (`rights-unavailable`), fail closed; a source record changed after the structure (different revision) refuses;
- the reader sees the source credit with the structure: check how the public read of a published structure surfaces credit (the Work's `rv:publicSource` / source credit) and add it only where the existing credit surface lacks the import's source (smallest change; say what it was).

Bounded work: the new check is a constant number of SPARQL statements (one ASK/SELECT on the source record), no per-placement scan; keep the existing contributor cap logic for the original path untouched.
