## Outcome

Make offline TDB2 compaction reviewable and recoverable: refuse a live owner,
require a clean stop and adequate disk headroom, report peak-space assumptions,
retain the old generation through a named recovery window and retire it only
through explicit operator action. Inspect Jena's actual compaction semantics
and the existing owner lock. Document the maintenance, verification, rollback
and retirement procedure concisely in recovery.md. Use the existing script
and fixture patterns; deliver deterministic offline refusal/recovery tests.

No second graph copy per revision, generic storage adapter, live 100k drill,
new runtime/tool or changes to kernel's command-module. Report the exact
timed populated-fixture drill still needed; manager owns heavy QA.
