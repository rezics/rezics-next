## Outcome

Canonical contract confirmed with kernel: new initial and ordinary Realm
policy revisions are the immutable publication receipt IRI. Initial creation
already uses it; ordinary publication still writes urn:rezics:realm-policy:UUID.
Unify new writes and Access permit/delivery consumers through the existing
receipt convention. Exact old pins and bytes remain readable/replayable until
explicit migration; do not derive a new token over old delivered rows silently.
Store the exact head/format only if necessary, with one minimal owner migration.
Kernel lends select-realm.ts; launch loan for space/policy.ts is pending before
dispatch. Keep native policy/selection authority, digest and epoch guards.

No new evaluator, policy resource, registry or meaning change; no broad consumer
rewrite. Any additional held owner file is a blocker to report, not to alter.
