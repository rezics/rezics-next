## Outcome

Same defect class as the landed token fix (`scripts/fixture/command-output.ts`, commit
4b4cb24e9, which redacts credential assignments regardless of surrounding ANSI codes and
chunk boundaries). `redactGovernanceOutput` in `scripts/ops/bootstrap/platform-grant.ts`
still uses `\b` before a Postgres URL and `Bearer`, and `\S+` for the value: a color
code glued to those strings can leave them in the thrown detail, and a following color
sequence can be consumed. Make it redact the secret value itself independent of color
and chunking (reuse the landed scanner if it fits; do not copy a second implementation),
keeping the surrounding ANSI and the bounded failure shape. Cases: URL and Bearer
directly after an ANSI code, inside a color span, before one, split across chunks, a
near-miss that must stay, and every call site that renders governance output.

## Checks

Show each new case fails with the fix removed (state the mutation). Run the touched
files with `task goal -- test`. Lint, AST, types. No `--heavy`.
