# Executable theme access operations

Use the elevated [theme capability](../contracts/custom-theme-execution.md) only
for an approved owner/host/artifact/capability revision and finite validity. Scope
eligibility management separately from resource editing, installation and approval.
Require current session assurance, expected revision and independent approval for
the elected sensitive actions. Operators cannot silently approve themselves.

Record grant/renew/revoke identity, expiry, exact review basis and private audit.
Notify the owning lifecycle through committed events; the effective deny/kill
fence precedes asynchronous cleanup. Re-evaluate changed dependencies and origin
requirements. Expired or missing review makes activation unavailable.

Qualify expiry/renew races, changed executable bytes, revoked manager authority,
stale caches and emergency shutdown before enabling external-live execution.
