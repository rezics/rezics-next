# Operation design

- [Deployment assessment](deployment.md): principal services concentrated on one host, API/unrelated workloads on the other.
- [Installation and upgrades](installation.md): release manifest, provisioning and activation.
- [Recovery](recovery.md): backups, cross-store reconciliation and failover.
- [Observability](observability.md): health, budgets, traces and incident diagnosis.
- [Security and erasure](security.md): credentials, disclosure and deletion frontiers.
- [Erasure procedure](erasure.md): storage-class inventory, immutable history, exact references and backups.
- [Executable theme access](custom-theme-external-live-access.md) and [incident response](custom-theme-review-and-incident-response.md).

These are required procedures and qualification criteria, not descriptions of an
existing deployment. Implementation supplies exact commands/configuration for the
elected engine builds without changing these contracts.
