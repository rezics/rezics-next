# Importer

The importer owns source dump ingestion, durable SQLite run and record state, and replayable requests for platform writes through the kernel API.

## Cost

These bounds follow `src/`, without measurements: R is stored records (including retained run history), B is binding/journal rows, M is one record/request/response's bytes, r is one page/batch's records, and k is rows changed; H is records already seen in a dump, C is a supplied chunk's bytes, S is supplied table/snapshot rows, D is disappearances, and q is commands for one record.
An indexed point operation examines at most one matching row plus O(log R) or O(log B) B-tree navigation; a keyset range examines its bounded results plus that navigation, without OFFSET, history enumeration, or COUNT scans.
Below, PK means the declared primary-key index, SELECT/INSERT/UPDATE/DELETE counts exclude connection-time schema/PRAGMA work, and each transaction adds BEGIN IMMEDIATE plus COMMIT (or ROLLBACK on failure); methods make zero kernel calls unless explicitly described.
Run/record pages cap r at 100, VNDB pages at 16, internal VNDB ranges at 32, and command/result batches at 100; accepted run projections/envelopes and binding snapshots cap M at 65,536 bytes (source-record projections add a small wrapper), while record metadata has fixed field byte limits of 64/512/256/64/128 for source/key/revision/digest/converter revision.
Growth checks below cite exact existing titles only for the exercised paths; entries marked “follow-up” name tests still needed, not passing evidence.

Dump duplicate detection retains all H native keys, exceeding bounded-neighbourhood memory even though payloads stream.
Dump and archive chunk retention has no producer chunk/backing-buffer cap, so a single chunk can retain the entire source independently of the record limit.
Run leases and atomic SQLite updates coordinate workers sharing the same database file and single writer; they do not establish a multi-machine shape or require a process-local lock.
Request attempts are bounded, but response bytes, valid advertised retry waits and caller-selected polling or fence loops lack a fixed service-wide bound on this base.
