# Native public-filter consumer

`createPublicFilterConsumerOperations` composes the injected Source and its binding with the existing
`createPublicFilterCustody` registry. It does not construct a Source or close supplied resources. Construction
is independent of native provider readiness. The public Source and binding factories are Semantic application
facades; normal process composition installs the native Semantic producer with Search planning/custody and Access
repair/authorization ports. An injected typed unavailable Source producer remains unavailable. Search retains its
generation-publication writer.

Capture admits the complete expanded shared grammar, rejects owner predicates and unexpanded saved references,
and compares optional compiled DSL before native I/O. Native resolution fixes the Source configuration, release,
read definition, physical UUID and original root. The Source bootstrap pre-arms the original cut; Search opens
its real PIT with that exact cut and Source adopts the committed observation. Bootstrap uncertainty recovers
that same identity; it never replaces the cut with current heads. Pending work stays in the existing registration
and transfers to the immutable observation. Source preparation may advance a bounded batch of individually receipted
Account homes; Search retains the original registration/bootstrap while it reports `preparing`, including when Access
contention leaves the cursor on the current home. Search supplies its current remaining input allowance after a
128-input reserve for capture handoff and persistence; Source admits up to 16 homes within that allowance and its
compiler-key estimate. It reads the retained cursor once before and once after the batch, while each home keeps its
own enrollment/adoption transaction and cursor CAS. Prepared materialization traverses that retained PIT in bounded steps
and commits its immutable native row set before adoption. Mixed prepared rows retain every raw engine candidate,
including duplicates and current-predicate rejects; serving revalidates native owners and may walk at most 600 of
those retained rows. No count or ordinary checkpoint certifies completeness.

Query acquires native custody, resolves the same root and records the execution's actual start and each raw
original/terminal own row. It retains every raw candidate and native key, including duplicates, rejects and
lookahead. Source join resolves the exact execution before the final all-home reduction observation; pending,
changed, incomplete routing, lost custody or changed incarnation prevents disclosure. Native completion and end
of engine input never replace final Source currentness. Missing Account-native binding remains unavailable.

Refill takes only an execution and consumed raw prefix, validates lineage, and derives its frontier from retained
raw keys. Each derived execution preserves the root definition and original observation. Revalidation and replay
consume the same root allowance over three rounds and `min(600,6s+3)` raw candidates. Required windows align public
hits with raw ordinals; EOF requires both complete native exhaustion and consumption of the full window.

Repair uses Source-owned bootstrap/execution/frontier locators, including local and foreign own-home advancement.
Search persists uncertain native dispatch before writing, uses the Source's exact bigint position at the existing
safe external-version boundary, rejects version conflicts, and verifies searchable current-winner body/version.
Search fixes each Source page request at `inputLimit: 64` so the retained receipt has the same size after an
uncertain delivery; the existing meter reserves capacity for the producer and independent Source-step replay.
Each bounded Source repair page retains its members and next ordinal before dispatch. Item completion and
ordinal advancement commit together; uncertain retries reuse the original version and document. Visibility
records remain in native execution custody. Only Source settle can certify its owner receipts plus
actual Search custody for the old cut/execution; a refresh, callback or successful write cannot publish an ACK.
Settled repair is a maintenance diagnostic; changed-since-start continues to block disclosure of the old
execution through query/status. Unresolved projection/owner work stays unavailable. Partial builds cannot authorize a replacement.

Lifecycle close barriers and native leases belong to custody. Factory close drains admitted work and closes
only PITs it owns, leaving supplied pools, engine and Source open. Closed or uncertain observations do not
become synthetic success. All returned native work costs include failed/replayed metadata, SQL, engine,
projection and visibility operations under the existing ceilings.
