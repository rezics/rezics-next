# Character and person search

The installed universal Search grammar accepts released relation qualifiers on the existing
`statement` leaf. Relation metadata does not itself admit a qualifier: the active filter release
must declare the property as a facet of the selected type and declare every requested qualifier
and its datatype. Item operands are native concept or subject UUIDs. A catalogue Person remains
distinct from an Account.

For example, a work's `wdt:P725` value selects the credited person; `wdt:P453` and `wdt:P3831`
qualifiers constrain the portrayed character and role on that same statement. Repeated voice
credits do not pool qualifiers across slots. The existing current statement matcher remains
the single interpretation of qualified evidence. No new vocabulary is written by Search.

Decision: qualified probes sharing a subject/property/value reuse one native seek and progress
cursor, while retaining independent same-statement truth results for each qualifier conjunction.

## Current evidence

Candidate index facts are hints. Current checks forward the complete qualifier conjunction to
the Semantic relation source, including when the selected relation sample overflows. Qualified
relation leaves under NOT also require current native evidence; absence from a sample cannot
manufacture a negative. Source uncertainty remains `not_proven` through the Boolean interpreter.

The producer validates qualifier structure against the shared grammar before I/O and admission
against each source subject's current release. It proves true only from one selected native
statement after existing original/terminal target, source-fence and moderation checks. Unsupported
qualifiers, withheld inputs and a bounded sweep without a witness remain unknown. Distinct
qualifying native statements may establish the same result identity, without combining their
qualifiers. These checks do not supply an inverse relation or a context preview.

## Native probe step bound

The ordinary qualifier equality grammar also admits canonical `"0"`, `"1"` and `"2"`
operands for `rezics:spoilerLevel`, only when the parent property declares that qualifier
and its released datatype is a dimensionless quantity. Native exact quantities are
normalized to those operands on the same selected statement. Unknown, malformed or
uncertain quantities cannot provide a witness. Source release changes during foreign
disclosure also invalidate the witness.

Decision: spoiler equality uses canonical decimal string operands in the existing qualifier
grammar; absence does not invent a level. Journey-wide threshold policy remains separate.

Decision: universal subjects:search carries optional spoilerThreshold 0/1/2; only exact released levels at or below it admit trait, gender and appearance evidence, while absent or uncertain levels remain unknown, including under NOT.

Released classification facets, including `schema:keywords` and `schema:gender`, use the
same bounded selected-value source and current target checks as other relation groups.
They retain exact concept UUID operands, with no concept seeding or alias inference.

Let P be the number of distinct requested subject/property/value keys (P <= 256), and A the
number with available current source/release admission. Qualifier variants do not increase P.
The existing selected-value index seeks at most A cursor positions and returns at most
min(1000, A * min(128, max(1, floor(1000/A)))) raw selected rows. Each conjunction has at most
four qualifier clauses, each with at most 64 alternatives. Matching runs per disclosed row and
per admitted variant; retained raw rows remain at most 1000. Existing source, target and tuple
disclosure work is unchanged. Progress writes at most A cursor rows using the existing lifecycle.

This is one bounded native evidence step, not an absence certificate, a whole-page bound or a
measurement of total preparation. Inverse appearances, spoiler thresholds, current release
replacement, finite complete preparation, matching context previews and the installed character/
person Web journey still require the continuation contract. A complete whole-page K must be
derived before dispatch for that integrated plan; a raw native LIMIT cannot certify it.
