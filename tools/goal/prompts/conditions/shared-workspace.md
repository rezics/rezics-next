Peers edit this tree at the same time. Commit your own work often with git add <your paths> (never -A or .). Use path-limited commits (git commit --only -- <your paths>) so a peer's staged files stay theirs. Every commit must have the subject '{{task.workspaceTaskName}}: <message>' and a 'Goal-Task: {{task.id}}' trailer. Never reset, checkout, stash, clean or rebase. A failure in files you did not touch is a peer's work in progress: rerun later or check only your own tests.
