# List presentation

List rows and cards keep each member's real Type. A released `listPresentation` may choose its image aspect and up to
four ordered fact properties for that Type. The nearest annotation replaces the whole inherited value. Without an
annotation, known current Types use explicit defaults: books portrait, film and series landscape, music square, and
recipes landscape. Unknown Types use the list's composition ratio or the existing `Cover` fallback.

The aspect values map to 3:4, 16:9 and 1:1. A card's actual Type chooses its own image frame, even when its grid has a
shared composition ratio. Suitability withholding, placeholders, crop fitting, focal points, alt text, attribution and
language remain part of the shared `Cover` renderer. Only facts already supplied with the bounded member data appear.

## Review globals

Review these same ten story IDs at phone 390 and desktop 1280, with `en` and `zh-Hans`, light and dark toolbar
globals. Width, locale and theme do not create separate stories. Book exercises keyboard focus, Mixed opens and
closes the actual responsive menu, and Withheld reveals the actual image. Key Facts uses an explicitly supplied
fixture value; the web Type Presentation pattern exercises selection through the real Search and card callers.
Screenshots still require maintainer visual review; component typing does not provide that approval.
