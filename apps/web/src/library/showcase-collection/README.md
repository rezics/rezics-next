# Collection presentation

Discovery consumes Search's admitted public Collection card and opaque continuation; Subject summaries remain a compatibility read. It never fills missing previews with catalogue or private inventory reads.

Presentation kind is an exact native Type or mixed when unset; ordered rows and grid are reversible view choices, and rows show native occurrence order without fabricated absolute ranks because the native read supplies no absolute rank across disclosure, filters or continuation pages.

Each member keeps its own Type geometry, facts, occurrence ID and original Subject association. Ordinary member links reuse the existing comparison return protocol. Dynamic Collections keep the shared property-filter episode and owner rule host. Review derives from the existing command plan; native action advice and acknowledgement remain authoritative.
