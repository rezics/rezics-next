# Copy inventory windows

Decision: Keep admitted cursor history in the mounted routed CopiesCurrent visit; carry at most eight opaque predecessors, the current coordinate and one staged destination across a deliberate cursor move, and admit the destination only after its exact successful native read.

The visit retains cursor coordinates only. It does not retain Copy rows, labels, credentials, editor state, comparison selection, command keys or deletion receipts. Direct cursor entry has no inferred predecessor. Changing the subject, filters or locale, replacing the reader or leaving the route retires the path. A new runtime cannot restore it.

Previous rereads the exact admitted predecessor. First omits the cursor and keeps the current subject and filters. More stages only the native next cursor and drops the former forward branch. Failed movement keeps its exact target available for a deliberate Retry and does not consume accepted predecessors. Retry refetches that staged address; Previous, First and More stay unavailable until the destination is admitted. A cursorless refresh rereads the current address. Preparing, failed, forbidden, unavailable and cached former results do not admit a staged destination. A native invalid-cursor restart admits the actual cursorless page as a fresh root while preserving the requested cursor for address recovery.

Each deliberate movement performs one existing credential-prepared native list read of at most 100 rows, including kind and status predicates. Declared native filterOptions become the inventory controls; malformed options grant no capability. The native reader may make its existing single cursorless recovery read when the cursor is invalid. There is no refill, count read, prefetch or page-chain replay. Unsupported kind or status filters remain unavailable without widening to an unfiltered read.

Conflict adoption keeps the incoming native Copy as inventory readback and the clean editor baseline. Local changes,
including clears, merge only into the unsaved draft; untouched fields take the incoming values. The draft remains
dirty until it matches that baseline or a save succeeds. Save uses the incoming revision, and inventory changes to
those edits only after authoritative native readback.

Conflict inspection preserves a native closed outcome without offering adoption. Point presentation carries the
owner's separate media and packaging condition observations and current editing advice; malformed native advice
remains unavailable, without deriving historical meaning from today's choices.
