# Copy inventory windows

Decision: Keep admitted cursor history in the mounted routed CopiesCurrent visit; carry at most eight opaque predecessors, the current coordinate and one staged destination across a deliberate cursor move, and admit the destination only after its exact successful native read.

The visit retains cursor coordinates only. It does not retain Copy rows, labels, credentials, editor state, comparison selection, command keys or deletion receipts. Direct cursor entry has no inferred predecessor. Changing the subject, filters or locale, replacing the reader or leaving the route retires the path. A new runtime cannot restore it.

Previous rereads the exact admitted predecessor. First omits the cursor and keeps the current subject and filters. More stages only the native next cursor and drops the former forward branch. Failed movement keeps its exact target available for a deliberate Retry and does not consume accepted predecessors. A cursorless refresh rereads the current address. Preparing, failed, forbidden, unavailable and cached former results do not admit a staged destination. A native invalid-cursor restart admits the actual cursorless page as a fresh root while preserving the requested cursor for address recovery.

Each deliberate movement performs one existing credential-prepared native list read of at most 100 rows. The native reader may make its existing single cursorless recovery read when the cursor is invalid. There is no refill, count read, prefetch or page-chain replay. Unsupported kind or status filters remain unavailable without widening to an unfiltered read.
