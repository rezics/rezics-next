# Progress history windows

Decision: deliberate same-session Changes and Completed units navigation uses the existing mounted private detail
reader and independent coordinate-only paths. The route loader prepares fresh visits; it does not duplicate cursor
movement reads. History navigation preserves the existing private Progress Work return intent and the single
editor/publication Stay/Leave decision. A history read never resolves an uncertain command.

Each section retains eight admitted predecessors, its current opaque cursor and one staged target. Cursors retain
the native 4096-character boundary. Previous rereads the exact admitted predecessor; First omits only that section's
cursor; More uses only its native next and drops any forward branch. Empty successes commit, including terminal
pages with backward controls. Failed reads keep the exact target for deliberate Retry without changing accepted
coordinates. Current refresh uses actual admitted cursors. A producer-stale cursor adds its existing cursorless
retry and restarts only that section, with a localized recovery notice. Direct later-cursor visits invent no Previous.

Only deliberate eligible cursor movements carry paths. Viewer, credentials/CSRF observation, exposure/admission,
locale, session or unrelated route replacement (including equal replacement and A/B/A) retires them. Full departure
unmounts the visit. Display-only rerenders preserve it. Coordinates live in the mounted component in the existing
Router/QueryClient; no old DTO, arrays, snapshot, command, credentials or browser persistence are retained there.
Keyboard movement may focus its admitted heading once; independent focus, cancellation or replacement cancels it.

After ordinary preparation, one detail read composes four native requests: one session, one at-most-100-row changes
page, one at-most-100-row completed-units page and one at-most-100-row published-log page. Labels arrive embedded
in these native responses. One existing `nameSubjectTypes` batch names the session Subject, optional version Subject
and the log page Subjects (at most 102 inputs, with type descriptor deduplication/cache owned by that reader).
A stale changes/units cursor adds exactly its existing one cursorless native page
retry; both stale sections add two. Each section replaces its one page; nothing prefetches, refills, scans totals,
requests per row or reads automatically. Log pagination and its existing stale-cursor retry remain separate and
preserve its exact address.

Historical facts preserve raw text, unknown measures, native ordering and duplicate unit occurrences. Disclosure
identity is scoped to native page replacement. These pages imply neither totals nor terminal state nor canonical
episode identities. The canonical episode checklist, scalar/independent-measure command authority, native
authorization and private no-store remain with their existing owners.
