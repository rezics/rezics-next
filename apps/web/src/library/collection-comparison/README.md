# Collection comparison

The native FULL member response supplies the finite facts. The actual member Type's released list presentation
selects their order; the existing shared formatter preserves recorded date precision, quantities and codes.
A single page-level release observation supplies property labels and presentation. An unavailable release keeps
ordinary member browsing available, without granting any authority or reading reference targets individually.
Property labels describe ordinary facts; they never turn an item into a qualified creator role or a work into a release.

Decision: comparison references use the existing localized Subject `via` return convention. Their Collection return
retains its admitted opaque cursor, supported filters, layout and exact supplied curated occurrence, plus one local
`returnTo` normalized by the existing Library directory admission. That intent can address only the same locale's
`/library/collections` page with its bounded cursor and `rows` or `previews` layout; invalid values resolve to that
directory. Nested redirects and arbitrary query text are not carried. Projections without occurrence IDs return to
their bounded filtered page. The filtered native projection supplies subjects and facts but no curated occurrence ID
or note; no index or subject ID is promoted to an occurrence ID. If filtered occurrence return is required, the
producer must supply the actual occurrence ID and note in that projection; the reader already accepts these fields
on curated member rows.

Admitted empty facts, absent observations and unavailable definitions have distinct presentation. A label without
a supplied destination remains text. A concealed target is never reconstructed from its label. The installed fact
union has no disclosure reason for omitted facts, so omission is not relabelled as confirmed withholding.
Reader reference links are separate from subject links and personal controls. Editors show the same comparison
labels without a departure link that could bypass the existing draft guard. No selection, draft or private action
is serialized in the return address. Return focus is restricted to the currently loaded occurrence; cursor recovery
never scans other pages or substitutes the same subject at a different occurrence.
Decision: each comparison departure or fragment navigation admits one return; native page, reader or address
replacement retires it, and moving focus elsewhere consumes it even if focus later returns to the document body.

Decision: compact-reading Web fixtures derive `currentHref` from `collectionPageAddress` for the active cursor,
filters and canonical layout, then retain a valid same-locale Collection-directory return. Occurrence and projection
references assert the `collectionMemberReturnAddress` owner preserves its normalized destination. Header acceptance
checks linked curator identity separately from the readable member count and native update time.
