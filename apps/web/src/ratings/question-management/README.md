This follows [Web](../../../../../docs/goals/web.md), the current [types](types.ts), [page](page.tsx),
[address](address.ts) and [named route](../../routes/realms/$id_.questions.tsx).
Decision: creation acknowledgements compare scale operands by value; JSON property order cannot turn the committed original definition into an uncertain command. A different scale remains uncertain and cannot select a new question.

The existing management reader and commands own admission, immutable definitions, caption compare-and-set,
lifecycle and authorization. This consumer only navigates their current native windows.

Decision: the management read calls the installed Realm management callable through the bounded client, and page and selection types derive from that installed response. Its closed management and caption-history schemas stay a named Kernel seam in [native](native.ts) until the official client publishes their runtime exports.

Decision: Previous uses admitted predecessors only; First deliberately reads the null cursor. Each independent
stream commits its staged target only after exact admitted success. Retry reads that same failed target. A direct
visit has no invented predecessor. A successful return truncates the abandoned branch; First clears it.

The named route retains one eligible visit in its existing QueryClient, surviving ordinary cursor and keyed page
remounts and Router Back/Forward. Its existing navigation observer distinguishes these movements from replacement
of an equal source. Realm, selected question, caller/credentials, locale or source retirement discards both coordinate
paths, including A–B–A replacement. Selection keeps the route's existing reset and fresh inspection semantics:
directory cursors bind the exact selected question. Caption coordinates belong to that question and original visit.
Inactive loader metadata is not cached, so an old loader source cannot be replayed before a fresh preparation.
No previous page bodies are cached. Returning always uses the existing readers, including caption readmission.

Each stream retains at most eight predecessor cursors, current and one staged target. At the admitted 4096 JavaScript
code-unit cursor bound this is at most 40,960 code units per stream, 81,920 total (163,840 UTF-16 bytes excluding
object overhead). Path work is O(8), independent of native population size. Presentation holds only the current
20-question directory and 20-caption window, plus the existing exact selected inspection. There is no prefetch,
refill, point-read enrichment, additional observer, browser storage or page archive.

Directory movement uses the existing Router departure blocker. Caption movement requests the same OwnVotesDeparture
decision locally; Stay changes neither coordinates, drafts nor selection. Leave is applied only after the original
authority is still current. Pending/uncertain commands remain locked with their original sender and operands.
Keyboard movement can focus only its region heading, and only while its original focus epoch remains eligible.
Forced retirement continues to remove private presentation synchronously through the existing page lease.

Empty first, sparse continuing and empty terminal windows have separate copy in every launch locale. Illustrative
stories and focused consumer tests do not establish installed native or signed-in browser acceptance; the original
controller retains native, command acknowledgement/current-reader/focus, classification and browser checks.
