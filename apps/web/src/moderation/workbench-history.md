# Board decision history

The workbench history visit reads one native Board history page and at most one selected exact decision, without
report, appeal or pending-queue scans. The mounted producer is `GET /v1/boards/{id}/moderation-history`;
`GET /v1/moderation-decisions/{id}` remains the selected receipt authority. The server binds both calls to its single
prepared session and carries private/no-store and the original abort signal on each read. Both operations use the
installed KernelClient declarations directly; the list projection derives its public fields from that response.
No reflective mounted-client cast or private producer import remains. Missing source tokens or native viewer/action
projection produce unavailable, not empty. Abort retires late page and exact results before receipt dispatch or final
publication. Directory coverage and horizon remain owned by the independent directory observation.

Decision: Board history uses independent `historyTargetKind` and `historyDecision` operands, renders a moderator-only
receipt, and keeps target advice unavailable until the exact reader supplies current context.

The queue filter, order and opaque cursor remain the return snapshot; `historyCursor` and `historyTargetKind` never
replace them. Selecting or closing an exact receipt preserves the history cursor. Changing the history target kind
or explicitly restarting clears only history continuation and selection. Returning clears the history visit and
restores focus to the same queue control through the existing guarded private-reader lifetime. The URL contains
only references and opaque cursors, never reasons or actor labels.

Rows follow the native order and decision time. Retained empty reasons and retired statements have separate
presentation. Native decider presentation is withheld or retired; no account lookup rehydrates it. Only explicit
native receipt advice creates an inspect control. The selected renderer keeps the original decision target ID and
shows only exact-reader current target navigation. It never offers an affected-author appeal form, appellant or
deadline. Current unavailable/concealed context does not replace an already admitted receipt's retained reason.
Older decisions without original command receipts have unavailable receipt advice.

Raw empty-with-next pages offer continuation without refill. Stale cursors offer explicit restart. Dependency
retry repeats the same search operands. The receiver retains one list page and one exact receipt, and the existing
workbench owner clears both on session, account, navigation, source or parent replacement. A failed selected read
cannot substitute a different target from a newer summary. Unknown browser admission withholds private results.

### Cost: history receiver

- Touches: one session preparation, one mounted native page GET and optionally one exact GET for the selected
  permitted row. The producer owns all authorization and disclosure; client fields grant nothing.
- Bound: one page of at most 20 rows and one exact receipt; no target body, reporter evidence or account name
  enrichment. One SHA-256 source fingerprint retains no session token. Source-native work remains additive to the
  producer's Content Cost declaration. Navigation replaces rather than appends pages.
- Growth check: receiver tests pin actual transport operands, independent cursors, sparse pages, same-input retry,
  missing advice/source and exact-identity replacement. Native independent population/physical growth and rendered
  browser acceptance remain receiving checks; fixed output size alone establishes no native physical bound.

Decision: reuse the queue coordinate engine for an independent Board history path in the same Router/QueryClient
visit and private-reader lifetime; commit movement only on admitted native history-page readiness, independently
of the selected receipt. First drops only history continuation and selection. A failed First retains the accepted
path until its deliberate retry succeeds. The queue-return owner still sequences beginHistory and current-page
return admission. No additional session observer or reader host is installed.

The path retains at most eight admitted predecessor opaque cursors, current, and one staged movement; it retains
no rows or receipts. Direct later-cursor entry invents no predecessors. Previous rereads its admitted address;
Next uses native continuation and truncates forward coordinates. Refresh and receipt Open/Close replace the
current page. Empty pages replace their own rows and retain backward controls, including empty-with-next.
Failed movement repeats its exact URL on Retry without consuming predecessors; stale cursors require explicit
Restart. Board, history target kind, locale or reader admission replacement and departure retire the path.
Keyboard movement focuses the admitted history heading once if eligible. Receipt Close instead restores its
current exact row, or the heading if the row is absent. Current queue admission owns return focus. Each deliberate
movement still costs one native 20-row page read and at most one permitted selected exact read; there is no replay,
prefetch, refill, persistence or receipt cache. Native continuations exceeding the 4096-character address boundary
are unavailable rather than becoming a different browser address.

The connected history stories use the installed page and exact operations with illustrative transport fixtures,
including retained/retired reasons, sparse pages, receipt selection and captured queue return. They are not native API
recordings or execution evidence. Focused regressions pin no-store, the shared prepared authorization and abort signal,
late page/exact retirement and the independent history path through the installed client. Native, browser, growth and
promoted acceptance remain separate from the supported wrapped Web workspace typecheck.
