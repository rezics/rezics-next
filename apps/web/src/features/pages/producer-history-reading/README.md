# Producer history recovery

One admitted native slice owns its row occurrences and correction entry. Every deliberate read withdraws that slice before requesting a replacement; sequence ownership rejects equal-page and A/B/A late results. Unavailable retries keep the exact failed stream, cursor and session. Restart asks for the first native page without the old session. Nothing scans or refills an old page.

Decision: any deliberate replacement retires the open correction through the existing current-reading host; the editor stays mounted privately until dismissed, and its possibly uncertain command is never replayed or transferred to fresh read admission.

Recovery and the generic producer origin remain visible without old relation facts. A retired correction cannot restore its former slice, even if a later read has equal labels or identifiers. The reader offers fresh admission and requires a new deliberate correction selection. Private navigation descriptors remain in this mount only.
