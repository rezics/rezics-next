# Literary work reader

The ordinary `schema:Book` Subject remains the identity for a literary work. Its multilingual labels, aliases,
descriptions, admitted contributors and work facts stay on the current composed Subject read. The existing
composition renders the bounded editions list; `bf:Instance` destinations open in a new tab, and each edition's
publication facts remain on that exact edition page. Parts and personal copies keep their current owners.

The reader adds no query, hydration, definition, adapter or write. It uses the current Overview context to link to
the existing Editions and Details views. Missing edition facts remain on the generic exact Subject facts path, and
the existing Literary profile action remains the correction path. Authority, locale, Context, identity or page
source replacement retires the reader panel until a new composed Subject source arrives.

## Cost

- **Overview:** zero reads beyond the Subject page's existing composition plan. The existing `SubjectList` admits
  one bounded current links page; the reader does not hydrate each edition. Its label window renders at most 32
  titles, 48 aliases and 16 descriptions from that admitted Subject response.
- **Navigation:** the existing editions view retains its own finite page and opaque continuation. Opening one exact
  edition is a deliberate navigation to that edition's current Subject page; no target is prefetched.
- **State:** one observation tuple identifies the current page source, work, locale, Context and session authority.
  It retains no statement history, target cache or pagination window.
