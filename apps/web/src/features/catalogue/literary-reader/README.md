# Literary grain reader

The ordinary page mounts released Book, BookSeries and bf:Instance identities and their actual released descendants.
It consumes the existing Subject, disclosed related summaries, current native descriptor and directed relation
windows. A member remains its supplied Type and statement; no count, title or numbering string creates volumes,
editions, integer positions or progress. The owning contract is [Subject pages](../../../../../docs/subject-pages.md#read-a-literary-work).

The native descriptor's existing literary admission supplies Type ancestry, property labels and direction results.
An unavailable or unsupported descriptor remains explicit. Canonical work mapping is a current native assertion,
never a guessed lookup. Missing mapping differs from withholding and currentness failure. Public facts and shared
value/source rendering are independent of correction admission.

## Cost

There are zero additional native calls, target hydrations or network decodes. `profileRelationWindows` carries the
actual planned row limit; the adapter selects at most one member and one edition window and discards previous rows
on replacement. Native page-node continuation and opaque cursors replace pages. It retains no history, full-series
index or speculative pages. The Subject, descriptor, current directed windows and source references are shared with
the ordinary page. `literaryCompositionCost` records supplied UTF-8 window bytes and retained projection bytes;
its request and decoded-byte values are incremental adapter costs. The existing page producer exports no whole-page
response byte limit, so fixture byte measurements are not represented as a native bound or executed SQL evidence.

One browser observation and a weak source-incarnation set retire old public results on source, release, reader,
credential, Context, locale or focus-window replacement, including A-to-B-to-A. Destinations open separately with a
validated native return address. The address carries the exact Context, current view/node/cursor and selected row
focus. Previous retains up to eight accepted addresses and reloads each through the current page reader; only address
metadata survives. If the selected row is gone on return, the reader explains currentness and leaves Restart and
available continuation links in place. Read retirement never changes private draft or uncertain-command ownership.

Each Previous, Next or target return performs one current Subject-page read through its existing route. The reader
retains no prior authorized payload. Address length is capped at 32,768 characters; oversized history evicts the
oldest address, and each retained entry contains only a view, node, optional opaque cursor of at most 8,192 characters
and optional focus key. At most eight entries survive. Two relation windows are selected; each keeps its native row
limit, source order, summaries and exact qualifiers/references. The existing 65,536-byte composition bound covers
their supplied labels, statements and source parts. The reader adds no document read or per-row target hydration.
