# Story arc reader

The ordinary Subject overview offers this public reader for `wd:Q2620972` and for works whose current
composition discloses `rezics:storyArc` slots. It complements the existing narrative Summary and Details;
those components retain document language, partial precision, source association and spoiler controls.
The [Subject owner](../../../../../../docs/subject-pages.md#read-a-story-arc) owns composition;
[native relations](../../../../../../services/kernel/src/semantic/README.md#relations) own stream meaning,
ordered slots, qualifiers, disclosure, freshness and opaque continuation.

The current immutable Release admits each direction separately. Work → arc memberships, arc ← work memberships,
other directed containment and narrative sequence stay distinct streams. Native order is retained verbatim;
positions, first/last parts and sources stay with the exact holder and statement. No date/title chronology,
transitive membership, recursive graph expansion, replacement writer or character hydration is introduced.

An arc's disclosed inverse member-work row can open one bounded `schema:character` forward window on that work,
filtered by this arc only when released `wdt:P518` filtering is admitted. Unqualified appearances never substitute
for that window. Missing configuration offers an explicit unsupported state and the existing Details path.
Empty, withheld and unavailable readings remain distinct. A failed continuation retains the previous window
and retries the same address; concealment or invalidity removes it. A missing page never establishes an arc's end.
A repeated cursor, duplicate assertion or mismatched holder/statement/target/filter makes the window unavailable.
Rows without native assertions disclose no context because their spoiler qualification cannot be evaluated.

The entire assertion, title, navigation, qualifiers and sources stay behind its spoiler gate. Every successful
window replacement resets reveal consent. The narrative Summary remains the existing composition component.
All windows and controls retire on viewer/session/exposure, subject, Context, Realm, locale, settings, source
observation, Query provider or lifetime replacement; late responses cannot restore them.

Decision: public destinations open in a new tab, retaining the originating work or arc's exact mounted window;
keyboard return restores its still-meaningful link or the reader heading. Only one member appearance window is
open at a time, and its Back action restores the member control. Existing correction/classification owners retain
all edits, ballot state, unknown-command and review recovery. Current Character destinations retain their owners.

## Cost

Each deliberate first/next/retry/restart/stream read costs one exact Subject read, the existing active-definition
and immutable Release pair, and at most one relations/links page. Opening a member's appearances repeats this plan
for that exact work and arc filter. There are no per-row reads, target hydration, polling, prefetch, writes or
session/exposure reads. At most one request per window is pending. One outer and one optional member window are
retained, each with at most 20 rows, 128 KiB per native row and a 2,686,976-byte page cap; Subject input is capped
at 4 MiB. Definitions retain the existing 4 MiB/1,024-Type/4,096-property limits and at most 64 streams. Cursors
retain at most 4,096 UTF-16 units. Old windows replace rather than accumulate. Admission temporarily serializes
input; normalized JS objects and transport overhead add to these serialized bounds. Projection and rendering
are O(admitted bytes + rows), independent of total arc size.

Authored stories exercise the disclosed journey, unsupported definitions and unavailable continuation. They are
source examples, not native publication or rendered passes. Focused tests use generated native client seams and
mounted keyboard/spoiler/retirement journeys. Wrapping shell components, theme tokens, 44px controls and all eight
existing locales support phone390/desktop1280. Native/browser acceptance remains deferred to integration.
