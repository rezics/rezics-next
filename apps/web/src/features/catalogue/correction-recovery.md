# Manga correction recovery

A successful current release can withdraw a correction property while its private holder remains mounted.
Render that holder separately as a private statement snapshot, retaining its original identity and complete value,
qualifiers and references. Current public fields must still derive exclusively from current admission.

Decision: any withdrawn unsent holder blocks the whole new batch until captured, cancellable discard or readmission;
sealed commands retain only the existing exact native replay, including an honest refusal under current admission.
Valid sibling edits and inclusion choices survive reconciliation. Confirmed outcomes remain confirmed; sealed or
possibly applied commands cannot be discarded. A new reading retires pending callbacks without dropping holders.

The shared `ExcludedFact` and captured-instance discard controls own private inspection and removal. The Manga
correction workspace owns admission and the batch guard; existing reading and departure boundaries retain custody.

Single-statement explicit reload retires public source and definition controls immediately; an unsent draft remains
inspectable as a private statement snapshot until a fresh read matches its original subject, type, source and property
and the current release readmits that property. Authored values survive readmission unchanged.
