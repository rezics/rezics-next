# Manga part reader

The ordinary Subject remains the identity for each Manga series, volume and disclosed part. The reader presents only
current composition rows whose relation definitions admit membership or edition meaning. It preserves the native
statement association, direction, source order, disclosed labels and qualifiers. Partial dates stay with the generic
Subject facts and heading because relation summaries do not supply them. Each link uses the exact target Subject ID.
Missing specialized chapter configuration stays unsupported while generic facts and relations remain available.

The existing `pages:read` composition supplies the Subject and bounded relation rows. The reader adds no part lookup,
definition fetch, progress overlay, write or private session read. `WORK_PARTS_PAGE_CAP` bounds rows at twenty. The
current return address carries the locale, selected Realm, view, node and opaque cursor; no previous windows or
whole-work membership set are retained. A source, release, locale, context, viewer, selected view or page-window
replacement retires the captured visit and offers an explicit current-page recovery link.

## Cost

- **Touches:** one bounded ordinary Subject composition per selected window, using already supplied definitions and native relation summaries. Preparing the domain projection adds no per-part network reads, public-to-private overlay or history enumeration. A deliberate next window performs one existing page-bound request; exact-part navigation starts that destination's existing reader, not a prefetch of all parts.
- **Bound:** reuse `WORK_PARTS_PAGE_CAP=20` and current composition/cursor byte caps. The model retains only the admitted current subject, bounded rows/qualifiers, one continuation and return address, with work O(current page fields + rows + admitted bytes). Do not retain old windows, whole-work membership sets or all release history in a new cache.
- **Growth check:** use the actual projection/loader at a fixed 20-row window while independently varying unrelated parts, selected-subject relation history and 1/10/100 sequential windows/retirements. Count dispatched composition/native calls, materialized/retained bytes and active controllers for populated, empty, sparse, withheld, unavailable and same-cursor retry. Assert fixed page-bounded work, no point-read fanout and no old retained windows. Existing native relation physical-plan acceptance stays Semantic-owned.

## Inspect one native occurrence

Web owns the selected Manga occurrence, its existing part/holder correction visit and deliberate return. Literary
stream discovery, franchise grouping and outer Connections returns keep their existing owners. The selected row is
identified by native node, direction, property, original holder, assertion ID and target. Repeated targets and
separate composition nodes remain separate choices. Selection retains one locator, never a copy of the evidence
or a previous page. A replaced read collapses inspection and permanently retires the preceding callbacks, including
equal successful replacement, account/credential, reader, release, Subject, Context, Realm, locale, address and A/B/A
changes. The two ordinary Subject composition query options disable structural sharing so an equal successful
response still establishes a new source incarnation. Browser pagehide also retires it; BFCache cannot revive the old reading.

The inspector renders only the supplied native assertion using the ordinary value surface. Qualifiers retain native
order. Each native reference remains a separate group, including empty groups; no references means none were disclosed
by this reading. Technical association details show the original holder, node, assertion, release and revision. An
inverse row belongs to its supplied `subject`, while a forward row belongs to the current composition's Subject.
Neither a target's general facts nor public counts can replace membership evidence. Missing assertions keep inspection
and correction unavailable. Malformed or over-bound assertions make that window unavailable rather than trimming its
evidence. Spoiler admission applies before projecting either the summary or the complete selected assertion.

Decision: the public return fragment carries one six-field occurrence locator; holder correction opens the existing
relation editor with that locator only inside `via`, so its own fresh holder admission and unsent/uncertain commands
remain authoritative. No editor property, slot, candidate or write operand is inferred from browsing intent.

`MangaReaderEntry` receives the actual ordinary Subject address and existing route session identity. ContextLink
preserves the already validated occurrence opener, locale and Realm through the actual part and relation-editor
routes. Deliberate return rereads the supported view/node/opaque cursor, selects only an exact re-admitted occurrence,
and focuses its connected Inspect control only if focus is otherwise unclaimed. A missing occurrence announces the
change and uses the current region heading; it never scans other windows. Canonical/new-tab links retain normal
browser behavior and the native editor retains its existing departure protection.

Retired recovery and unavailable-window Retry are ordinary document links: they obtain a new admitted page before any
controls reappear. No click clears the retirement latch against old windows. Retry retains the exact supported node
and cursor; explicit Restart removes only its cursor and returns to the region. Sparse continued, terminal empty,
withheld and unavailable windows remain distinct. Overview enters the full Contents/Edition view afresh, since a
preview node cannot supply the full view's continuation. A full-view Next uses its exact supplied native node/cursor.

### Retained disclosure bounds

Each supplied window still admits at most `WORK_PARTS_PAGE_CAP=20` rows. Each retained assertion admits one main Snak,
at most 16 qualifiers, 16 reference groups and 16 parts per reference: at most 273 Snaks. Each row's related projection
admits at most 256 native summary entries, retaining only matching disclosed IDs. No per-target read, definition fetch,
private overlay, new producer ABI or browser refill is added. Labels for values and evidence properties come from the
current supplied summaries and released property labels; unavailable labels are never resolved by title.

For `W` supplied relation windows, the conservative composed retention bound is `20W` assertions, `320W` qualifiers,
`320W` reference groups, `5,120W` reference parts, `5,460W` total Snaks and `5,120W` related-summary slots. These are sums,
not a new traversal allowance. The installed composition's 16-read bound gives at most 320 rows, 5,120 qualifiers,
5,120 reference groups, 81,920 reference parts, 87,360 Snaks and 81,920 related slots. Native producers may disclose
fewer distinct related summaries across a response; this conservative row-slot bound does not claim additional reads.
The selected inspector adapts at most its one row's 256 labels and retains one origin fragment of at most 2,048
characters inside the existing 32,768-character Subject return-address cap. Node, property and assertion locator fields
are bounded at 64, 256 and 128 characters; holder and target retain native UUID identity. Existing 8,192-character
opaque cursor, composition byte limits and producer response limits remain unchanged. There is no new assumed whole
page byte ceiling. Work is linear in the current supplied windows and admitted evidence; retirement releases its old
source reference, and sequential visits do not retain prior bodies.
