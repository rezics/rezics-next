# Catalogue creation

Music context, catalogue file and Concept creation use `creation-host/use-creation-host.tsx`
for the mounted metadata reading, last good release, retained term/fact types, archived choices,
refresh exclusion and review revision. Profiles retain native preparation, commands, field admission
and labels. `CreateSubjectForm` remains the term editor and review/command authority.

Decision: a refresh attempt retires review authority even if recovery returns the same digest;
archived choices remain available during a failed refresh so retained drafts can be recovered explicitly.
The existing `useCatalogueLifetime` boundary fences reader/address replacement without another observer.
Concept owns classification return and leave confirmation; file hash/codec explanations remain profile notices.
The shared statement summary projects values through `PartValue`, preserves evidence order, and renders
translated normal, preferred or deprecated rank meanings without reconstructing command operands.
