# Supplied Person and Character names

`PeopleNamesEntry` reads only the supplied public labels and aliases through the bounded
[model](model.ts). Person and Character mount it through
[SuppliedNames](../../pages/showcase-people/names.tsx); it does not fetch names or infer spellings,
language roles or permissions.

Decision: Reader preference allocation does not create a new name authority episode. Undefined to
first prepared preferences, including actual default values, and fresh equal-valued preference
objects preserve the open disclosure, local spelling filter, language/name windows and current
Sources/Terms handoff. Preparation during pending native advice keeps that existing request and
allows its current reply. Spoiler and suitability disclosure retirement belongs to
[PeopleFacts](../people-facts/visit.tsx), not this supplied-name identity.

The entry still binds public observation and release identity plus exact Subject, type, revision,
Context and locale. The shared [names lifetime](../work-names/lifetime.ts) owns browser observation,
viewer/credential and departure retirement, including permanent retirement on source reuse after
replacement. Preference preparation cannot restore withdrawn names, old advice or old links.

[Native advice](../work-names/advice.ts) keeps its existing lifetime and explicit retry policy.
[Names handoff](../work-names/navigation.tsx) owns frozen return operands and surviving exact-name
focus; [local navigation](navigation.ts) binds the supplied origin and selected Realm. Sources and
Terms keep their [reading](../subject-sources-page.tsx) and [command](../subject-terms-session.tsx)
contracts. Preference observations neither replace a return binding nor move focus off a connected
control.

Cost stays one admitted supplied-name model, one local filter, eight language groups with 24 names
per group window, and one advice lifetime. There are no per-name reads or additional indexes.

Consumer regressions in [people-names](../../../../tests/people-names.test.tsx) and
[people-names-source-visit](../../../../tests/people-names-source-visit.test.tsx) cover mounted
Person/Character preparation, bounded view continuity, pending advice, source/session retirement
and exact Sources return. Their execution belongs to integrated verification.
