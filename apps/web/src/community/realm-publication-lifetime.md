# Realm publication caller lifetime

Publication review extends the existing curation visit. Explicit selection reads one preparation for the original
work and Realm. It distinguishes no decision from adopted, rejected and withdrawn current decisions, including the
native timestamp. It keeps original and terminal work references and their independently disclosed presentations
separate. Only the admitted command buttons confirm a write; selection, inspection and conflict review never write.
Shelf heads do not supply review preconditions. The existing command remains responsible for current authorization,
including receipt replay.

A 409/412 consumes the preparation. Review explicitly reads a replacing preparation; a subsequent explicit decision
uses that preparation's original subject, destination and quoted precondition with a fresh key. No adopted-only point
read or automatic retry participates. An unavailable write retains its exact original sender, action, body, key,
subject and precondition. Read-only inspection may explain current state but never resolves that write or changes its
retry operands, even if its verdict matches. Definitive results release the original command.

One mounted caller captures Realm, reader, locale, session QueryClient generation, preparation source, sender and
source observation. Viewer, CSRF-session, locale, source/disclosure replacement and unmount retire selection,
preparation, original command and late effects. Strict Mode reconnects a healthy visit synchronously with a fresh
connection ticket. Selected work, in-flight commands and unknown outcomes use the shared departure owner. Stay
retains the original retry; confirmed Leave retires local continuations before navigation without cancelling a native
write. Closing review preserves an unknown retry. Existing picker/clear/opener keyboard focus remains local.
Shelf-menu actions select and open review; they never execute a decision. Shelf continuation and source/adopted rows
remain independent of preparation failure.

## Installed caller

The installed generated `realms({realmId}).publications({subjectId}).preparation.get` owns the response contract. The
Web reader invokes it once with private, no-store response handling and rejects a response whose serialized UTF-8
envelope exceeds the same 128 KiB limit before retaining selected detail. Preparation remains in the mounted visit,
outside query caches and persistent browser state. The current Realm decision and exact command advice remain usable
when either optional Subject presentation is concealed, empty, or unavailable. Preparation failure preserves shelf
continuation, reconciliation, membership and Board consumers.

The original presentation belongs to the original selected Subject; the terminal presentation belongs to its
disclosed redirect target. The review shows both identities and each label and cover state independently. Available
labels carry their native language. Available covers use the shared Cover and image-credit rendering, including the
complete Content-owned credit and rights obligations. The shelf picker contributes only original identity; its
title, types and image never become native review presentation. Commands continue to address the original Subject.

Decision: cap the serialized and retained selected publication review at 128 KiB UTF-8, project original and terminal Semantic summaries in one observation, and independently report an optional label or complete cover as unavailable when its full meaning cannot fit; never truncate attribution or legal text.

Replacing the mounted review scope closes its category and retires local focus effects. Ordinary inspection replaces
only the current preparation; it cannot release an unknown command or change its original retry operands. A fresh
native response can enable confirmation only after its original Subject, Realm destination, expected head and quoted
precondition match the existing command contract. GET success never supplies command authorization.

## Cost and bounds

- **Touches:** One generated preparation read per explicit selection or inspection and one existing native command
  per confirmed decision or original retry. No per-row reads, polling, background conflict lookup or shelf scan.
- **Response and retained detail:** At most 128 KiB of serialized UTF-8 JSON for `{preparation}`, checked by both
  producer and installed reader before retaining it. Two Realm title outcomes and two selected Subject label/cover
  pairs fit the current presentation contract: each available title or label has at most 4096 characters (at most
  25 KiB encoded JSON), and each complete cover summary is at most 12 KiB. The aggregate normalizer changes only an
  optional sibling that cannot fit to `unavailable`; it never truncates a label, attribution, credit or rights
  obligation. Original and terminal summaries are projected by unique-id map lookup in O(1) selected keys, once per
  Semantic observation, independent of admitted population size.
- **Focused coverage:** Kernel projection assertions cover 1/10/20 supplied summaries, original and terminal
  identities, multibyte label and complete credit retention, and whole-cover unavailability at its field boundary.
  Installed receiver assertions cover 1/10/20 supplied detail populations and reject an over-budget response.
  Current-head conflict, explicit readmission, exact unknown retry, and source/session/locale/exposure replacement
  remain pinned by the connected caller fixtures and visit owner.
- **Deferred acceptance:** Native producer recordings, physical growth proof, and rendered phone/desktop, light/dark,
  eight-locale review remain with their existing owners. Generated declarations and focused source fixtures establish
  none of those passes.

The implementation follows the installed generated method, native preparation implementation and its Semantic
summary adapter, and the existing command and private caller lifetime owners. No legacy implementation is ported.
