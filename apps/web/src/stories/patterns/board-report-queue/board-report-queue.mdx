# Moderation report queue

`BoardReportQueue` renders the real board moderation page's bounded report page. Each review card separates the
submitted reason and evidence from the ordinarily readable reported revision and current target. Report inspection
never unlocks either body. Missing, refused and removed content stays neutral; there are no reporter identities,
other-report summaries, copied bodies, raw identifier headings or per-card detail requests.

Open **Review report** to enter one takedown reason, or dismiss without a reason. The shared controls keep the draft
when the panel closes. A request disables the form and announces submission. An unchanged retry retains its command
key; edits and action changes create a new intent. Native denial, conflict and uncertain transport errors preserve
the draft and never confirm success. Native conflict explains that the report or target changed; native denial
explains the current permission failure without exposing private details. Both require an explicit current-state
refresh and review before a new decision, which receives a new command key. A lost response alone offers an exact
command retry to confirm its outcome. Its draft and decision controls stay locked until that outcome is known;
editing cannot turn an uncertain submission into a second command. Unknown failures remain errors and offer a fresh
read rather than a blind replay.

A confirmed command stays visible until navigation. Takedown confirmation is distinct from a projected report
outcome: the page does not claim that asynchronous report resolution has finished. It hides the current and revision
bodies for that target across the returned page after a confirmed takedown. Dismissal preserves current content.
Resolved read rows show the native disposition and resolution time. Appeal statements remain in the separate tab.

An empty page with a continuation still offers Next page. It does not imply a total count or an exhausted queue.
Loading and error states show no report details. The page uses its known board route for Back to board; it does not
invent a community name or fetch one merely for the heading.
