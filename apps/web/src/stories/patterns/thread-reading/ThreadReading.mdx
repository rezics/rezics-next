# Thread reading

Pattern and Page stories share the delivered `ThreadReading` region and native post/header components; Pages add
`AppShell`. Existing thread, owned-thread, Realm-thread and history recordings supply their data. Explicit lifecycle
examples use null current bodies. The existing state components represent loading, unavailable and current denial.
Play interactions reach selected/cancelled parent, own edit, history and report states.

See the web README's Thread reading source contract for layout, privacy and data bounds. Review the same story IDs
with `phone390` and `desktop1280` viewport globals and existing locale/theme globals. These stories establish no
native authorization or visual pass. Exact revision pages belong to their separate route.
