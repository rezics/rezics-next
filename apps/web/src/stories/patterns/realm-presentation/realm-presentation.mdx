The [Web owner contract](../../../../README.md) owns this interface. The Pattern is the same component inserted
in Space/Realm management. Fixture transports exercise the mounted native source adapter with explicit HTTP DTOs; fixture success supplies no native evidence.
Use the existing viewport, locale and theme globals for review. Rules select an existing exact post revision;
authoring stays in the existing post composer. The board/header owner alone composes the public community layout.

The default Panel binds its query and Settings controller to one Realm visit, QueryClient session source and cache
revision, account, CSRF credential, readiness and locale. A same-account update retires pending work and starts a
fresh cache entry. Settings owns selection openings and preview responses by exact slot, input and head. Its
uncertain retry stays in the current visit and keeps the original command identity; a new visit starts without that
private draft or intent. The actual site upload transport remains uploader-bound and is cancelled with the visit.
