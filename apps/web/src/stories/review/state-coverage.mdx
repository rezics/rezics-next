# State coverage

The <LedgerLink /> is the source of truth for page story
coverage. Each row names a route, state, viewer, and desktop and phone story.

- A story reference covers only the outcome that story actually renders.
- `missing` means there is no story for that cell yet.
- `planned: <dependency>` means the outcome has no API yet and names the capability it awaits.
- A recording that fabricates a missing outcome never counts as coverage.

Storybook fixtures support interface review. Native API acceptance remains the evidence for authorization,
disclosure, indexing cost, and lifecycle behavior.
