# Storybook catalogue

The catalogue presents route-level pages, shell-free patterns, and shared components. Page stories use recorded data; a
pattern isolates one connected region of a page. The [coverage map](../../../../docs/development/page-stories.md) tracks
implemented and pending outcomes.

Start with a product area to find its pages and connected workflows together. Each folder contains the relevant
behavior states. For example, find the [Collection Editor](?path=/story/patterns-collection-editor--details)
under Library → Collections. Shared UI primitives are in the composed Components catalogue.

## Change the view

Use the Locale and Theme toolbars to switch language and light or dark theme. Choose a story and use the viewport
toolbar to inspect the same story ID at `desktop1280` or `phone390`. Width, locale and theme use globals rather than
separate behavior exports.
