# Current conversation activity

The native reading page selects its one thread through the existing conversation activity producer and confirms
after foreign hydration. Its closed activity field contains public exact or lower-bound reply counts and the native
last contribution time, or explicit withheld/unavailable state. Private cohorts are withheld by that producer.
No internal witness crosses the wire. A changed source uses the page's existing unavailable response and retry.

The browser keeps this activity alongside the admitted page, independently of loaded reply rows, cursor and reactions.
Zero and null remain native facts: zero is rendered and a null timestamp adds no time label. Continuations and selected
post visits use that same native page. Retry and accepted replies refresh the original page request through the existing
reader owner; the composer keeps uncertain command intent. Page/session retirement hides the whole observation.
Activity uses the reader's exact query key, the shared browser observation/cache subscription and a retiring address
lease. Fetching, invalidation, replacement and session changes retire displayed advice without retiring readable bodies
or taking over refresh. Equal session replacement and away/back transitions cannot reactivate a retired observation.

Decision: consume `ReadingPageResponse.conversationActivity` directly through the existing closed display adapter once
the official complete-input publication supplies that installed property and root-derived reading callable. The publisher
owns generated declarations and public roots; the receiver introduces no API DTO or type override. An absent field at a
retained compatibility boundary is explicitly unavailable, never zero or a guessed total. Keep the existing transport,
activity producer and browser observation owner.

The activity row wraps on small screens, uses a native keyboard button for retry, labels lower bounds in the active
locale and renders the absolute native timestamp in UTC. Existing Board activity messages cover these same meanings.

Work stays bounded to one selected native thread and its one confirmation. It adds no per-reply activity work, census,
aggregate, polling or new command authority. Original reading-page source/place/actor checks and reply bounds remain.
