# Private Media inventory visit

The signed-in `/library/media` route reads one native window of at most 20 rows. Sparse windows keep their
native continuation, including empty continuing windows. Inspection replaces the selected row and uses only
current native advice. The existing container return descriptor contains row, viewer, cursor, locale and source;
it is a focus hint, not read authority.

Decision: preserve the mounted removal episode by withholding deliberate page movement while its original
request is sending or uncertain; ordinary row inspection and original-command recovery remain available.
The synchronous episode ref gates activation before React renders the sending state. Acknowledgement or refusal
releases movement through the existing episode settlement. Retirement still withholds private presentation
through the existing current-origin boundary. This decision adds no command host or retry engine.

## Read and retention costs

One native list read supplies the current window; local indexing and rendering cost O(N), N <= 20. Inspection
uses that window without another list read. The original removal sender, command and acknowledgement/readback
remain in the existing removal episode. They never belong in cursor history or container-return state.
Transport and query retain their existing no-store and zero-disposal-retention policy.

## Remaining return journey

Previous and First are not yet integrated. Their coordinates belong in the mounted route or outer-page visit,
not the workspace keyed by cursor. Retain at most eight admitted preceding coordinates plus current and one
staged target, using `ownMediaCursor` grammar. Retain no previous window bodies. Commit movement only after a
fresh read of the exact target passes current subject, locale, source and origin admission. Failed movement
keeps its exact target for Retry; First omits cursor. Invalid cursors require explicit Restart. A later empty
terminal window means end of this traversal, not an empty account.

Address changes must continue retiring the existing shared read origin. Loader/query coordination must supply
one read per deliberate movement, without seeding a replacement authority from stale loader data. Browser
Back/Forward re-admits data. Fresh visits invent no predecessors. Viewer, session/account, credential/caller,
exposure, source, locale, client or visit replacement clears coordinates and staged targets together with row
presentation. Equal replacement and A/B/A cannot revive a retired visit. New movement controls must use the same
synchronous removal gate and preserve conditional keyboard heading focus.
